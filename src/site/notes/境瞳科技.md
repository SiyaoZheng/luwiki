# 境瞳科技

境瞳科技是 [[社会世界模型\|社会世界模型]] 和社会智能方向的创业公司。公开资料显示，公司脱胎于中国人民大学信息学院，并完成数千万元人民币天使轮融资；其长期目标是用大规模社会模拟器为社会世界模型预训练提供数据。

## 定位

- 公司目标是让 AI Agent 理解人类社会中的意图、博弈、舆论传播和群体行为。
- 公开披露的社会模拟器运行超过 1350 万个拟人化 AI Agent，覆盖 100 多个国家。
- CEO 弭宝瞳把社会世界模型类比为对社会动力学的可计算表示，与具身智能中的物理动力学建模相对。
- 团队背景集中在社会计算、社会模拟、心智建模、多智能体协作、用户行为预测、Agent Memory 和 LLM Alignment。

## 关联

- [[社会世界模型\|社会世界模型]]：境瞳科技当前产品和长期叙事的核心概念。
- [[世界模型\|世界模型]]：把世界模型从物理/机器人语境扩展到社会动力学语境。
- [[以人为中心的具身智能\|以人为中心的具身智能]]：两者都强调 AI 需要理解人，但一个偏具身共处，一个偏社会关系与群体反应。

## 三同关系线索

- 核心人物是弭宝瞳。公开报道把他列为境瞳科技创始人/CEO，并将团队来源写成中国人民大学信息学院社会计算与社会智能实验室。
- 同校/同事线索非常强：这页可以直接写“人大系团队”，但要把它具体化为中国人民大学信息学院、社会计算/社会智能实验室、社会模拟和多智能体研究积累，而不是当作模糊标签。
- 融资关系统一经 [[境瞳科技天使轮融资\|境瞳科技天使轮融资]] 事件页中转；这些是资本网络，不能替代团队关系，也不能推出共同投资机构之间的联盟。
