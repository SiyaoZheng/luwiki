# Anthropic Long-Term Benefit Trust

Anthropic Long-Term Benefit Trust（LTBT）是受特拉华州法支配的普通法目的信托，也是 [[Anthropic\|Anthropic]] 公司治理结构中的 Class T 股东。它不是 Anthropic 的母公司、运营主体、非营利基金会、公共机构或平行董事会。LTBT 的公开使命与 Anthropic PBC 的公司目的相呼应，但其实际权力来自信托文件、公司章程和 Class T，而不是“代表全人类”这一表述本身。

LTBT 于 2023 年在 [[Anthropic Series C 融资\|Anthropic Series C 融资]] 交割时配合公司修章建立，并于 2023-09-19 对外详解。它接替了 2021 年 Series A 文件中的 Long-Term Benefit Committee 早期方案；后者是治理设计前身，不应当作另一个现存组织或 LTBT 的无时点别名。

## 法律结构与角色分层

Anthropic 官方将 LTBT 定义为 Delaware common-law purpose trust。特拉华州法第 12 编 §3556 允许没有可识别受益人的非慈善目的信托有效存在，但这不等于公众成为可诉受益人，也不等于公众持有 Anthropic。

参与设计的外部律师说明，信托原设计包含：

- 五名 Voting Trustees，负责实质治理权；
- 一名由特拉华州信托机构担任的 Administrative Trustee，只承担维持特拉华法域与准据法所需的狭窄行政职能；
- Anthropic 公司及满足未公开持股比例、持股期限条件的股东群体具有一定执行信托的路径。

Administrative Trustee 的身份、完整 Trust Agreement、执行条件和后续修订均未公开。本轮也没有证据证明 LTBT 另设 Trust Protector。参与设计律师所述由公司及合格股东群体执行信托的安排，在 2025-08-21 生效且适用于无论何时设立之信托的特拉华州修法下，落入 §3556(c) 的 enforcer 概念；但现行 Trust Agreement 未公开，无法确认指定主体、门槛、是否存在排他 standing，或文书是否修改 enforcer 默认的 fiduciary 身份。

## Class T 与董事权

Anthropic 在 Series C 交割时创设 Class T Common Stock，并由 LTBT 独家持有。Class T 数量很少、经济权利受限，核心用途是把部分董事选举和罢免权交给信托结构。个人 Trustees 并非以个人投资者身份持有 Class T；公司 2026 年公告称 Trustees 不持 Anthropic 个人股权、不分享公司利润，只按时间和服务获得补偿。

公开材料能够确认的权力包括：

- 按时间和融资里程碑逐步选举、撤换部分董事；
- 对某些可能显著改变公司或业务的行动取得预先通知；
- 就长期问题向董事会和领导层提供意见；
- 在部分 Class T 权利、董事会结构或重大公司行动上行使章程列明的类别权利。

公司 2023 年公告称，设计目标是在四年内让 LTBT 选出董事会多数。外部设计律师把阶段描述为五席中的一席、两席、三席。一份由研究者称从特拉华州取得、但由 Google Drive 而非 Anthropic 或特拉华州官网托管的 2024-05-20 章程副本，进一步列出阶段日期、融资阈值、重大事项通知和部分 Class T 同意权。由于本轮未取得现行完整章程，2024 条款只能作为日期化快照，不能无条件写成 2026 年现行全文。

“通知权”不等于通用否决权；LTBT 也没有公开的一般模型发布 veto。LTBT 不介入日常经营或普通商业战略，Anthropic 仍由公司董事会监督。由 LTBT 选出的董事仍是 Anthropic PBC 董事，并承担公司法上的 fiduciary duties，而不是只向 Trustees 或抽象公众负责。

| 2023-12 | Jason Matheny 离任 | 公司称为避免与其政策工作产生潜在冲突 |

独立性应限定为相对 Anthropic 管理层、投资者和个人经济利益的制度设计。新 Trustees 仍由现任 Trustees 在与公司协商后选出，股东也保留章程列明的超多数 failsafe；因此“独立”不等于政府任命、公众代表、不可替换或完全脱离公司。

## 董事任命的实际运作

公开任命记录显示 LTBT 的董事权已经实际运行：

- [[2024 LTBT任命Jay Kreps为Anthropic董事\|2024 LTBT任命Jay Kreps为Anthropic董事]]：2024-05-29，Anthropic 一手公告确认 Jay 由 LTBT 任命；TIME 次日报道称他是 LTBT 选出的首位董事。同日 Luke Muehlhauser 另行离任，不能据此写成 LTBT 罢免了他。
- [[2025 LTBT任命Reed Hastings为Anthropic董事\|2025 LTBT任命Reed Hastings为Anthropic董事]]：2025-05-28，Reed Hastings 由 LTBT 任命。
- [[2026 LTBT任命Vas Narasimhan为Anthropic董事\|2026 LTBT任命Vas Narasimhan为Anthropic董事]]：2026-04-14，官方称该任命后 Trust-appointed directors 在当时董事会中已占多数。

2026-04 的多数表述对应当时七人董事会并包含 Jay Kreps；2026-08 当前公司页只列六名董事且不列 Jay，也未逐席标明选举来源。Chris Liddell 的任命公告也没有说明由哪一类别选出。因此不能根据历史任命稿自行推算当前 LTBT 席位或把 2026-04 的多数状态机械外推到 2026-08。

## 股东 failsafe 与可执行性边界

Anthropic 2023 年公告说明，随着 LTBT 权力逐步增加，股东改变信托及相关权力所需的超多数门槛也提高。这是防止少数主体轻易移除信托的 failsafe 设计，同时也说明结构并非永不可改。

Trust Agreement 与现行完整章程没有公开，公众并无已核实的直接执行 standing。独立法律分析指出，公开可知的执行路径主要落在公司和满足条件的股东群体。外部投资者的融资金额、商业合同或无表决权证券不能据此推出其拥有 LTBT 席位、董事任命权或可单独修改信托。

## 证据边界

- LTBT 本身持有 Class T；个人 Trustees 没有个人经济性股权。两者不能混写。
- 五人是结构设计，不等于每个时点都有五名公开在任者。
- 2024 章程副本由第三方托管且仅是历史快照；现行完整章程未取得，不能当作当前逐条有效版本。
- Class T 的选董权、特定同意权、通知权和咨询角色不同；不能概括成“控制一切”。
- 董事被 LTBT 任命不改变其作为 Anthropic PBC 董事的公司法职责。
- LTBT 与 Anthropic PBC、投资者、董事会、Trustees、Administrative Trustee 都是不同角色。
- 本页只研究可核验的组织与治理关系，不建立抽象治理理论、通用目的信托或技术实现页面。
