# 清华大学计算机科学与技术系

清华大学计算机科学与技术系是[[清华大学\|清华大学]]的教学科研单位，成立于 1958 年，覆盖计算机系统、软件、理论、人工智能、机器人和人机交互等方向。

## 与当前实体的关系

- [[刘松铭\|刘松铭]]与清华计算机系、朱军教授的关系已由院系官方页面确认：刘松铭为计 91 班本科生、2022 年本科生特等奖学金获得者，页面明确列出导师朱军教授。人物—院系和导师关系已核验，不再停留在媒体/作者网络线索层。
- LiberAI是刘松铭的公司节点，不是清华计算机系的校办企业或下属机构。

## 边界

同系、共同论文与创业公司关系必须分别建模；院系背景不构成公司投资、技术背书或成果归属。
