# 华南理工大学广州国际校区

华南理工大学广州国际校区是[[华南理工大学\|华南理工大学]]第三个校区，由教育部、广东省、广州市和华南理工大学四方共建，不是独立大学法人。

## 与当前实体的关系

- [[吴贤铭智能工程学院\|吴贤铭智能工程学院]]位于该校区，是校区内学院节点。
- 校区地缘可用于观察粤港澳大湾区智能制造与机器人教育网络，但不自动构成企业合作关系。

## 边界

本校区不能与香港科技大学（广州）混同：前者是华工校区，后者是独立合作办学法人。
