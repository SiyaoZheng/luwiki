# 北京经济技术开发区

北京经济技术开发区（北京亦庄）在本轮资料中作为机器人应用与公共运营试点的政府端点出现。

## 已核验关联

- 启动 [[2027 北京亦庄人形机器人半程马拉松\|2027 北京亦庄人形机器人半程马拉松]] 全球招募。
- 公开 [[北京经开区具身机器人演艺沙盒审批试点\|具身机器人演艺沙盒审批试点]] 的流程与试点状态。

## 边界

以上仅说明其在两项公开事项中的机构角色，不能由此推定任何企业、产品或赛事结果。
