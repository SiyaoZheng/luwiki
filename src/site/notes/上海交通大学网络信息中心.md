# 上海交通大学网络信息中心

上海交通大学网络信息中心是[[上海交通大学\|上海交通大学]]负责校园网络安全、信息化、数据服务与校级计算平台的核心部门，前身为 1973 年创建的计算中心。

## 与当前实体的关系

- 中心官方大事记确认其建设和运营校级计算服务；[[致远一号\|致远一号]]属于这条校内算力基础设施链。
- [[OpenClaw 上海交大课堂部署\|OpenClaw 上海交大课堂部署]]确认网络信息中心承担运行环境、网络、安全策略和并发支撑。截至 2026-08-10，公开材料没有把中心列为 OpenClaw 创始团队、代码权利人或产品所有者；该关系明确关闭为校内基础设施与部署执行，不由运维角色推断项目权属。

## 边界

平台运维或部署支持不等于中心是 OpenClaw 的创始团队、投资方或产品公司。
