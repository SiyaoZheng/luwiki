# 自进化智能体

自进化智能体指在部署后能通过环境交互、任务反馈、工具扩展、经验沉淀和策略更新持续改变自身能力的 agent。它不是单纯更长上下文，也不是固定工作流自动化。

## 观察

- 甲木 GEO 来源把自进化智能体定义为能在使用中自我学习、自我迭代、自我升级的系统，并把环境交互、自主发现不足、自我持续改进和经验沉淀复用列为核心能力。
- 2026 中国 AI 智能体大会确实设置了自进化智能体技术研讨会，说明 SEA 已成为国内 Agent 议题的一部分。但来源中的具体数据，例如某些 star 数、国家标准编号和人物判断，需要逐条核验。
- [[AI 记忆系统\|AI 记忆系统]] 是自进化智能体的必要但不充分条件。只有记住历史不等于自我进化；进化还要求反馈评估、技能更新、策略选择和可审计回滚。
- [[yoyo\|yoyo]] 把自进化智能体变成一个可观察的 coding agent 实验：它通过 harness、skills、GitHub issues、人类反馈和公开运行记录持续修改自身。
- [[Hermes Agent\|Hermes Agent]] 提供了更工程化的自进化路径：把成功工作流压缩成 skill，在跨模型调用中复现，而不是只依赖下一次 prompt 重新探索。
- 自进化能力会放大 [[AI Agent 安全\|AI Agent 安全]] 问题：agent 如果可以自己安装技能、调整信任图谱或改写行为策略，就必须有权限边界、版本记录和人工审计。
