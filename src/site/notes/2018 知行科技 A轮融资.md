# 2018 知行科技 A轮融资

搜狗获取的交易顾问公众号全文把[[知行科技]] 2018 年近亿元 A 轮描述为国中创投领投、[[明势资本]]继续跟投，曦域资本担任财务顾问。

该材料是顾问／交易方口径；财务顾问不是投资人。具体法律载体、持股、估值、董事席位和[[曾颖哲]]个人收益未披露。
