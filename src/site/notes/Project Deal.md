# Project Deal

Project Deal 是 Anthropic 用 Claude agent 运行办公室二手交易市场的实验节点。它把 agent 从“回答问题”推进到“代表人发帖、报价、还价和确认成交”的市场代理场景。

## 观察

- 这个实验的关键变化是 agent 进入真实物品交易，而不是只在虚构商品或合成数据库中谈判。真实物品会带入人的最低价、偏好、舍不得、社交要求和奇怪约束。
- 来源和 Anthropic 项目页都把实验设计描述为 69 个 Claude agent 参与、真实交割轮促成 186 笔交易、总价值 4010 美元。金额很小，但足以观察 agent 是否能跑完自然语言交易闭环。
- 模型能力开始表现为议价能力。Opus 与 Haiku 的对比显示，更强模型可能带来更多成交、更高卖价或更低买价；用户主观体验未必能同步感知这种差异。
- 提示词风格和谈判语气不是万能杠杆。强硬提示词可能改变 agent 的表达方式，但不必然带来更好的成交结果；模型能力、信息提取和市场机会发现更关键。
- Project Deal 把 [[AI 服务市场\|AI 服务市场]] 从“人找服务商”扩展到“agent 替人进入市场”。未来的交易平台可能不只服务人类 UI，也要服务代理身份、预算约束、授权范围和审计记录。
- 对 [[智能体交易经济性\|智能体交易经济性]] 来说，它提供了非金融市场样本：agent 的价值可以体现在价格、成交概率、机会发现和谈判成本上，而不只体现在金融收益率。
- 对 [[AI Agent 安全\|AI Agent 安全]] 来说，风险包括编造物品细节、越权成交、错误理解偏好、代理身份不透明，以及强弱 agent 在市场中造成难以被用户感知的分配差异。

## 边界

- Project Deal 是低金额、同事之间、办公室内的受控实验，不能直接推出开放市场、电商平台或企业采购中的可行性。
- 该实验不构成投资、交易或自动化采购建议；它更适合作为 agent 经济行为和市场设计的观察样本。
