# 经营者集中申报合规

经营者集中申报合规关注企业并购、收购或控制权变化是否需要在交易完成前依法申报。它的关键观察是：即使交易经评估不具有排除、限制竞争效果，未依法事先申报本身仍可能构成程序性违法。

## 观察

- 立讯精密收购闻泰科技部分业务案显示，经营者集中合规不只看交易结果是否限制竞争，也看交易是否在应申报时履行了事先申报程序。
- 主动报告违法事实、配合调查、完善并有效实施反垄断合规管理制度，可能进入监管处罚裁量，但不能消除未申报行为本身。
- 该案体现了“处罚与教育相结合”的监管逻辑：处罚既针对已经发生的程序违法，也向经营主体释放主动纠错和制度建设的激励。
- 对公司治理来说，反垄断合规不是交易后补救事项，而应前置到投资、并购、业务整合和法务尽调流程中。

## 边界

- 本页只记录监管合规观察，不构成法律意见。
- 罚款金额、从轻/下调处罚原因和具体案件事实均来自来源中的监管通报转述，后续引用应优先核对市场监管总局正式处罚决定。
