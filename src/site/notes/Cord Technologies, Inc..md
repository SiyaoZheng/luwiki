# Cord Technologies, Inc.

Cord Technologies, Inc. 是 [[Encord\|Encord]] 的美国法律主体。Encord 官网页脚列出该名称；美国 SEC 将其登记为 2021 年设立的 Delaware corporation，CIK 0001867487。

## 治理与融资申报

- 2024-08-13 Form D 列 [[Eric Landau\|Eric Landau]]、[[Ulrik Stig Hansen\|Ulrik Stig Hansen]] 为 executive officer/director，[[Anna Khan\|Anna Khan]] 与 [[T.J. Rylander\|T.J. Rylander]] 为董事。
- 该次申报对应 Series B-1/B-2 preferred stock：拟募 35,499,961 美元，已售 32,499,965 美元，7 名投资者。
- Form D 是发行通知，SEC 明示未审核其准确与完整；它不披露完整 cap table 或各投资者股比。
