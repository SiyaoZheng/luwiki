# LiberAI

LiberAI 是一个围绕具身基础模型和物理世界模型展开的机器人 AI 公司节点。它的可沉淀价值不在于单次融资数字，而在于把“预训练、物理数据稀缺、视频泛化和机器人可执行动作”组织成一条公司路线。

## 观察

- LiberAI 把 [[世界模型\|世界模型]] 理解为对物理 action 到 state transition 的建模，而不是只生成未来画面。这使它与 [[因果世界模型\|因果世界模型]] 相邻：重点从像素连续性转向动作、受力、接触和结果之间的机制关系。
- 这条路线把预训练放在核心位置。它默认具身智能不会只靠少量真机示教或任务微调解决，而需要先从更大规模的数据中学习可迁移的物理和操作先验。
- 物理数据稀缺是 LiberAI 叙事中的关键瓶颈。如果直接把稀缺物理数据与海量视频混训，视频模态可能淹没真正重要的物理信号；因此，公司路线强调在视频空间和物理空间之间建立对齐桥梁。
- [[刘松铭\|刘松铭]] 早期参与的 RDT-1B / RDT-2 工作为 LiberAI 提供了“具身预训练”和“无本体人类数据”背景，但这些研究工作不应被自动等同于 LiberAI 当前产品能力。
- LiberAI 是 [[物理 AI 创业生态\|物理 AI 创业生态]] 里“世界模型公司化”的一个节点：融资叙事、人才背景、预训练基础设施和真实机器人数据都被放进同一个商业故事中。

## 边界

- 数亿元 Pre-A、近 5 亿元早期融资和“全球首创”之类表述来自真格基金文章口径，需要用公司公告、工商信息或投资方公告继续核验。
- 当前公开材料更适合说明技术路线和创业定位，不能证明其模型已经在开放基准或真实客户任务中形成稳定领先。

## 三同关系线索

- 核心人物是[[刘松铭\|刘松铭]]。公司页只建立“公司—创始人/CEO”边；其清华学籍、导师和 RDT 共同研究关系在人物页分层核验，不把所有论文作者或清华师生自动写成 LiberAI 团队。
- 清华计算机系官方页面已经补强刘松铭的学籍与导师关系，但这仍是创始人个人训练路径，不是 LiberAI 与学校之间的投资、孵化、校办或技术授权关系。
- 投资关系可作为组织网络线索记录，但不等于三同关系本身；只有当投资方、导师、校友平台或早期员工之间有公开交叉证据时，才写入具体关系。
