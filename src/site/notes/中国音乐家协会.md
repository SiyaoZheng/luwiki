# 中国音乐家协会

中国音乐家协会（简称“中国音协”）成立于 1949 年，官方概况将其界定为全国性专业人民团体。本页将协会职务、会员关系与高校学籍、艺术院团任职分开建模。

## 与当前实体的关系

- [[雷佳\|雷佳]]：中国音协第十次全国代表大会公告记载，雷佳于 2026-06-28 当选第十届副主席；协会现行领导页面在 2026-08-10 仍将其列为副主席。这是协会一侧的直接确认。

## 证据状态与边界

- `协会主体与组织性质`：协会官网已核验。
- `雷佳—协会职务`：协会公告与现行领导页双重核验；页面未把雷佳列为“驻会副主席”，不能扩大职务属性。
- 协会职务、协会会员、参与协会活动是三种不同关系；任何一种都不能推出高校同学、师承或私人交往。
- 仅在协会改选、现行领导页变更或职务公告更新时重新核对，不再把这条关系保留为一般性待核验事项。
