# Linux Mark Institute

Linux Mark Institute（LMI）是 Linux® 文字商标的管理与再许可安排。按 2026-08-11 可核验的公开材料，最稳妥的当前身份不是一个已经证实仍独立存续的法人，而是由 [[Linux Foundation\|Linux Foundation]] 管理的项目／政策名称：LMI 的历史域名现已转入基金会法律页面，现行 Version 2.0 再许可协议的合同主体也直接是 Linux Foundation。

这套制度处理的是名称作为来源标识时的商标权，不处理 Linux 内核代码的版权许可、技术路线或维护者权限。开源代码许可不会自动附带商标许可；获得商标再许可也不构成产品认证、兼容性证明、安全保证或 Linus Torvalds／Linux Foundation 的背书。

## 当前权利链

| 层级 | 可核验角色 | 权利边界 |
| --- | --- | --- |
| [[Linus Torvalds\|Linus Torvalds]] | Linux 商标所有人；美国注册号 1,916,230、序列号 74/560,867 | 商标所有权不是内核全部代码的版权，也不是对所有 Linux 派生软件的所有权 |
| [[Linux Foundation\|Linux Foundation]] | 独占被许可人、LMI 计划管理者；代表商标所有人提供和管理再许可 | 管理商标不等于控制内核技术决策，也不等于拥有 Tux 图像 |
| 获批申请人 | 就申请核准书所列的准确组合标记和商品／服务取得非独占使用权 | 许可不可转让、没有排他性，也不会替申请人解决近似商标或域名争议 |

Linux 是文字商标；大小写变化不改变其文字商标性质。Tux 则是 Larry Ewing 创作的图像，需按其单独条件处理，不能由 Linux 文字商标再许可推出使用权。

## LMI 是什么，不是什么

当前 Linux Foundation 的《Trademark Usage》把 LMI 明确写为由基金会管理；`lmi.linuxfoundation.org` 和 `linuxmark.org` 的公众入口均重定向到基金会的 Linux Mark 页面。现行合同的双方是 Linux Foundation 与 sublicensee。这些证据支持把 LMI 写成现行商标管理／再许可计划。

历史材料则显示，LMI 曾以单独组织面目开展工作。2001 年访谈称其为新设非营利机构；2002 年官网存档称其为 California not-for-profit corporation。LWN 与 LMI 存档显示，它在 2005 年重组为 Oregon nonprofit mutual benefit corporation、获 501(c)(6) 资格，网站由 OSDL 托管，且当时仍有独立董事会。俄勒冈州当前仅含 active registrations 的开放数据中，精确名称 `LMI OREGON, LLC` 与 `LINUX MARK INSTITUTE` 均无结果。这个负结果只能说明本轮未找到同名活跃登记，不能证明历史实体何时注销、迁移或并入。

因此，LMI 的历史组织身份与当前项目身份需要分层叙述；不能仅凭旧协议或公司信息聚合站，把 `LMI Oregon, LLC` 写成今天仍在签约和运营的主体。

## 所有权争议与制度形成

| 时间 | 已核验事件 | 证据边界 |
| --- | --- | --- |
| 1994—1995 | William R. Della Croce Jr. 申请并取得美国 `LINUX` 注册；后向 Linux 企业主张收费 | 这说明其一度持有登记，不证明他是名称的真实首用者 |
| 1996-11-27 | Linus Torvalds、Workgroup Solutions、Yggdrasil、Specialized Systems Consultants／Linux Journal 与 [[Linux International\|Linux International]] 向 TTAB 提起 cancellation proceeding 92025806 | 诉求是撤销登记；不能把后来的和解写成法院已判定 Linux 是否为通用名称 |
| 1997 | 和解后登记转让给 Torvalds，程序于 1997-09-23 dismissed with prejudice | 转让与结案可核；保密和解的其他条款不可外推 |
| 2001—2005 | 公开材料开始以 LMI 非营利安排描述日常商标管理；2005 年俄勒冈重组并获得 OSDL 托管支持 | OSDL 提供服务器和部分人员支持，当时报道明确说它未取得 Linux 商标的特殊权利 |
| 2004—2006 | 许可从一次性 500 美元变为按收入分档的年度费用，随后又出现低于 5 万美元收入免收、较高收入按比例且封顶的方案 | 费用变化和主动联络引发透明度与自由软件分发适配争议；2005 年初版并非“人人每年 5,000 美元” |
| 2006-10-18 至 2006-12-05 | 可用官网存档把“收费自筹”切换为“获批申请人免费、永久、全球许可”的窗口限定在这 48 天内 | 快照只能限定政策页面变化区间，不能给出内部决定或合同生效的精确时点 |
| 当前 | 基金会向获批申请人提供免费、全球、永久的 Version 2.0 再许可 | 当前页面未标出 Version 2.0 发布日；“永久”仍受合同终止条款约束 |

1996—1997 年的所有权与转让事件由 [[Linux 商标争议（1996—1997）\|Linux 商标争议（1996—1997）]] 继续追踪；组织端点由 [[Linux International\|Linux International]] 补全。收费、期限与申请范围的版本变化由 [[Linux 商标再许可制度演化\|Linux 商标再许可制度演化]] 单独核验。

## 谁需要申请

LMI 当前 FAQ 使用一个三问测试。以下三项全部为“是”时，应申请再许可：

1. 该用法是自己的 trademark／brand identifier，而不只是日常提及；
2. 标记含相邻字母 `Linux`，大小写变化及外语中的语音等价形式也可能计入；
3. 标记用于识别 Linux-based 的软件商品或相关服务。

是否盈利、是否非营利以及是否已经向政府注册该标记，都不会自动改变这个测试。每个组合标记要单独申请，并说明具体商品或服务。

| 使用方式 | 当前政策下的处理 | 需要保留的法律边界 |
| --- | --- | --- |
| 新闻、论文、评论中指称 Linux | 通常无需再许可 | 不应暗示赞助或背书；基金会仍建议使用 `®` 和归属声明 |
| `runs on Linux`、`Linux-compatible` 等事实性说明 | 通常不把 Linux 当作自己的来源标识 | 是否构成指称性使用要看整体呈现，不只看单个短语 |
| `Foo Linux OS`、`Linux Foo` 等产品或服务品牌 | 需要申请 | 只覆盖获批的准确标记和商品／服务范围 |
| 机构名或咨询服务名含 Linux | 作为软件相关服务的来源标识时需要申请 | 免费提供或未注册不构成豁免 |
| 含 Linux 的域名 | 单纯注册域名不需要 | 域名被当作产品／服务品牌使用时仍可能需要；混淆分析是另一个问题 |
| 写有赞语的 T 恤、杯子、铅笔 | 当前 FAQ 认为通常属于 fair use | 不能把该例子外推到以 Linux 作为服装品牌、使用基金会 logo 或其他项目商标 |

基金会 FAQ 的 “fair use” 是其政策和风险指引，不是全球统一的法律安全港。美国 descriptive fair use、nominative fair use 及各巡回区的混淆分析并不完全相同，其他法域也可能采用不同规则。具体争议仍需结合使用语境和当地法律；[[Linux 商标的公平使用边界\|Linux 商标的公平使用边界]] 负责后续比较，本页不构成法律意见。

## 现行再许可的实际约束

现行 Version 2.0 协议称授权为 worldwide、non-exclusive、perpetual、non-transferable，并且免费申请。但这不是“无条件且不可撤销”：

- 授权只覆盖申请核准书列明的准确组合标记与商品／服务；
- Linux 应作为形容词搭配通用名词，不能在获批品牌中单独当作名词或动词；
- sublicensee 需使用规定的归属文字、不得挑战 Torvalds 的所有权，并承担合同约定的税费、赔偿和合规义务；
- Linux Foundation 可以检查获准商品和广告以履行商标维护职责；
- 重大违约、未经同意的转让、控制权变化、停止商业使用、破产或特定注册被最终驳回等情形可触发终止；
- “worldwide”只在 Torvalds 实际拥有权利且当地法律允许的范围内有效，不等于已证明每个司法辖区都有注册；
- Linux Foundation 不保证标记可注册、不会侵权、符合技术标准或获得市场排他性，也不替不同 sublicensee 调解争议。

2005 年澳大利亚注册与执法风波显示，美国登记和全球合同语言不能替代各法域审查；[[Linux 商标澳大利亚争议（2005）\|Linux 商标澳大利亚争议（2005）]] 将继续核验当地官方记录和政策反馈。

## 为什么开源项目仍管理商标

开源许可证允许在版权条件内复制、修改和再分发代码，商标则用于识别商品或服务来源。二者分离，使 fork 可以继续使用代码，却往往需要避免造成原项目赞助或官方延续的误解。对 Linux 而言，LMI 的制度目标是允许真实指称和广泛社区使用，同时对把 Linux 纳入自有品牌的行为维持可追踪的许可链和质量控制。

这种安排也带来治理张力。2005 年从一次性费用转为年度分档费用时，社区质疑收费、分发适配与决策透明度；LMI 支持者则把费用解释为跨法域注册和执法成本。现行免费制度消除了明确的申请费，却没有消除归属、范围、检查、终止和不挑战条款。因而“免费”描述的是价格，不是权利无边界。

## 不能推出

- 不能把 Linux Foundation 写成 Linux 商标所有人；所有人是 Linus Torvalds。
- 不能把现行 LMI 写成已经核实仍独立存续的 `LMI Oregon, LLC`；本轮只确认其历史组织形态和当前基金会管理的项目形态。
- 不能把商标再许可当作 Linux 内核代码许可、全部内核版权转让或技术治理授权。
- 不能把 sublicense 当作产品认证、安全审计、标准符合、兼容性证明或官方背书。
- 不能把 free、perpetual、worldwide 改写为无条件、不可撤销、可转让或每个国家均已注册。
- 不能把当前 FAQ 的 fair-use 例子写成适用于所有法域和所有商品呈现的普遍法律结论。
- 不能因本轮未检得近年公开判决，就声称 LMI／Linux Foundation 从未执法。
