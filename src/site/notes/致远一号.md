# 致远一号

致远一号是 [[上海交通大学\|上海交通大学]] 校内智算平台节点。来源称其拥有 1024 块华为昇腾 910B 加速卡，FP16 峰值算力 313 PFLOPS，并为教学科研提供校内闭环的大模型服务和 API 调用环境。

## 观察

- 致远一号的关键价值不只是算力规模，而是把模型 API、云主机、并发环境、安全策略和校内数据闭环组织成教学科研基础设施。
- 在 [[OpenClaw 上海交大课堂部署\|OpenClaw 上海交大课堂部署]] 事件中，致远一号支撑 45 个学生智能体和 1 个教师智能体同时运行，说明校内算力平台可以承载 agent 教学场景，而不仅是传统 HPC 作业。
- 来源称平台已上线 GLM、DeepSeek、MiniMax、Qwen 等多个大模型服务，供师生切换。这使模型选择、课程实践和数据安全可以在同一校内环境中管理。
- 对 [[Token-maxxing\|Token-maxxing]] 来说，致远一号提供了另一种组织路径：与其让师生个人分散调用外部 API，不如由机构提供统一预算、权限、日志和安全边界。

## 边界

- 具体算力、开放范围、收费规则、模型列表和 API 申请流程可能随平台阶段变化，应以校内正式通知为准。
