# Eric Landau

Eric Landau 是 [[Encord\|Encord]] 联合创始人兼 CEO。公司官方作者页称其此前在 DRW 从事高频交易和量化研究，拥有 [[Harvard University\|Harvard University]] 应用物理 S.M.，以及 [[Stanford University\|Stanford University]] 电气工程 M.S. 与物理 B.S.

## 治理关系

- SEC 2024 Form D 将其列为 [[Cord Technologies, Inc.\|Cord Technologies, Inc.]] executive officer、director，并由其以 CEO 身份签署。
- Companies House 将其列为 [[Cord Technologies Limited\|Cord Technologies Limited]] 当前董事。
- 这些治理角色确认人物—法律主体关系，不披露其当前股比或投票权。
