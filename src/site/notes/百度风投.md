# 百度风投

百度风投是由百度集团发起、聚焦人工智能相关创新的独立风险投资机构。

## 身份与层级

- “独立风险投资机构”与其由 [[百度\|百度]] 发起两项事实并存；具体管理人与基金载体需交易穿透。
