# 浙江大学生物医学工程与仪器科学学院

浙江大学生物医学工程与仪器科学学院，简称“生仪学院”，是 [[浙江大学\|浙江大学]] 的院系节点，覆盖生物医学工程、电子信息技术与仪器等教学科研方向。本页只维护与当前人物网络有关的组织层级，不把人物创业活动自动转化为学院与公司的机构关系。

## 研究与训练语境

孙煜的校方页面把脑机接口、神经调控和神经工程列为研究方向，2020 年招聘页进一步列出脑电、磁共振和近红外脑影像等认知神经工程方法。王肃杰的本科与博士阶段公开记录则表明，他在同一院系的生物医学工程训练网络中进入睡眠监测和脑机接口创业议题。

共同院系、师生和参赛记录能够支持教学科研网络，但不自动证明同门、实验室成员身份、学院持股、技术许可或校方商业背书。神踪科技的公司关系通过人物节点中转，本页不建立公司—学院直边。

## 证据边界

- 学院官网确认组织名称、隶属和学科方向；具体人物关系仍由个人主页、校方名单与带时间的报道分别核验。
- 王肃杰 2019 年记录是本科阶段名单，2023 年记录是博士研究生身份；本页不据此推断当前学位状态。
- 孙煜的公司兼职或创业角色不等于学院与公司已经存在投资、采购、技术许可或联合实验室关系。
