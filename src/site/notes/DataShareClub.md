# DataShareClub

DataShareClub 是一个提供全国城市历史天气和空气质量数据查询的平台节点。当前页面显示其覆盖城市逐小时温度、降水、AQI、湿度、风速风向、气压、能见度、露点、云量和短波太阳辐射等字段。

## 观察

- 城市模拟和人本研究需要的不只是建筑/道路底图，也需要天气、空气质量、能见度、热环境和辐射等连续环境变量。
- DataShareClub 与 [[WUDAPT\|WUDAPT]] 相邻：WUDAPT 更偏城市形态和 Local Climate Zone 分类，DataShareClub 更偏逐小时气象和空气质量观测。
- 对 [[人本城市模拟\|人本城市模拟]] 来说，天气和空气质量可以成为行为、情绪、出行、户外活动和公共健康模型的环境协变量。
- 对 [[MindSpace\|MindSpace]] 这类空间数据库路线来说，气象和 AQI 数据可以成为空间记忆层的一部分，而不是只作为外部背景。
- [[潜空间数据同化\|潜空间数据同化]] 和 [[PepWeather\|PepWeather]] 提醒，天气数据的下游不止查询和回溯，还包括概率预报、风险定价、出行保障和不确定性传播。

## 边界

- 当前来源是网页抽取结果，未核验数据来源、历史覆盖、授权条款和下载接口。
- 天气/AQI 数据用于研究或应用时，需要记录城市、站点/区域、时间、字段定义、缺失值和数据供应方。

## 三同关系线索

- DataShareClub 当前是数据平台页，不是公开团队页。官网只足以记录平台覆盖字段、城市范围和下载能力，不足以写创始人、公司主体或学校关系。
- 组织关系应写成“历史天气/AQI 数据入口 + 下游城市模拟/天气服务/研究应用”，与 [[PepWeather\|PepWeather]]、[[WUDAPT\|WUDAPT]]、[[人本城市模拟\|人本城市模拟]] 互链即可。
- 如果后续用于研究或商业采购，应优先补公司主体、数据来源、授权条款和接口协议，而不是补私人关系。
