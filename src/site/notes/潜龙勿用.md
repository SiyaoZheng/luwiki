# 潜龙勿用

“潜龙勿用”是《易经》乾卦初九爻的经典表达。它在本 wiki 中可作为一种关于时机、位置和能力显露的文化观察：行动能力已经存在，但外部位置、资源和承认条件尚未成熟。

## 观察

- “潜龙”不是无能，而是能力处在低位、初始或未被承认阶段；“勿用”不是永久不行动，而是避免在条件不足时过早暴露或强行推进。
- 这个隐喻把发展阶段分成两个问题：是否已经有内在力量，以及是否处在可以施展力量的位置。二者不同步时，策略重点转向积蓄、学习、等待和降低风险。
- 来源中的解释把“潜龙勿用”转成职业和创业语境：早期位置低、资源少、外部阻力大时，过度显露才华或强行动作可能带来反效果。
- 作为文化概念，“潜龙勿用”与现代组织中的试用期、早期创业、学徒阶段和研究积累期相邻：它强调能力形成与机会窗口之间的时间差。

## 边界

- 这里把“潜龙勿用”作为文化隐喻和行动时机模型，不作为占卜、投资、健康或人生决策建议。
