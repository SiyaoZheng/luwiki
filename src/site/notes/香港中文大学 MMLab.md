# 香港中文大学 MMLab

香港中文大学 MMLab 是[[香港中文大学\|香港中文大学]]的多媒体与计算机视觉研究网络节点，官方域名位于港中文体系。

## 与当前实体的关系

- [[黄青虬\|黄青虬]]的博士训练已由 MMLab 官方校友页直接确认：Qingqiu Huang 于 2016—2020 年在 MMLab 攻读博士，2020 年获博士学位，导师为 Dahua Lin。页面同时记录其本科和当时任职，相关机构关系只在人物页按固定中转路径建边。
- 该训练线索有助于解释墨奇智能的视觉和机器人算法来源，但不等于实验室孵化、投资或拥有公司。

## 边界

“MMLab 系”不是可替代逐人核验的团队标签；不同学校和时期的 MMLab 关联必须按作者、导师、项目与日期确认。黄青虬关系以官方校友页的 2016—2020 历史记录为界，只有实验室档案修订时才重新核对。
