# 北京大学光华管理学院

北京大学光华管理学院是[[北京大学\|北京大学]]的管理学院节点，前身可追溯至 1985 年设立的经济管理系，1994 年采用现名。

## 与当前实体的关系

- 学院案例页面明确把[[王宁\|王宁]]列为光华 MBA 学生和案例对象，支持教育/案例传播关系。
- 泡泡玛特作为案例对象进入学院教学传播网络，不等于学院投资、持股或为公司经营结果背书。

## 边界

MBA 学籍只支持同校线索；不能自动推断具体同学、导师、校友引荐或商业资源输送。
