# Pika AI Selves

Pika AI Selves 是 Pika 围绕个人数字分身推出的产品节点。它的观察价值在于：一家 AI 视频公司把外貌、声音、动作、表达风格、记忆和跨平台互动组合成“被养育的 AI 自我”，而不是只做视频生成工具。

## 观察

- AI Selves 把 [[数字分身\|数字分身]] 从文本人格文件推进到多模态身份代理：外貌、声音、视频表达、记忆、个性和社交行为被放进同一个分身体验。
- 来源中的关键心智模型是“养育”而不是“提示”：用户不只是一次性输入 prompt，而是持续塑造分身如何行动、思考、说话和成长。
- 这类产品把 [[AI 记忆系统\|AI 记忆系统]] 推到人格成长层。分身如果能跨 X、Slack、Discord、手机等环境互动，就需要持续记忆、场景切换和边界管理。
- 对 [[AI Agent 安全\|AI Agent 安全]] 来说，数字分身的风险不是普通生成内容风险，而是身份代理风险：它可能代表用户发言、互动、承诺、赚钱或维护关系。
- Pika 的视频背景说明数字分身竞争可能不只比文字人格复刻，也比视觉身份、动作表达和视频内容生成能力。

## 边界
