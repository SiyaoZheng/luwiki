# 神踪科技

神踪科技是位于杭州的脑机接口与神经工程技术公司，官网使用“杭州神踪科技有限公司”这一主体名称，并把公司方向概括为非侵入式脑机监测、评估与干预。当前最明确的公开产品线是“暮安”多导睡眠监测仪；产品能力与临床有效性需要分开判断。

公开报道把公司描述为高校研究与学生创业进入产业化的案例。相关教育和任职关系分别由 [[孙煜\|孙煜]] 与 [[王肃杰\|王肃杰]] 页面连接机构节点；本页不因人物履历建立公司—高校直边。

## 产品与技术路线

### 多导睡眠监测

公司官网把“暮安”列为多导睡眠监测仪，公开材料描述其采集脑电、眼电、肌电、心电、呼吸等多种生理信号，并把可穿戴、小型化与远程数据传输作为产品特征。这个路线可以理解为把传统床旁多导睡眠监测的多信号采集压缩进更轻便的设备与软件工作流。

上述信息能够确认产品目标和信号类型，但不能单凭公司页面或媒体报道确认：

- 对睡眠障碍的诊断准确率或临床敏感度、特异度；
- 与医院标准多导睡眠监测系统的等效性；
- AI 自动判读在不同人群、疾病和场景中的泛化表现；
- 医院覆盖、销量、市场份额或治疗收益。

这些结论分别需要医疗器械注册资料、说明书、临床试验、采购记录和独立评测支持。

### 从监测到干预

公司产品中心还列出经颅聚焦超声、失眠认知行为治疗管理系统、心理评估和认知训练等方向，并用“监测—评估—干预”组织产品矩阵。这是公司当前的产品组合与发展叙事，不表示每项产品均已完成同等级别的注册、临床验证或规模部署。
