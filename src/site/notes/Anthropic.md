# Anthropic

Anthropic 是 2021 年成立、依特拉华州法组织的 public benefit corporation（PBC）。现行法律主体在条款中写作 **Anthropic, PBC**；[[Claude\|Claude]] 是由该公司运营的产品与品牌，不是另一家公司。PBC 形态要求董事在股东经济利益、受公司行为实质影响者的利益与声明的公共利益目的之间作平衡，但不把公司变成非营利组织、公共机构或公众直接控制的企业。

公司由一批前 OpenAI 人员共同创办。[[Dario Amodei\|Dario Amodei]] 自早期担任 CEO，[[Daniela Amodei\|Daniela Amodei]] 担任 President；其他稳定可核的共同创办人包括 [[Jack Clark\|Jack Clark]]、[[Sam McCandlish\|Sam McCandlish]]、[[Jared Kaplan\|Jared Kaplan]]、[[Chris Olah\|Chris Olah]] 与 [[Tom Brown\|Tom Brown]]。Ben Mann 的 co-founder 称谓在公开来源中存在冲突，暂不把它写成无争议事实。人物的前雇主与学校关系经人物页中转，不能从共同履历推断私人关系、知识产权转让或现有控制。

## 产品与商业入口

Anthropic 的商业体系已经形成直接订阅、开发者平台、企业合同、云分销和伙伴采购等不同入口。

| 层次 | 产品／渠道 | 截至 2026-08-11 的商业定位 |
|---|---|---|
| 个人订阅 | [[Claude\|Claude]] Free、Pro、Max | Free 为 0 美元；Pro 月付 20 美元、年付折合 17 美元/月；Max 为 100 或 200 美元/月 |
| 团队 | Claude Team | 面向 2—150 人；Standard 年付 20／月付 25 美元每席每月，Premium 年付 100／月付 125 美元 |
| 企业 | [[Claude Enterprise\|Claude Enterprise]] | 自助入口为 20 美元/席，使用量另按平台费率计；销售协商合同可能采用不同条款 |
| 开发者与用量 | [[Claude Platform\|Claude Platform]] | 与 Claude app 订阅分开计费；订阅不自动包含平台用量 |
| 命名产品 | [[Claude Code\|Claude Code]]、[[Claude Cowork\|Claude Cowork]] | 属 Claude 产品组合，面向个人和企业提供不同采购入口 |
| 伙伴采购 | [[Claude Marketplace\|Claude Marketplace]] | 企业可把部分 Anthropic 合同承诺额度用于购买合作伙伴产品 |
| 服务伙伴 | [[Claude Partner Network\|Claude Partner Network]] | 认证、咨询、实施与联合市场进入网络；2026 年公告初始投入 1 亿美元伙伴支持 |

公开价格会变，税费、用量额度、销售折扣和企业合同未完全公开。Claude app、Claude Platform、Enterprise、Marketplace 与各云渠道不能因共享品牌而合并成一个合同或账单主体。

## 云供应、分销与战略投资

### Amazon 与 AWS

[[Amazon投资Anthropic\|Amazon投资Anthropic]]记录 Amazon 集团的少数股权投资；[[Amazon Web Services\|Amazon Web Services]]则是 Anthropic 公开确认的主要云与训练基础设施提供方。资本关系、云采购和渠道分销属于同一合作框架中的不同边，不能把 AWS 业务单元直接写成证券持有人。

Amazon 的 SEC 披露显示，截至 2026 年 6 月 30 日累计实际投入 **180 亿美元**：2023—2025 年累计 80 亿美元，2026 年第二季度又以 Series G 与 Series H 无表决权优先股投入 100 亿美元。另有最高 **150 亿美元**的条件性未来融资额度，额度随约定的 AWS 容量交付里程碑开放，并由 Anthropic 决定是否提款。该未来额度不是已到账资金。

Anthropic 同时承诺未来十年在 AWS 支出超过 1,000 亿美元。已投入股权资金、条件性未来额度、证券公允价值和长期云采购承诺不能相加；采购承诺也不是已经确认的 AWS 收入。Series H 已包含 Amazon 的 50 亿美元投入，不能再加到该轮 650 亿美元上。

商业渠道包括 [[Amazon Bedrock\|Amazon Bedrock]] 与 [[Claude Platform on AWS\|Claude Platform on AWS]]：前者由 AWS 管理、销售和计费，后者经 AWS 账户采购但由 Anthropic 运营。两者不是同一产品。AWS 是“主要”提供方不等于排他提供方，Anthropic 同时通过 Google Vertex AI、Microsoft Azure 等渠道提供产品。

无表决权、少数持股和 Amazon 对 Anthropic 不并表都不等于完全没有合同影响力；当前精确持股比例、完整治理权利与证券登记主体仍未公开。英国 CMA 2024 年因营业额和份额门槛不满足而结束审查，没有就 Amazon 是否取得 material influence 作实体判断。
### Alphabet／Google

[[Alphabet Inc.\|Alphabet Inc.]]／Google 既是少数投资关联方，也通过 [[Google Cloud\|Google Cloud]] 的 [[Google Vertex AI\|Google Vertex AI]] 分销 Claude，同时运营竞争产品 [[Google Gemini\|Google Gemini]]。英国 CMA 在 2024 年事实下认定 Google 没有取得对 Anthropic 的 material influence；该结论不能自动外推到后续投资。2025—2026 年额外投资金额主要来自媒体报道，缺少同级公司公告时不并入官方融资总额。

### 微软与 NVIDIA

[[微软\|微软]] 在 2025 年公告最高投资 50 亿美元，[[NVIDIA\|NVIDIA]] 最高投资 100 亿美元；Anthropic 同时承诺购买 300 亿美元 Azure 计算容量。Claude 进入 [[Microsoft Foundry\|Microsoft Foundry]]，但 AWS 仍被列为主要云提供方。投资上限、采购承诺、分销和产品集成并不证明任何一方取得控制权，也不代表金额已经全部到账。

## 客户、合作伙伴与市场进入

[[GitLab\|GitLab]] 同时是 Anthropic 的企业客户、产品集成伙伴和 [[Claude Marketplace\|Claude Marketplace]] 供应商。Anthropic 客户案例称 GitLab 采用 Claude Enterprise，并把 Anthropic 平台用于自身产品；GitLab 官方公告又把 Claude 纳入 [[GitLab Duo Agent Platform\|GitLab Duo Agent Platform]]。案例中的 25%—50% 生产率区间来自厂商与客户调查，不是独立实验，也不能外推到所有用户。

其他已公告关系包括：

- [[Snowflake\|Snowflake]]：多年期 2 亿美元协议，涵盖平台分销与联合市场进入；协议标称金额不等于 Anthropic 已确认收入或 Snowflake 已付款。
- [[Salesforce\|Salesforce]]：平台分销、产品集成和内部采用。
- [[Deloitte\|Deloitte]]：服务伙伴与内部企业采用；公告中的人员覆盖和认证人数属于计划／公司口径。
- [[Accenture\|Accenture]]：设立联合业务组、培训和共同市场进入；培训人数是计划值。
- Claude Partner Network 与 Claude Marketplace 分别承接服务伙伴和采购渠道，不应合并。

公司还通过不同国家的产品上线和办公室扩展市场覆盖。支持地区清单的缺席只能写成“当前未列入支持范围”，不能在没有公司公告时推断为主动退出市场。

## 董事会与 LTBT

现行官网列出的董事为：

- [[Dario Amodei\|Dario Amodei]]
- [[Daniela Amodei\|Daniela Amodei]]
- [[Yasmin Razavi\|Yasmin Razavi]]
- [[Reed Hastings\|Reed Hastings]]
- [[Chris Liddell\|Chris Liddell]]
- [[Vas Narasimhan\|Vas Narasimhan]]

[[Anthropic Long-Term Benefit Trust\|Anthropic Long-Term Benefit Trust]]（LTBT）是特拉华州普通法目的信托，独家持有 Class T 股票，并按章程和时点逐步取得选举、撤换部分董事的权力。截至 2026-08-12，当前公司页公开列出的 trustees 为 Neil Buddy Shah、Richard Fontaine 与 Ben Bernanke。五人是结构设计，不等于每个时点都有五名公开在任者；公司也没有逐席披露现行董事的选举来源，不能由当前名单自行计算 LTBT 的控制比例。

LTBT 的董事权已通过 [[2024 LTBT任命Jay Kreps为Anthropic董事\|2024 LTBT任命Jay Kreps为Anthropic董事]]、[[2025 LTBT任命Reed Hastings为Anthropic董事\|2025 LTBT任命Reed Hastings为Anthropic董事]] 与 [[2026 LTBT任命Vas Narasimhan为Anthropic董事\|2026 LTBT任命Vas Narasimhan为Anthropic董事]] 实际运作。2026-04-14 公告称任命 Vas 后，LTBT 任命董事在当时七人董事会中占多数；当前公司页只列六名董事且未逐席标明来源，不能把四月状态机械外推。[[2026 Mariano-Florentino Cuéllar退出LTBT并加入Anthropic管理层\|2026 Mariano-Florentino Cuéllar退出LTBT并加入Anthropic管理层]]记录他于 2026-08-04 离任并成为公司首任 Chief Global Affairs Officer。

LTBT 不负责日常经营；Trust 本身持有 Class T，但 trustees 个人不持 Anthropic 经济性股权、不分享利润。股东仍保留以超多数门槛修改有关权力的 failsafe。PBC 与 LTBT 都不等于公众持股、公众董事席位或不可修改的永久控制。

现任运营层还包括 CTO [[Rahul Patil\|Rahul Patil]]、Chief Architect [[Sam McCandlish\|Sam McCandlish]]、CFO [[Krishna Rao\|Krishna Rao]]、产品组织负责人 [[Ami Vora\|Ami Vora]]、Chief Commercial Officer [[Paul Smith\|Paul Smith]]；[[Mike Krieger\|Mike Krieger]] 转入 [[Anthropic Labs\|Anthropic Labs]]。头衔不能替代董事权、持股或 LTBT 权限证据。

## 竞争、监管与诉讼

Anthropic 与 [[OpenAI\|OpenAI]]／[[ChatGPT Enterprise\|ChatGPT Enterprise]]、Google／Google Gemini、微软／[[Microsoft 365 Copilot\|Microsoft 365 Copilot]] 等在企业助手、开发者平台和企业采购中竞争。Google 与微软又同时是投资或渠道关联方，因此合作与竞争可以并存。第三方企业调查的样本和估计方法不同，不能把单一调查写成全球审计市场份额。

英国的 [[CMA对Amazon-Anthropic合作审查\|CMA对Amazon-Anthropic合作审查]] 因营业额和 share-of-supply 管辖门槛不足而关闭，并没有对 Amazon 是否取得 material influence 作实体判断。[[CMA对Alphabet-Anthropic合作审查\|CMA对Alphabet-Anthropic合作审查]] 则只在 2024 年当时安排下认定 Google 未取得 material influence。FTC 2025 年行业报告讨论股权、咨询权、云依赖与信息共享的竞争风险，但不是认定 Anthropic 或投资方违法的执法命令。

知识产权方面，[[Bartz诉Anthropic版权和解\|Bartz诉Anthropic版权和解]] 于 2026-07-20 获法院最终批准，设立最低 15 亿美元的不可返还和解基金。最终 Works List 为 482,460 件作品，截至 2026-04-16 有 91.3% 收到有效 claim；扣费前“约每件 3,000 美元”不是每位作者的保证净到手额。和解只覆盖特定作品和截至 2025-08-25 的过去 input-related claims，不释放过去 output claims 或未来行为；它不是政府罚款，也没有把所有训练用途一次性判为合法或违法。[[Concord Music Group诉Anthropic版权案\|Concord Music Group诉Anthropic版权案]] 与 [[Reddit诉Anthropic合同案\|Reddit诉Anthropic合同案]] 仍属待决，诉状主张和程序裁定不能写成终局责任认定。

## 证据边界

- Anthropic 是私人 PBC；公开融资公告不足以还原完整 cap table、实时持股和表决权。
- PBC 的法定平衡义务、LTBT 的 Class T 权利、董事会职责与投资者商业关系是不同治理层。
- Amazon 只被公开确认为少数投资者，精确持股未知；Google 的监管结论有明确时点。
- 私募投后估值、run-rate revenue、客户数、合同承诺、到账现金和确认收入不能互换。
- 公司案例、合作伙伴公告与产品定价可证明商业入口和关系存在，不能单独证明净生产率、客户留存、市场份额或长期利润。
- 提交保密 S-1 草案只是上市准备步骤；发行仍取决于审查与市场条件。
- 原告诉称、初步裁定、管辖决定与最终责任必须分开。
- 本页只记录识别公司、产品和商业关系所需的高层事实，不展开技术实现或 cybersecurity。

## Claude Code 商业产品补充（2026-08-11）

[[Claude Code\|Claude Code]] 是 Anthropic 开发运营、归入 Claude 品牌组合的商业产品。公司于 2025-02-24 以有限研究预览形式首次公布，并于 2025-05-22 宣布核心产品正式可用。它通过个人付费订阅、Team／Enterprise 席位、独立按量采购和云市场渠道进入企业采购；不同入口共享产品品牌，但不必然共享合同方、账单主体或价格条件。

合同主体随客户地区与渠道变化：欧洲经济区、瑞士和英国的直接商业客户原则上由 [[Anthropic Ireland, Limited\|Anthropic Ireland, Limited]] 签约，其他地区原则上由 Anthropic, PBC 签约；云市场交易还受渠道方条款约束。当前公开价显示个人 Pro、Max，Team Standard／Premium 和 Enterprise 均可包含 Claude Code，但旧企业席位、销售协商合同、税费和用量计费可能不同，网页价格不能回溯外推到历史合同。

Anthropic 在 2025-09、2025-12 和 2026-02 分别自报 Claude Code 的年化 run-rate revenue 超过 5 亿、10 亿和 25 亿美元。最后一个公开的产品专属数字仍是 2026-02 的公司口径；2026-05 的 470 亿美元以上数字属于 Anthropic 全公司，不能转记为 Claude Code 收入。Run-rate 是把当时收入节奏年化，不等于审计后的 GAAP 收入、ARR、利润、现金回款或市场份额。

客户证据强度不一。[[Rakuten Group\|Rakuten Group]] 与 [[Salesforce\|Salesforce]] 从客户侧确认采用；[[ServiceNow\|ServiceNow]]、[[PwC\|PwC]]、[[Cognizant\|Cognizant]] 和 [[Coinbase\|Coinbase]] 分别披露团队部署、未来扩展或多供应商访问，但这些口径不能互换为已付费活跃席位。[[Cox Communications\|Cox Communications]] 的约 2,500 用户数字来自 Anthropic 与 [[Accenture\|Accenture]] 共同发布的厂商案例。Anthropic 另点名 [[Netflix\|Netflix]]、[[Spotify\|Spotify]]、[[KPMG\|KPMG]] 和 [[L'Oréal\|L'Oréal]] 为使用者；在没有同级客户侧材料前，应保留“厂商点名”的来源归属。

Anthropic 于 2025-12 公布 [[Anthropic收购Bun\|Anthropic收购Bun]]，并把 [[Bun\|Bun]] 团队与 Claude Code 产品路线相连；Bun 继续开源不改变 Claude Code 自身的商业许可属性。企业侧同时存在 [[GitHub Copilot\|GitHub Copilot]]、[[Cursor\|Cursor]] 等替代采购选择；Coinbase 的多产品开放证明多供应商并用可以存在，但不足以给出市场份额或领导地位。
