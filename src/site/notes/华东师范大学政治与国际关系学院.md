# 华东师范大学政治与国际关系学院

华东师范大学政治与国际关系学院是[[华东师范大学\|华东师范大学]]院系节点，2021 年在原政治学系和国际关系与地区发展研究院基础上组建。

## 与当前实体的关系

- [[刘擎\|刘擎]]是学院政治学系教授；学院官方人物页支持其任教关系。
- 学院科研机构目录把[[华东师范大学世界政治研究中心\|华东师范大学世界政治研究中心]]列为学院建设的校级科研机构，中心专页另行确认成立时间、主任和成员。这已足以闭合公开行政层级；页面未显示独立法人身份。

## 边界

学院任教、研究中心任职和公共思想传播是不同关系，不能从学院身份推断所有观点代表学校。
