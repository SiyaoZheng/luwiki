# 生成引擎优化

生成引擎优化（GEO）是围绕 AI 搜索、问答和 agent 信息使用习惯重构品牌内容的实践。它不是传统 SEO 的简单改名，因为目标不只是让网页被检索到，还包括让模型/agent 在回答、引用、决策或工具调用中信任并使用内容。

## 观察

- 甲木 GEO 来源把 GEO 的变化描述为从“一次性适配”走向“持续进化”：当 agent 能自我更新信任图谱和语义偏好，品牌内容不能只做一次关键词优化。
- 与 [[自进化智能体\|自进化智能体]] 结合后，GEO 的对象从生成式搜索系统扩展到 agent 网络：内容是否新鲜、是否有版本记录、是否支持决策、是否可被其他 agent 调用或转发，都会影响可见性。
- 该来源提出 “Generative Evolution Optimization” 的新解释，但这应视为行业评论话术，不是已稳定的标准定义。
- [[Profound\|Profound]] 把 GEO 推向可观测化：品牌需要知道自己在 ChatGPT、Claude、Gemini 等模型中如何被提及、引用、比较，以及不同模型使用哪些来源支撑回答。
- Agent-led Growth 把内容策略的对象从搜索引擎和人类点击者扩展到 agent 用户。内容是否原创、可核验、可引用、可被模型用于决策，会影响品牌在 AI 回答中的可见性。
- 对 wiki 来说，GEO 的可靠做法更像知识库维护：持续更新、证据可追溯、版本可审计、减少过时内容，而不是堆关键词。
- GEO 的结果必须拆层：允许抓取、进入索引/搜索、触发检索、被选为 citation、在答案中获得 prominence、事实/语言被 absorption、产生 referral，最后才是 conversion。上游某一层改善不能自动解释下游销售或品牌效果。
- Google、OpenAI 和 Perplexity 已公开 crawler/robots、基础内容质量或站长控制，但没有公开完整的检索、排序和引用评分公式。平台准入规则是必要条件，不是曝光承诺。

## 截至 2026-08-10 的答案

- **平台规则只公开了一部分。** Google 明确 AI Overviews/AI Mode 依赖核心 Search 排名与质量系统，标准 SEO 仍适用，而且 `llms.txt`、特殊 AI markup、强制内容切片或只为 AI 重写都不是必要条件；它还明确第三方工具不能访问内部排名系统。OpenAI 说明允许 OAI-SearchBot 有助于内容被发现、摘要和清晰引用，并建议用 referral traffic 观测点击。Perplexity 公开 PerplexityBot、robots 和 IP 范围。后两者同样没有承诺抓取后一定被选中或公开 citation score。
- **“动态语义偏好”可以测量，但不能被当作稳定的平台属性。** 可复现设计应固定一个按意图和漏斗分层的 prompt panel，加入同义改写；记录平台、模型、地区、语言、账号状态和时间；每个 prompt 重复运行；保存完整回答、citation 和页面版本；分别测 search trigger、selection、prominence、absorption、referral 与 conversion。跨时间变化可能来自模型更新、检索波动、竞争者内容和个性化，不能只归因于“Agent 口味变化”。
- **“Agent 网络布局”目前没有统一可验证指标。** crawler 可访问性、结构化且可核验的事实、稳定 canonical URL 和及时版本更新属于可审计基础；“被 agent 记住/转发”只有在能取得具体调用、引用或转介日志时才是观测值。公众号所称动态关键词矩阵和 agent 口碑网络仍是行业假说，不是已证实机制。
- **GEO 的因果证据边界已经可以关闭。** 基础 GEO 论文的“最高约 40%”来自固定实验环境，说明 already-retrieved content 的改写可改变呈现；它不证明真实平台的 organic discoverability、长期流量或成交增长。2026 年跨平台测量研究把 citation selection 与 absorption 分开，但主要是描述性比较；同期批判综述未发现长期、跨平台、对 organic discoverability 或下游行为稳定有效的技术。
- **服务商证明增量效果需要对照，而不是只报 visibility dashboard。** 最低可接受设计是预先固定 prompts 和主要指标，使用同时期 control/holdout 或分阶段上线，保持其他 SEO/PR/产品发布不变或显式建模，重复采样并报告方差、负结果和原始回答，再把 citation、referral、qualified lead 与 conversion 分开归因。没有对照的品牌 case study 只能标为观察性证据。
