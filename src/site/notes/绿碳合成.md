# 绿碳合成

绿碳合成是绿碳合成能源（绍兴）有限公司使用的业务简称。公开资料将其定位为可持续航空燃料（SAF）、生物柴油、生物石脑油等绿色燃油与化工原料的工艺研发企业。

## 技术与商业化边界

公司公开路线是面向生物质等原料的费托合成工艺，并计划通过中试、示范工程、工艺包和设备销售推进商业化。催化剂寿命、成本、碳减排和计划产能主要来自公司或融资方口径；中试完成、认证、稳定量产、客户采购和单位经济性需要分别核验。
