# ABot-Earth

ABot-Earth 是高德/Amap CV Lab 的生成式 3D Earth / 城市世界模型项目节点。它把卫星影像、文字提示和 3D Gaussian Splatting 连接起来，目标是低成本生成可漫游、可导出的公里级三维空间。

## 观察

- ABot-Earth 把 [[世界模型\|世界模型]] 从机器人动作后果预测扩展到城市级空间生成。这里的“世界”首先是可渲染、可编辑、可导入引擎的 3D 地块，而不是社会世界或机器人控制策略。
- 项目选择 3DGS 作为核心表达，使生成结果更接近实时渲染和引擎接入资产，而不是只停留在视频或图片层。它因此与 [[AI 建筑设计工具\|AI 建筑设计工具]]、数字孪生、游戏、XR 和低空经济的空间底座相邻。
- 与 [[World Labs\|World Labs]] 的持久 3D 世界路线相比，ABot-Earth 更依赖地理空间数据和城市级生成；与 [[MindSpace\|MindSpace]] 的空间数据库/空间记忆路线相比，它更偏三维空间内容生产和城市底图。
- [[WUDAPT\|WUDAPT]] 提供相邻的城市数据路线：ABot-Earth 侧重城市级 3D 生成，WUDAPT 侧重城市形态/气候分类；二者都把城市空间转成可计算对象。
- [[消费级空间相机\|消费级空间相机]] 提供小尺度互补路线：ABot-Earth 从遥感/地图生成城市级空间，消费级 3DGS 相机从现场捕获室内和个人空间。
- 对 [[具身智能数据基础设施\|具身智能数据基础设施]] 来说，ABot-Earth 提供的是“可生成的环境层”：如果城市、园区和建筑外部空间能被低成本转成可交互 3D 场景，就可能服务于机器人导航、低空飞行、自动驾驶仿真和应急演练。
- [[MILO\|MILO]] 补充了表示层问题：城市级 3DGS 或空间生成如果要进入编辑、仿真和工程流程，最终仍需要可靠、轻量、几何一致的网格或其他可操作表面表示。

## 边界

- “全球首个”“成本降至百分之一”“效率提升千倍”等属于作者或产品传播口径。技术报告和 Studio 能证明项目、方法与可交互入口存在，但不能单独完成对这些比较数字的独立审计。
- 城市级 3D 生成不等于物理可执行世界模型。它能提供空间几何和视觉底座，但不自动提供可用于机器人控制的接触、动力学、材料和任务反馈。

## 截至 2026-08-10 的公开制品答案

- **可核查**：技术报告、产品 Studio 和公开 GitHub 仓库均存在；因此 ABot-Earth 不是只有媒体概述的概念项目。
- **不可复现部分**：仓库当前主要提供说明、报告和展示材料；本轮未见完成训练/推理复现所需的实现、权重、数据、许可证和 release package。公开仓库存在不等于代码已开源。
- **判断边界**：可以记录作者报告的生成范围和质量指标，但成本“百分之一”、效率“千倍”只能标成第一方比较；不能据此推断单位城市的真实生产成本或对传统测绘流程的普遍替代。
- **重开条件**：出现稳定许可证下的可运行代码与模型/数据说明，或第三方以相同区域、质量阈值和人力成本对照复现。
