# BettaFish

BettaFish 是一个开源 AI 多 Agent 舆情分析助手节点。来源将其描述为通过多平台采集、多个分析 agent 和“辩论主持人”机制，自动生成结构化舆情分析报告。

## 观察

- BettaFish 的核心不是单一模型总结，而是把数据采集、情绪分析、观点提炼、趋势预测和辩论主持拆成多个 agent 角色。这使舆情分析更接近协作式分析工作流。
- 舆情分析的任务对象包括品牌口碑、危机公关、竞品动态和产品反馈。这些都是 [[智能社会治理\|智能社会治理]] 和平台治理中的常见信息环境问题。
- 多平台采集和多模态解析会带来合规边界：公开平台数据、评论区、短视频、内部业务数据和跨平台画像不能简单混在一起使用。
- 来源强调 GitHub star 数，但在 [[GitHub Star 信号污染\|GitHub Star 信号污染]] 背景下，star 只能作为来源口径，不应当直接等同于真实社区活跃、工具质量或安全可信。
- 如果 agent 用 BettaFish 这类工具做社会信号监测，需要保留采集范围、时间戳、平台规则、模型版本和人工复核记录。

## 边界

- 当前来源是工具推荐文章，未核验 GitHub 仓库活跃度、许可证、数据采集合规性或真实部署效果。
- 舆情分析报告不能直接替代人工判断，尤其是危机公关、公共治理和投资场景。
