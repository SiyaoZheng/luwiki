# AgentSociety²

AgentSociety² 是面向 [[可执行社会科学\|可执行社会科学]] 的一体化研究环境。它把 AI Social Scientists、Silicon Participants、社会仿真环境和研究流程放进同一个可运行系统，目标是让社会科学问题能够被构造、干预、运行和比较。

## 观察

- AgentSociety² 把 [[社会世界模型\|社会世界模型]] 从“模拟社会行为”推进到“执行研究流程”。系统不只是生成一群 agent，而是连接文献理解、假设生成、实验设计、仿真执行、结果分析和论文呈现。
- 它的关键结构是双角色：AI Social Scientists 在研究者侧组织流程，Silicon Participants 在被研究对象侧生成行为轨迹。这个设计让社会科学里的 AI 同时进入研究工具和研究对象。
- 系统把公共品博弈、囚徒困境、信任博弈、心理实验、社交媒体空间、事件空间、经济空间和移动空间等环境封装为可组合模块，使研究假设能被翻译为环境规则、干预程序和测量指标。
- 对 [[人本城市模拟\|人本城市模拟]] 而言，AgentSociety² 提供了相邻路线：前者从城市影像和 ABM 抽取人本行为，后者把城市移动、灾害响应和平台机制等社会过程放入可执行 agent 环境。
- [[遥感多智能体灾害预警\|遥感多智能体灾害预警]] 提供了灾害响应的传感器/环境侧样本：agent 不只模拟社会行为，也可以进入观测、早筛、专家分析和决策融合链路。
- [[Simile\|Simile]] 提供产业侧对照：同样使用生成式智能体模拟人类行为，但目标更偏客户、市场或受众反应预测，而不是研究流程本身。
- [[Emergence World\|Emergence World]] 提供长程运行对照：它强调 agent 在持续共享世界里的记忆、资源、治理和行为漂移，而 AgentSociety² 更强调把研究问题翻译成假设、实验和测量流程。两者都能扩展机制探索，但前者的跨模型示范结果和后者的硅基参与者输出都需要外部校准，不能直接当作现实社会的因果事实。

## 边界

- Silicon Participants 不能无条件替代真实人类被试。更稳妥的定位是机制探索、实验设计预演、边界情景生成和理论压力测试。
- 研究者仍需要保留问题选择、理论解释、伦理判断和外部效度评估；否则“可执行”会滑向自动化幻觉。
