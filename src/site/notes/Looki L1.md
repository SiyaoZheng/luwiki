# Looki L1

Looki L1 是一个可穿戴 AI 相机产品节点。它的观察价值不在于单次评测结论，而在于把“全天候第一视角/胸前视角记录、云端素材分析、自动回忆短片和多模态问答”组织成一种消费级 AI 记忆设备。

## 观察

- Looki L1 的核心不是普通运动相机，而是把间隔拍摄、录音、素材上传、自动筛选和 AI 总结组合成“记忆/灵感”工作流。
- 这种产品形态把 [[AI 记忆系统\|AI 记忆系统]] 从聊天和 agent 工作流带到可穿戴硬件：记忆的原材料不再只是文本，而是日常视频、音频、环境、食物和活动片段。
- “故事模式”显示 AI 硬件可以围绕数据采集节奏设计，而不是只在 App 里加一个聊天入口。硬件、拍摄频率、云端分析、自动删除和回忆生成共同构成体验。
- 评测暴露出的磁吸脱落、设备查找、网络连接和 App 引导问题说明：AI 硬件的瓶颈常常不是模型是否聪明，而是佩戴、找回、联网和可靠性这些基础体验。
- 全天候可穿戴记录会放大 [[AI Agent 安全\|AI Agent 安全]] 和隐私问题：设备可能拍到旁人、家庭空间、工作场景和敏感对话；自动上传和自动删除都需要更清晰的授权、留存和可审计机制。
- 与 [[消费级空间相机\|消费级空间相机]] 相比，Looki L1 更偏日常事件和个人记忆，不是三维空间资产采集设备；但两者都说明消费硬件正在变成现实世界数据入口。
- 与 [[AI 可穿戴上下文设备\|AI 可穿戴上下文设备]] 中的戒指、手链和吊坠相比，Looki L1 走的是影像/音频记忆路线；共同问题是如何把连续采集变成可控、可删除、可解释的个人上下文。
- 新增体验文强调了 Chat/Lifelog/For You 三类体验：用户可以向素材提问、按日历回看，并把一天的片段自动整理为高光。这强化了 Looki L1 的核心定位：不是拍摄设备，而是可查询的生活日志。
