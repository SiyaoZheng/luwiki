# 上海交通大学

上海交通大学是教育部直属并与上海市共建的高校。本页是学校级父机构节点，不把校内平台、学院、实验室或校友公司并入大学本体。

## 组织层级与关系

- [[上海交通大学网络信息中心\|上海交通大学网络信息中心]]是校内网络安全、信息化与计算服务部门；[[致远一号\|致远一号]]是校内智算平台。
- [[OpenClaw 上海交大课堂部署\|OpenClaw 上海交大课堂部署]]把学校、网络信息中心、致远一号和 OpenClaw 项目连接为一次教学部署事件；它不等于学校拥有项目知识产权。
- 36氪履历把[[刘凌志\|刘凌志]]的博士经历连接到上海交通大学。截至 2026-08-10，本轮仍未找到可唯一匹配的学校人物页、校友页、学位记录或学位论文，因此该人物—学校边保持 C 级，不能据此连接凌川科技。仅在校方或学位档案出现时升级。

## 边界

同校、校内部署或校友经历不能推出学校投资、公司背书、师生关系或知识产权归属。
