# 2018 镁伽机器人 A轮融资

[[镁伽机器人]]公开材料把 2018 年 A 轮描述为愉悦资本领投、[[明势资本]]等机构跟投。2019 年博世创投领投后续轮次、2022 年高盛资产管理参与 C 轮，均是独立事件。

机构名称与[[曾颖哲]]的前雇主履历发生重叠，但不同年份和业务单元不能证明他促成后续融资。具体基金、股比和董事席位未披露。
