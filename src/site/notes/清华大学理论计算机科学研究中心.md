# 清华大学理论计算机科学研究中心

清华大学理论计算机科学研究中心是[[清华大学交叉信息研究院\|清华大学交叉信息研究院]]体系内的研究机构。清华官方记录其由[[姚期智\|姚期智]]回国任教后建立。

## 关系类型与证据

- `中心—研究院`：现行组织层级由交叉信息研究院官方材料支持。
- `姚期智—中心`：创办/领导关系由清华官方成立公告支持。

## 边界

中心不是独立大学或公司；与中心有关的学生、教师和创业者仍须逐人核验学籍、任职或导师关系。
