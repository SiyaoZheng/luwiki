# 中国人民大学信息学院

中国人民大学信息学院是[[中国人民大学\|中国人民大学]]的教学科研单位，覆盖计算机、信息管理、数据与商务智能等方向。

## 与当前实体的关系

- 境瞳科技团队来源被公开报道连接到信息学院及社会计算研究积累；当前公司关系仍主要是媒体证据。
- 学院科研目录列出“社会网络智能计算实验室”等官方节点，WAMDM 官网也确认学院内部的社会计算研究方向；但没有确认境瞳科技报道所称“中国人民大学社会计算与社会智能实验室”这一标准名称。名称不同的团队不合并。

## 边界

学院研究方向和团队来源不能自动推出公司是校办企业、获得学院投资或拥有独家技术授权。
