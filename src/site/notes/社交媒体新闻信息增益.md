# 社交媒体新闻信息增益

社交媒体新闻信息增益指可靠新闻内容进入用户日常信息流后，对时事知识、真实新闻识别、信念准确性和媒体信任产生的正向效果。它提供了虚假信息治理的建设式路径：不只是减少坏信息，也要增加好信息的可见度。

## 观察

- Nature Human Behaviour 研究显示，在法国和德国的 Instagram/WhatsApp 田野实验中，要求用户关注可靠新闻账号两周，可以提升时事知识和真实新闻意识。
- 该干预提升的是 belief accuracy，尤其是让人更愿意相信真实新闻，而不是简单让人更怀疑假新闻。这对 [[虚假信息纠正\|虚假信息纠正]] 很重要：公共理性的修复不只是纠错，也包括恢复对真实信息的识别和信任。
- 研究没有显著提高主观“我更懂新闻”的自信，也没有显著改变政治兴趣或情感极化，说明小剂量可靠新闻供给可能在不制造过度自信的情况下提升事实知识。
- 对 [[智能社会治理\|智能社会治理]] 来说，这是一种供给侧信息治理：平台和新闻机构可以通过稳定、低成本、持续出现的可靠信息改善公共事实环境。
- 与 [[社交媒体注意力资本\|社交媒体注意力资本]] 相比，新闻信息增益关注的不是谁更能获得互动，而是可靠公共信息能否穿透娱乐和社交噪音。

## 边界

- 研究效果被作者描述为微小但真实，且发生在法国/德国、Instagram/WhatsApp 和两周干预场景中；迁移到微信、小红书、微博、TikTok 或 YouTube 需要重新检验。
