# PixVerse

PixVerse 是 [[爱诗科技\|爱诗科技]] 开发的 AI 视频产品与平台，正在把产品叙事扩展到实时 [[世界模型\|世界模型]] 和 [[神经游戏引擎\|神经游戏引擎]]。它的关键变化不是“视频更好看”，而是视频从一次性输出变成可持续响应用户输入的交互环境。

## 观察

- PixVerse R1 把视频生成从固定长度 clip 推向连续、可交互、状态化的视频流。官方称 R1 可以实时响应用户输入，并把文本、图像、音频和视频作为统一 token stream 处理。
- PixVerse Game 把实时视频模型接入游戏创作：创作者定义规则、目标、玩法和世界观，视觉世界、叙事语气和角色呈现则在交互中实时生成。
- 这条路线把游戏分成三层：抽象 game mechanics、实时生成的 world expression、以及协调二者的 AI agent orchestration。它说明 AI-native game 不只是 NPC 会说话，也可能改变渲染和内容生产管线。
- 2026 年 7 月披露的整体 C 轮口径属于 [[爱诗科技\|爱诗科技]]，不是 PixVerse 产品自身融资；公司页再连接独立融资事件与资本端点。该事件支持 [[世界模型创业热\|世界模型创业热]] 中的一个观察：视频模型公司正在把“实时世界模型”作为下一阶段融资和产品叙事。
- PixVerse Game 仍应视为早期研究/探索系统。官方 deep dive 也承认延迟、类型泛化和每 session 计算成本仍是限制，不能直接等同于成熟商业游戏引擎。
- [[Emu Video\|Emu Video]] 提供了相邻的短视频生成路线：从文本/图像生成 4 秒 clip 与 PixVerse 的实时世界模型叙事不同，但共同推动设计素材从静态图走向时间化表达。
- R1 已有公开 Web 体验和公司宣布的 shared-world/合作 API 路径；这使它不同于纯论文 demo。但 Game Engine 官方仍将自身定义为 early-stage research system，并明确说量化 benchmark 尚待后续。

## 截至 2026-08-10 的答案与边界

- **R1 已上线，Game Engine 尚未成为稳定生态**：R1 有 Web 和有限合作路径；Game Engine deep dive 则自称早期研究系统，承认快节奏延迟、有限类型泛化和高会话成本。长程状态仍会漂移。升级为成熟创作者平台至少需要公开编辑器/SDK 的稳定版本、可迁移项目、创作者留存、长会话失败率和第三方作品生态。
- **没有可复现独立 benchmark**：官方“technical”页面是公司作者的产品/研究说明，不是同行评审论文，也未提供权重、代码和可复现实验协议；官方还写明量化 benchmark 将在系统成熟后补充。下一触发条件是公开论文或技术报告附数据/评测协议，且由第三方在相同会话长度、分辨率和交互条件下复现。
- **规模证据分层后仍缺商业核心指标**：公司称全球注册用户超过一亿；Google Play 显示 5000 万+下载、约 441 万评价和 4.5 星。前者是公司口径，后者是 Android 分发指标；两者都不等于 DAU/MAU、R1 或 Game Engine 使用量、付费转化、留存和 ARR。本轮来源范围内未找到这些公开数据。
- **已有平台规则，数据与儿童安全审计仍缺**：条款、隐私政策和社区规范覆盖年龄、输入输出权利、下架与内容限制，但本轮未找到训练语料许可证清单、独立版权审计、R1/Game 专项红队或儿童安全评测。发布这类审计或监管/法院对其训练与生成行为作出明确认定时再更新。
