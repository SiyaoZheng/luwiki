# 知行科技与Mobileye SuperVision合作

[[知行科技]]港交所招股书披露其与[[Mobileye Global Inc.]]合作，把 SuperVision 用于极氪和 Polestar 车型。知行科技采购基础域控制器，并承担系统、机械和光学集成、测试与验证；Mobileye 保留相关知识产权。

协议为非排他安排，不能把供应与集成关系写成合资、共同控制、知识产权转让或永久排他绑定。
