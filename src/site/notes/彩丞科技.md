# 彩丞科技

彩丞科技是一家围绕 3D 光学材料、立体视觉产品和印刷包装应用的公司品牌。公开材料对应的法律主体另建为 [[上海彩丞新材料科技有限公司\|上海彩丞新材料科技有限公司]]，不作为品牌别名。它的稳定观察价值不在“校友访谈”本身，而在于传统印刷包装行业中也存在材料、光学、防伪和视觉体验驱动的技术创业路径。

## 产品与应用

- 以 3D 光学材料作为基材，通过高精度 UV 印刷实现裸眼立体视觉效果。
- 应用场景包括包装、广告展示、装饰材料、文化用品、工艺礼品和防伪。
- 技术叙事强调 360 度全方位立体效果、图像稳定、材料规格多样、食品级环保材料和防伪能力。

## 三同关系线索

- 核心人物是 [[柯罗马\|柯罗马]]。清华社科学院文章提供其创业转向和清华学习经历；36氪项目页和沃衍资本项目页提供公司产品、融资和投资方外部线索。
- 同校关系不能只写“武大/清华系”，而应拆成两类：武汉大学提供哲学与软件工程训练，清华经管/社科学院经历提供创业氛围和商业训练线索。
- 投资方关系统一经 [[彩丞科技历史融资\|彩丞科技历史融资]] 中转；这些是资本关系，不等同于同学或同事关系，也不建立投资机构之间的直接边。

## 截至 2026-08-10 的证据答案

- “是否存在专利”已经得到肯定答案：国家知识产权局专利 CN108954227B 显示 [[上海彩丞新材料科技有限公司\|上海彩丞新材料科技有限公司]] 是“一种可改变光斑大小的透镜组件”的专利权人，2018 年申请、2024 年授权。上海市科委项目名单还出现该主体的 Safelight 防眩光照明 PET 材料；这使“有光学材料/透镜研发活动”不再只依赖校友访谈。
- 这些证据不能回答产品销量和客户效果。专利证明权利要求与授权记录，项目名单证明项目入选；二者都不证明量产、结题验收、食品级/防伪性能、市场份额或具名客户采用。
- 当前官方企业登记档案、现行股权/经营状态、公司自有产品目录、公开采购/验收和客户一手案例仍未取得。因此公司成立时间与融资保留商业项目页口径，客户和性能主张不升格为事实。
- 重新开启经营/产品判断的条件已固定为现行登记档案、产品规格与检测报告、公开采购或客户验收、带样本和基线的性能测试。检索中出现名称相近的浙江法律主体；在没有工商沿革或公司公告前，不与上海主体合并，也不把其专利计入本页。
