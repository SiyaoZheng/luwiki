# 武汉大学

武汉大学是教育部直属综合性大学。本页作为学校级教育网络节点。

## 与当前实体的关系

- [[柯罗马\|柯罗马]]的武汉大学哲学与软件工程训练由武汉大学印包系全国校友会访谈支持。截至 2026-08-10，本轮未取得教务/学位记录，因此确认公开校友叙述，不补写具体学位与年份；仅在可唯一匹配的学校档案出现时升级。
- 彩丞科技与武汉大学的关系经柯罗马个人教育经历中转，不是学校投资或校办企业关系。

## 边界

跨专业学习不能自动推出同学、导师或创业团队来自武汉大学；所有具体人物边须逐项核验。
