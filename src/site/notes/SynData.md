# SynData

SynData 是 [[灵初智能\|灵初智能]] / PsiBotAI 发布在 Hugging Face 的真实世界多模态人类操作数据集节点。

## 关系与边界

- **发布者**：[[灵初智能\|灵初智能]] 的 PsiBotAI 组织账号。
- **采集与平台关系**：数据集与 [[Psi Data\|Psi Data]]、[[Psi-SynEngine\|Psi-SynEngine]] 处于同一人类数据路线，但公开数据集、采集平台和采集引擎不是同一实体。
- **模型关系**：公司材料把该数据路线与 [[Psi-R2\|Psi-R2]]、[[Psi-W0\|Psi-W0]] 的训练联系起来；具体训练切分、许可和数据清洗仍应回到数据卡与模型文档。
- **边界**：媒体所谓“全球最大”“Trending 第一”是带时间的口径，不能替代数据集文件、许可、任务分布和版本审计。
