# 王长虎

王长虎是 [[爱诗科技\|爱诗科技]] 创始人兼 CEO。爱诗科技官网和财联社材料把其创业方向连接到 AI 视频生成产品 [[PixVerse\|PixVerse]]。

## 关系网络

- **创业**：[[爱诗科技\|爱诗科技]] 创始人兼 CEO；[[PixVerse\|PixVerse]] 是公司核心产品。
- **前任职**：财联社称其曾任 [[字节跳动\|字节跳动]] 视觉技术负责人，参与视觉算法平台和相关产品建设。
- **边界**：当前来源不足以把爱诗科技整个团队聚合的清华、北大、中科院、微软亚洲研究院、快手、腾讯背景具体分配给王长虎本人。

个人前任职不等于字节跳动投资爱诗科技、授权技术或与现团队存在整体迁移关系。
