# 爱诗科技 2026 C轮融资

爱诗科技 2026 C 轮融资由 3 月完成的 C 轮和 7 月完成的 Series C extension 构成。公司一手公告确认 3 月 C 轮由 [[鼎晖投资\|鼎晖投资]] 领投；7 月扩展轮把 [[阿里巴巴\|阿里巴巴]] 列为新增投资者之一，并未称其领投。

## 截至 2026-08-10 的轮次答案

| 日期/阶段 | 一手证据支持的角色 | 金额口径 | 边界 |
|---|---|---|---|
| 2026-03-12 C 轮 | [[鼎晖投资\|鼎晖投资]]领投；鼎晖公告具体列鼎晖香港基金、[[鼎晖VGC\|鼎晖VGC]]、鼎晖百孚 | 公司和鼎晖公告未披露金额；媒体称 3 亿美元 | 未公开签约法律实体、各方出资额、股比和董事安排 |
| 2026-07-14 Series C extension | [[阿里巴巴\|阿里巴巴]]是新增投资者之一；iGlobe Partners、OCBC LionX Ventures 为既有投资者 | 整个 Series C 累计 4.39 亿美元；第一财经写 29.8 亿元人民币 | 官方没有使用 `C+` 或“阿里巴巴领投”，也没有披露扩展轮单独金额 |

第一财经“C+ 轮由阿里巴巴领投”是 C 级媒体说法，不能覆盖交易当事方公告。PixVerse 官方只确认阿里巴巴领投过 2025 年 6000 万美元 Series B；该历史角色不能迁移到 2026 年扩展轮。

## 主体与图谱边界

- **组织端点**：[[爱诗科技\|爱诗科技]] → 本融资事件 → [[鼎晖投资\|鼎晖投资]]、[[鼎晖VGC\|鼎晖VGC]]、[[阿里巴巴\|阿里巴巴]]。产品 PixVerse 只经公司节点连接本事件，不在产品页建立资本边。
- PixVerse 服务条款把全球服务运营方写为 `AIVORA PTE. LTD.`；这不证明它就是 C 轮融资接收主体、爱诗科技的境外控股公司或中文法律实体。交易公告未披露完整合同主体，故不猜测法律载体。
- **证据等级**：A/B：PixVerse 公司公告、鼎晖投资公告和产品条款；C：第一财经对 3 亿美元、29.8 亿元、`C+` 和阿里巴巴领投的报道。
- **不能推出**：4.39 亿美元/29.8 亿元不是 7 月扩展轮单独金额、估值或阿里巴巴出资额；参投也不等于投资方对模型能力、用户规模、收入或商业效果作独立验证。

## 重开条件

- 只有公司或投资方补充公告、投资协议、监管/工商材料披露 `C+`、领投角色、单笔金额、股比、董事安排或融资法律主体时，才升级相应字段；此前维持“阿里巴巴为扩展轮新增投资者之一”。
