# 北京大学

北京大学是综合性高校。本页作为学校级父节点，区分院系、研究机构、学籍和商业案例传播关系。

## 与当前实体的关系

- [[北京大学光华管理学院\|北京大学光华管理学院]]是校内学院节点；王宁的光华 MBA 经历由学院案例页面支持，人物关系在学院层承接。
- 王肇凯本人公开简历称其于 2019–2022 年取得北京大学经济学双学士学位；北京大学国家发展研究院官网确认，该项目面向校内非经管专业本科生开设。两条证据共同确认项目机制与本人公开履历相容，但不等于学校对该人的授位记录已经公开。

## 截至 2026-08-10 的核验结论

- **已回答**：NeuraInsight 团队资料里的“北大经济学双学位”可上溯到王肇凯本人简历，不再只是非官方项目数据库的转述。
- **证据等级**：人物教育经历为“本人公开履历”；北大一侧仅确认双学位项目机制，没有检索到可对应王肇凯的校友人物页、授位名单或个体学位记录。因此页面不把它写成“北大已核验授位”。
- **更新触发**：只有北京大学发布可对应的校友/人物记录，或当事人公开可验证的学校学位材料时，才把证据等级提升为校方交叉确认。

## 边界

同校、商学院案例或校友身份不能推出学校投资泡泡玛特、对公司背书或具体私人关系。
