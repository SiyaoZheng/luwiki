# 香港科技大学

香港科技大学是 1991 年成立的香港研究型大学。本页与[[香港科技大学（广州）\|香港科技大学（广州）]]分别建模。

## 与当前实体的关系

- [[严朝旭\|严朝旭]]的 HKUST 博士答辩记录与香港科技大学（广州）官方报道相互支持；后者明确把他写为香港科技大学博士毕业生。该人物边不能与港科大（广州）的独立学籍体系混写。
- 十镜科技创始人的香港高校博士经历当前指向香港中文大学而非港科大，不能混同“港中文”和“港科大”。
- [[唐本忠\|唐本忠]]的学校官方履历记载其自 1994 年起任职香港科技大学；这是既往雇佣关系，不等于其现任机构与港科大存在隶属关系。

## 边界

港科大与港科大（广州）属于协同办学体系但具有独立法律主体；共享品牌不能替代具体校区、学籍和聘用关系。
