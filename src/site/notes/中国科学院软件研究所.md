# 中国科学院软件研究所

中国科学院软件研究所是[[中国科学院\|中国科学院]]所属研究所，成立于 1985 年，聚焦计算机科学理论与软件高新技术。

## 与当前实体的关系

- [[姜大昕\|姜大昕]]的中科院软件所经历来自公开媒体履历。截至 2026-08-10，本轮未找到研究所人物/校友页、学位论文元数据或可唯一匹配档案，因此关系保持媒体等级，不补写学位、导师和时间；仅在研究所或学位档案出现时升级。
- 研究所与中国科学技术大学同属中科院体系，但二者没有因此形成直接上下级边；各自只连接共同上级 [[中国科学院\|中国科学院]]。

## 边界

研究所训练经历不能自动推出同事、同门或研究所对创业公司的投资与技术授权。
