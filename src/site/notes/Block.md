# Block

Block, Inc. 是历史上以 Square 品牌和公司名称广为人知的金融科技公司。本页在当前人物网络中只承担[[杨骏]] 2014—2015 年职业端点；品牌、历史公司名称与具体产品仍须按时点区分。

达达证券文件称杨骏 2014—2015 年担任 Square 增长工程团队负责人，负责用户增长策略与实施。该履历不证明 Square／Block 与[[达达集团]]或[[线性资本]]存在股权、客户、投资或合作关系。
