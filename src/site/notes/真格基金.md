# 真格基金

真格基金是聚焦种子期和早期创业项目的投资机构。

## 身份与层级

- 真格基金是投资品牌节点；具体基金、管理人和出资主体需要按每笔交易文件穿透。

## 当前网络角色

- [[境瞳科技天使轮融资\|境瞳科技天使轮融资]] 与 [[源策未来种子轮融资\|源策未来种子轮融资]] 将真格基金列为资本端点。

## 证据等级与边界

- **证据**：A：机构官网；C：媒体融资披露。
- **不能推出**：共同投资不等于与其他机构形成联盟，也不能推出董事席位、控制权或技术验证。
- 与其他机构共同出现在同一轮融资中，只形成融资事件的共同端点，不自动构成机构联盟、联合控制或人物私人关系。
