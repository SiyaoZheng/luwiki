# 镁伽机器人

镁伽机器人（MegaRobo，现主要使用“镁伽科技”品牌；境内运营主体包括北京镁伽机器人科技有限公司）是一家面向智慧实验室与智能制造场景的机器人自动化和自主智能体解决方案企业。

## 产品与产业边界

公司从运动控制和协作机器人起步，当前官网强调感知、构思、执行闭环，以及生命科学、化工、食品、农业、集成电路和新能源等行业。自主智能体、效率提升和客户采用多为公司口径，需按具体产品、实验任务、部署规模和客户验收核验。

## 投资与旧页碰撞

- [[2018 镁伽机器人 A轮融资]]记录明势资本跟投。
- 在[[物理 AI 创业生态]]中，镁伽补入“实验执行与自动化”层；与深度原理的科学决策/材料研发智能体形成可比较的上下游位置，但未发现双方直接合作。
- 2019 年博世创投领投后续轮次、2022 年高盛资产管理联合领投 C 轮，与[[曾颖哲]]早年任职博世和高盛形成机构名称重叠；不同业务单元和年份不能据此推断他促成交易。
