# Simile

Simile 是由 [[Joon Sung Park\|Joon Sung Park]] 等人创立的人类行为模拟公司节点。它把 Stanford Generative Agents / Smallville 研究所展示的生成式智能体路线，从论文中的虚拟小镇推进到面向受众、市场或群体反应的商业化模拟工具。

## 观察

- Simile 的核心问题不是“让一个 agent 更像人”，而是把许多基于真实数据训练的虚拟个体组合成可运行的群体模拟系统。
- 这条路线把 LLM 的能力理解为模拟引擎：模型不只生成回答，也可以承载多样化人格、互动规则、社会关系和反事实实验。
- 与 [[AgentSociety²\|AgentSociety²]] 相比，Simile 更像商业化社会模拟产品；AgentSociety² 更偏一体化可执行社会科学研究环境。
- 与 [[社会世界模型\|社会世界模型]] 的关系很直接：Simile 试图把个体决策和群体反应组织成可干预、可重新编译的世界状态。
- 对 [[可执行社会科学\|可执行社会科学]] 来说，Simile 是产业侧样本：社会仿真开始被包装为市场研究、受众预测和策略测试工具；没有真实数据校准时，不能主张外部效度。

## 边界

- 截至 2026-08-10，Simile 官网与创始人公开履历足以确认公司、研究路线和人物角色；公开官网未提供可回读的定价、完整产品文档、具名客户验证协议或外部校准报告，融资额与投资人仍是二次披露口径。现有证据只支持“商业化社会模拟公司”这一定位，不支持把预测有效性写成已验证能力；仅在公司融资公告、正式产品文档、可核验客户案例或独立校准研究出现时重开。
- 模拟人群的结果不是现实人群事实；它最多是机制探索、反事实草案或决策辅助，不能替代真实实验和调查。

## 三同关系线索

- [[Joon Sung Park\|Joon Sung Park]] 本人 CV 将其 2025 年 6 月起的职务写为 Simile co-founder and CEO；Sequoia 访谈也以 founder/CEO 身份介绍他。这使公司—人物边达到可核验标准。
- Park 的 Stanford University、University of Illinois Urbana-Champaign 和 Swarthmore College 学位关系只在人物页建立，本公司页不链接高校。三段履历来自本人 CV，尚不是校方学籍记录。
- Generative Agents 论文确认 Park 与 Joseph C. O'Brien、Carrie J. Cai、Meredith Ringel Morris、Percy Liang、Michael S. Bernstein 的共同作者关系，但论文署名不能自动证明共同创办 Simile。本轮只为商业角色逐项闭合的 Park 建人物节点。

## 不能推出

论文共同作者关系不能自动等同于共同创办 Simile；个人在 Stanford 的研究训练也不能推出 Stanford University 投资、孵化、许可或背书 Simile。当前建立的是 Simile—Joon Sung Park 与 Park—学校两组分开的事实边。
