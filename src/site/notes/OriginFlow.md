# OriginFlow

OriginFlow（中文品牌“渊澈太初”）是一家位于北京的 [[具身智能数据基础设施\|具身智能数据基础设施]] 创业公司。公司官网把自身定位为 Physical AI 的真实世界数据基础设施提供方，目标是把人类操作过程转化为可供机器人训练和评估的数据。当前公开产品包括 Origin Kit 和 Origin Data；截至 2026-08-10，技术能力、产品状态和商业化规模按本页的日期化证据等级记录。

## 数据链路与产品

公司公开的数据链路可以概括为：

**人类自然操作 → Origin Kit 同步采集 → NeuroScale 组织和解码多模态信号 → Origin Data 质检、对齐、标注和交付 → 机器人训练与评估数据**

### NeuroScale

NeuroScale 是 OriginFlow 对其数据采集范式的命名。当前官网称它同步使用表面肌电（sEMG）、IMU 和视觉，面向动作意图、连续手部运动、三维姿态、主动用力和接触动态等变量。

sEMG 记录的是与肌肉激活相关的外周生理信号，不是脑电，也不是对中枢“意图”的直接读取。它可能比单纯视频更接近发力和动作生成过程，但“从神经意图源头采集”仍属于公司及交易方的解释框架。

### Origin Kit

Origin Kit 是公司官网公开展示的采集硬件组合，包括神经肌电腕带、第一视角采集设备和控制单元。官网称它能够同步记录 sEMG、IMU 和第一视角视频。

### Origin Data

Origin Data 面向采集后的质量检查、多模态时间对齐、标注、存储和数据集交付。它说明公司的商业对象不只是腕带硬件，也包括把现场记录加工成训练资产的数据运营流程。

### PULSE

2026 年 5 月融资材料提到名为 PULSE 的神经肌电基础模型；投资方出品播客的节目说明将其展开为 `Pre-training Universal Lightweight sEMG Encoder`。截至 2026-08-10，公司官网仍未出现 PULSE，也没有公开其结构、训练数据、模型卡、论文、权重、benchmark 或 demo。因此名称与展开式只能按公司关联方口径记录，不能把手部姿态、用力或触觉重建性能视为已核验事实。

### 研发与交付能力的公开面

公司招聘页公开客户解决方案、硬件、算法、嵌入式、VLA/多模态学习和数据平台六类方向。职位说明支持公司正在建设多传感器同步与标定、视觉/深度/IMU 融合、大规模数据平台以及“有效数据增益”评测能力；招聘目标不能反推这些组件已经完成或达到生产性能。

客户解决方案职位提到真实部署、数据接口和项目交付，VLA 职位把跨硬件、仿真与灵巧遥操作的采集闭环写作研发任务。公开面仍只有预约 demo、招聘需求和合作公告，没有可核验的付费合同、中标记录、客户侧生产报告、续费、收入或单位数据成本；官网所称跨本体技能迁移也没有公开 benchmark。

## 专利申请说明了什么

北京渊澈太初智能科技有限公司有两项与公开产品路线直接相关的专利申请：

- CN122220678A 以 IMU 辅助识别并抑制动态场景中的肌电运动伪迹。
- CN122388589A 围绕干电极与皮肤接触阻抗变化，自适应调整采集系统参数。

这些申请披露了团队围绕可穿戴肌电采集中的动态干扰和电极稳定性提出的技术方案，与 Origin Kit 的公开工程路线一致。但专利申请不是授权结论，也不能证明方案已经实现，更不能证明重建精度、跨人群泛化、量产可靠性或机器人任务收益。

## 为什么这个公司值得观察

- OriginFlow 把机器人“数据荒”从视频数量问题推进到身体过程问题：手部动作、肌肉激活、发力、接触和第一视角需要被同步记录。
- 它与 [[手亿科技\|手亿科技]]、[[灵初智能\|灵初智能]]、[[Ego-NeuroLoop\|Ego-NeuroLoop]] 形成可比较路线：共同把人类操作转成训练数据，但传感器组合、身体信号和目标变量不同。
- 公开证据尚未覆盖的工程环节不只在腕带或模型，还包括同步误差、信号质量、任务设计、真值标定、跨人/跨环境复用、数据权利和长期场景运营；对应重开条件见下表。
- 这也是一个 [[人类活动数据\|人类活动数据]] 治理问题。若工业工人或家庭服务参与者的操作被持续转化为训练资产，知情同意、补偿、撤回、二次使用、跨境处理和技能数据收益分配都会成为基础设施的一部分。官网现有隐私政策是网站/服务通用政策，没有单列技能数据采集参与者；服务条款的准据法字段仍保留模板占位符。它们不能替代具体采集项目协议，也不能据此反向推断公司已经违规。
