# 复旦大学

复旦大学是综合性高校。本页作为学校级父机构节点，区分大学、学院、重点实验室和课题组。

## 与当前实体的关系

- [[复旦大学计算与智能创新学院\|复旦大学计算与智能创新学院]]是校内学院节点；肖仰华的教授任职由学院人物页承接。
- [[复旦大学知识工场实验室\|复旦大学知识工场实验室]]与[[上海市数据科学重点实验室\|上海市数据科学重点实验室]]是两个不同科研节点。
- [[陆奇\|陆奇]]的复旦学习经历已由复旦大学校友会确认：计算机 80 级本科、84 级硕士，毕业后曾留校任教；该关系不再停留在媒体履历层。

## 边界

共同负责人和同一校址不能把两个实验室合并；学校任职也不代表所有个人观点为校方立场。
