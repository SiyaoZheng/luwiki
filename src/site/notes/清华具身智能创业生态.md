# 清华具身智能创业生态

[[清华大学\|清华大学]]相关的具身智能创业生态至少包含三类节点：学生/教师创业团队、校友会和路演平台、以及投资和产业协作网络。

## 已出现节点

- [[OriginFlow\|OriginFlow]]：[[秦深涛\|秦深涛]] 是[[清华大学车辆与运载学院\|清华大学车辆与运载学院]] 2023 级在读博士生。[[清华 x-lab\|清华 x-lab]] 还记录了他更早的“元信号数据科技”项目，说明神经信号与具身智能方向在 OriginFlow 成立前已经进入清华创业平台；这不等于[[清华大学\|清华大学]]投资、技术背书或拥有公司知识产权。
- [[LiberAI\|LiberAI]]：[[刘松铭\|刘松铭]]的清华计算机系本科生和导师关系已由校方页面核验。公司与学校的关系只经创始人人物节点中转；论文作者、导师和清华同学不能自动写成 LiberAI 团队。
- 手亿科技：公开报道给出许展玮、于进洋姓名和“清华系团队”背景，但当前缺少足以独立建人的公司或学校一手页面。本生态页仅保留媒体画像文字，不建立公司到本生态页、学校或院系的 wikilink。
- [[清创荟世界模型论坛\|清创荟世界模型论坛]]：清华大学上海校友会三创服务平台围绕世界模型组织前沿论坛和科创路演。
- [[以人为中心的具身模型范式\|以人为中心的具身模型范式]]：冯瑶、刘淼与清华人工智能学院相关，呈现学术研究走向创业的路径。
- 第 6 批图谱类来源把银河通用、星动纪元、星海图、千诀科技、原力灵机、零次方机器人和 AtomBite.AI 放在同一张“清华系具身智能”地图中，显示清华背景正在被媒体组织成一个创业生态叙事。

## 初步判断

清华具身智能生态不是单纯的“学校背景”标签，而是由人才、基金、校友平台、地方产业资源和媒体叙事共同组成。当前来源集中在几个关键词上：[[具身智能数据基础设施\|具身智能数据基础设施]]、[[世界模型\|世界模型]]、[[以人为中心的具身智能\|以人为中心的具身智能]]、整机与“大脑”分工、垂直场景落地，以及供应链机会。

图谱类来源给出的“7 家公司、250 亿融资”等数字适合作为媒体叙事线索，暂不作为硬事实沉淀；后续需要逐家公司用工商、融资数据库、公司公告或可信媒体核验。

OriginFlow 还提示“清华系”需要拆成不同关系：[[清华大学车辆与运载学院\|车辆学院]]在读学籍、[[清华 x-lab\|清华 x-lab]]活动、[[水木清华校友种子基金\|水木清华校友种子基金]]投资和清华相关行业活动是四种不同连接。它们共同构成生态入口，但不能被压缩成私人校友关系或校方背书。

## 机构节点

- [[清华大学\|清华大学]]：父机构节点。
- [[清华大学车辆与运载学院\|清华大学车辆与运载学院]]：秦深涛在读学籍的直接院系节点。
- [[清华大学计算机科学与技术系\|清华大学计算机科学与技术系]]：刘松铭本科生和导师关系的直接院系节点；[[LiberAI\|LiberAI]]只经刘松铭中转。
- [[清华 x-lab\|清华 x-lab]]：元信号数据科技项目进入创业教育平台的节点。
- [[水木清华校友种子基金\|水木清华校友种子基金]]：投资 OriginFlow 的校友资本节点；不是[[清华大学\|清华大学]]本体。

## 关系建模规则

- 公司背景按“公司→具名创始人→本人学籍/任职院系→大学”连接，不能把创始人履历压成公司—学校组织边。
- 媒体只称“团队来自某校”且没有足以建页的具名人物时，保留为媒体叙事文字，不建立公司—学校 wikilink。
- 校友论坛、创业教育、投资、路演和课程活动分别使用平台、基金或事件节点，不伪装成学籍、师承或共同任职。

## 截至 2026-08-10 的证据分级

“清华系”不是单一身份，当前团队清单应按关系证据而不是媒体分组来读：

| 层级 | 当前可写结论 | 仍不能推出 |
|---|---|---|
| 人物—院系关系已由校方或学院材料核验 | [[OriginFlow\|OriginFlow]] 经[[秦深涛\|秦深涛]]连接车辆学院；[[LiberAI\|LiberAI]]经[[刘松铭\|刘松铭]]连接计算机系 | 公司由清华投资、校方技术背书、导师或同学自动属于创业团队 |
| 公司/技术节点存在，但“清华关系”仍主要来自媒体 | 星海图、原力灵机和手亿科技可以作为公司或技术观察对象 | 在缺少具名人物与校方/公司一手材料时，把公司接到清华机构图谱 |
| 仅有图谱型来源列举 | 银河通用、星动纪元、千诀科技、零次方机器人、AtomBite.AI | “七家公司”“250 亿融资”或完整清华团队名单已经逐条核实 |

因此，原来的“逐条核验团队清单”已经有了可执行答案：本页只把第一层写成确定图谱边；第二、三层保留为来源线索，待具名人物、校方/公司材料和融资事件级证据出现后再升级。

## 组织关系的已核验样本

[[OriginFlow\|OriginFlow]] 已提供一条足够清晰、但不能泛化给其他团队的路径：在读学籍经人物和院系中转，创业教育经[[清华 x-lab\|清华 x-lab]]，资本关系经[[OriginFlow 融资与 NeuroScale\|融资事件]]连接[[水木清华校友种子基金\|水木清华校友种子基金]]，产业合作连接[[联想新视界\|联想新视界]]，校友论坛/路演则由[[清创荟世界模型论坛\|清创荟世界模型论坛]]承接。这回答了“投资、产业试点、校友平台如何区分”的问题；其他团队是否覆盖这些关系，仍须逐项补证，不能由一个案例外推。

## 技术标签的功能校准

- **世界模型**至少要说明 action/state 接口、预测对象和下游用途。LiberAI 的公开叙事强调 physical action 到 state transition；媒体列举的原力灵机路线可以进一步用 action-conditioned learned environment 理解，星海图则主张 WAM 与 VLA 融合。后两者的性能和清华关系仍不能因媒体同图列举而升级为事实。
- **数据基础设施**不是世界模型的同义词。[[OriginFlow\|OriginFlow]] 的核心是神经肌电、IMU、第一视角视觉的采集与处理链，不能为了纳入热门标签而改写成世界模型公司。
- **人本具身**指把人的可观察状态、反馈、授权、纠正和长期关系纳入系统设计；它不等于已经验证了意图读取、情绪识别或完整 Human Model 因果链。该边界由[[以人为中心的具身智能\|以人为中心的具身智能]]统一维护。

由此，原来的三个泛化待补充项已分别转为：证据分级矩阵、组织关系中转规则和技术功能映射。页面仍可继续增加新公司，但新增节点必须先满足相应证据层级。
