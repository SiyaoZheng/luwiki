# 金融数据 MCP

金融数据 MCP 是把行情、K 线、技术指标和图表数据包装成模型可调用工具的接口路线。它的知识对象不是“某个策略会赚钱”，而是金融数据如何进入 agent 工具链，以及这个过程带来的凭据、时效、合规和审计边界。

## 观察

- MCP 让金融数据从人工查看的终端界面变成 agent 可调用的工具接口。模型可以在同一工作流中读取行情、调用指标、生成解释或构造后续分析步骤。
- 这类接口会把瓶颈从“模型没有实时数据”转移到数据来源、授权方式、时间戳、指标定义、工具稳定性和输出可审计性。
- 以 TradingView 会话 Cookie 作为接入方式的工具更像个人或实验型数据桥接，不应被当作生产级金融基础设施。Cookie 失效、服务条款、反爬、账号权限和数据延迟都可能影响结论。
- 金融数据 MCP 与 [[智能体交易经济性\|智能体交易经济性]] 的关系是前后端关系：前者提供数据和工具通道，后者追问 agent 的动态判断是否真的创造了扣除成本后的增量价值。
- [[Qlib\|Qlib]] 提供了更完整的离线量化研究参照：MCP 工具适合 agent 调用数据，Qlib 适合组织研究、回测和评估 pipeline；两者都需要 provenance 和审计。
- 对 [[AI Agent 安全\|AI Agent 安全]] 来说，金融数据 MCP 的风险不只在错误投资建议，也包括凭据暴露、工具越权、过时数据、不可复现实验和自动化下单边界。

## 边界

- 该页面不记录投资建议，也不把技术指标解释提升为可交易信号。
- 任何金融 agent 分析都应保留时间戳、数据来源、标的、费用、滑点、账户权限和人工确认记录。
- 如果工具依赖第三方平台会话、非公开接口或页面抓取，需要先确认平台条款和机构合规要求。
