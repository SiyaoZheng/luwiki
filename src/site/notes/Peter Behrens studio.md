# Peter Behrens studio

Peter Behrens studio（彼得·贝伦斯工作室）是本库为 20 世纪初 Peter Behrens 建筑事务所/办公室建立的历史工作场所节点。它不是一个可假定持续至今、法律形态始终不变的公司实体。
