# Palantir

Palantir 是一个企业数据、决策和运营软件公司节点。它在本 wiki 中的意义是观察企业 AI 如何从“模型回答问题”走向“数据、对象、权限、决策和操作被统一建模”的运行系统。

## 观察

- Palantir 首页把公司定位为帮助组织整合数据、决策和运营的软件。这说明它的核心对象不是单个 AI 助手，而是组织操作系统。
- Foundry 和 Ontology 把企业数据资产组织成可操作对象层。这个本体层使业务对象、流程、权限和动作可以被软件系统持续引用，而不是散落在报表、数据库和文档里。
- AIP 把 LLM 和其他模型放进企业私有网络与受控环境中运行，提示企业 AI 的关键问题是数据边界、访问控制、审计、模型调用和业务动作如何接入同一治理层。
- 对 [[AI Agent 安全\|AI Agent 安全]] 来说，Palantir 代表一种企业级路线：与其让 agent 直接漫游所有系统，不如先构建对象、权限和操作边界，再把模型放进这个边界内工作。

## 三同关系线索

- Palantir 2026 年代理文件把 [[Alexander Karp\|Alexander Karp]]、[[Stephen Cohen\|Stephen Cohen]] 和 [[Peter Thiel\|Peter Thiel]] 列为共同创始人，并分别确认 Karp 的 CEO、Cohen 的 President/Secretary、Thiel 的 Chairman 身份。三人的公司角色因此可以由公司节点直接连接人物节点。
- 教育关系只在人物页建立：Karp 的 Haverford College、Stanford University 与 Goethe University Frankfurt 学位，Cohen 的 Stanford University 学位，以及 Thiel 的 Stanford University、Stanford Law School 学位均由 SEC 文件披露。本公司页不链接这些学校，以免把个人履历误画成 Palantir—高校合作。
- PayPal 是 Thiel 的历史创业和任职关系，不是 Palantir 与 PayPal 的组织隶属关系。本页也不把客户、政府业务或投资关系写成私人三同。
