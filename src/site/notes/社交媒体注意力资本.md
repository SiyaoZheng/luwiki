# 社交媒体注意力资本

社交媒体注意力资本指平台上被看见、被互动、被传播的能力。它既像一种资源，也像一种由表达方式、平台机制和受众情绪反应共同分配的社会结果。

## 观察

- Nature Human Behaviour 研究提示，在中国 Z 世代社交媒体数据中，“怎么表达”比“你是谁”更能解释注意力获取：emoji 多样性和情绪表达类型比性别、教育、家庭背景或人格等传统个体属性更重要。
- 这说明平台注意力与传统资源并不完全对齐。表达方式可以在短期内制造注意力优势，使注意力更容易被获得，但也更难持续。
- 研究使用 agent-based simulation 指向 empathy evocation 机制：表达方式通过唤起共情影响注意力分配。这使它与 [[社会世界模型\|社会世界模型]] 相关，因为注意力不只是个体属性结果，也是互动机制和传播过程。
- 对 [[可执行社会科学\|可执行社会科学]] 来说，这类研究提供了一个模板：真实数据、因果识别和 agent simulation 可以共同解释平台行为，而不是只做相关性预测。
- 第 181 条中文解读补充了研究设计细节：微信公开记录、线下调查连接、网络中心性指标、固定效应、工具变量和随机实验共同支撑“表达方式影响注意力”的判断。

## 边界

- “表达方式更重要”不是说身份、结构资源或平台算法无关，而是在该研究对象和测量框架下，表达特征对注意力的解释力更强。
- 注意力获得不等于信任、影响力、说服或长期关系资本。
