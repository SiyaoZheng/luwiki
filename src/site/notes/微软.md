# 微软

微软是软件、云计算、开发工具、游戏和人工智能领域的全球科技公司。集团、地区法律主体、[[Microsoft Azure\|Microsoft Azure]]、[[GitHub\|GitHub]] 等业务和产品需要分层建模。

## 身份与层级

- 微软集团、[[微软亚洲研究院\|微软亚洲研究院]] 与历史工程业务单元需要分开建模。
- 微软于 2018 年完成收购 [[GitHub\|GitHub]]。FY2019 10-K 把会计收购日记为 2018 年 10 月 25 日，公开完成公告为 10 月 26 日；GitHub 自收购日起并入微软合并财务报表。
- 这条公司所有权边不等于微软收购了 Git 项目、全部 Git 代码版权或 Git 的上游治理；平台、项目和用户内容权利的分层见 [[Git 与 GitHub 的制度边界\|Git 与 GitHub 的制度边界]]。

## Anthropic 商业关系

微软与 [[Anthropic\|Anthropic]] 于 2025 年公告战略合作：Anthropic 承诺购买 300 亿美元 Azure 计算容量；微软承诺最高投资 50 亿美元。[[Claude\|Claude]] 随后进入 [[Microsoft Foundry\|Microsoft Foundry]] 的 Azure 合同和计费渠道，并与部分微软产品形成集成。

这些关系并非排他。Anthropic 公告继续把 [[Amazon Web Services\|Amazon Web Services]] 列为主要云提供方；微软的 [[Microsoft 365 Copilot\|Microsoft 365 Copilot]] 又与 Claude 的企业订阅争夺部分相同客户预算。云供应、投资、分销、产品集成和竞争可以同时存在，不能压缩成单一“联盟”。

公告中的 300 亿美元采购承诺和“最高 50 亿美元”投资不是公告当天已经确认的收入或全部到账现金；后续融资轮吸收部分既有投资承诺，不能重复相加。

## 当前网络角色

- [[陆奇\|陆奇]] 与 [[姜大昕\|姜大昕]] 的人物页用微软经历解释技术管理和 AI 工程网络；阶跃星辰公司关系经姜大昕中转。
- GitHub 现行材料把 Microsoft 称为 parent company／affiliate；2025 年 GitHub 被纳入 Microsoft CoreAI 组织，账单、合同和联合市场动作也存在具体协同。公开材料未单列 GitHub 营收、利润或各产品收入，不能把 Intelligent Cloud 总额归给 GitHub。

- 母公司监督、业务归组和联合销售不能替代具体产品、内容处置或客户合同的决策链证据。
- 与 Anthropic 的投资和采购承诺不公开实时持股、到账进度或各产品收入。
