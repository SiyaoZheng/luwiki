# 微软

微软是软件、云计算、开发工具、游戏和人工智能领域的全球科技公司。

## 身份与层级

- 微软集团、[[微软亚洲研究院\|微软亚洲研究院]] 与历史工程业务单元需要分开建模。
- 微软于 2018 年完成收购 [[GitHub\|GitHub]]。FY2019 10-K 把会计收购日记为 2018 年 10 月 25 日，公开完成公告为 10 月 26 日；GitHub 自收购日起并入微软合并财务报表。
- 这条公司所有权边不等于微软收购了 Git 项目、全部 Git 代码版权或 Git 的上游治理；平台、项目和用户内容权利的分层见 [[Git 与 GitHub 的制度边界\|Git 与 GitHub 的制度边界]]。

## 当前网络角色

- [[陆奇\|陆奇]] 与 [[姜大昕\|姜大昕]] 的人物页用微软经历解释技术管理和 AI 工程网络；阶跃星辰公司关系经姜大昕中转。
- GitHub 现行材料把 Microsoft 称为 parent company／affiliate；2025 年 GitHub 被纳入 Microsoft CoreAI 组织，账单、合同和联合市场动作也存在具体协同。公开材料未单列 GitHub 营收、利润或各产品收入，不能把 Intelligent Cloud 总额归给 GitHub。

## 证据等级与边界

- **证据**：A：微软官方入口、收购公告与 SEC 财务披露；B：欧盟合并决定及可靠商业报道；B/C：人物公开履历。
- **不能推出**：共同前雇主不等于具体人物互相共事，也不表示微软投资其后续公司。
- 同一前雇主、同一投资方或同一产业活动只形成检索边，不自动形成机构联盟或私人关系。
- 母公司监督、CoreAI 归组和联合销售不能替代具体产品、内容处置或客户合同的决策链证据。
