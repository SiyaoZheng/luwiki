# LABUBU

LABUBU 是泡泡玛特 THE MONSTERS 角色矩阵中的核心 IP 节点。当前来源把它放在与三丽鸥联名的盲盒和毛绒公仔发售中，用来观察潮玩 IP 如何通过跨品牌联名、稀缺发售和二级市场传播维持热度。

## 观察

- LABUBU 与三丽鸥联名把“怪萌”角色和 Hello Kitty、酷洛米、美乐蒂等甜美角色叠加，制造出明显的风格冲突和社交传播点。
- 泡泡玛特 2025 年年报披露 THE MONSTERS 年收入 141.611 亿元、占集团收入 38.1%，同比增长 365.7%。这是可审计的 IP 家族口径，不是 LABUBU 单一角色、单一 SKU 或三丽鸥联名口径。
- LABUBU 与 [[Zimomo\|Zimomo]] 同属 THE MONSTERS 角色运营的一部分：一个强调跨 IP 联名和盲盒扩散，一个强调周年主题和高价搪胶毛绒公仔。
- [[泡泡玛特\|泡泡玛特]] / [[王宁\|王宁]] 来源把 LABUBU 放进更大的公司战略中：爆款 IP 既能获得跨场景传播，也需要节奏控制，避免过度消耗角色价值。

## 截至 2026-08-10 的销售证据答案

- 年报确认 LABUBU 是 THE MONSTERS 的代表角色，并列出第三代搪胶毛绒和 Mini LABUBU 产品；它没有把 THE MONSTERS 收入拆到 LABUBU 单一角色，更没有披露具体三丽鸥联名的销量或收入。
- 媒体所称“一分钟售罄”、社交讨论量与二级市场挂牌价仍不能当作成交或收入证据。只有品牌发售记录、平台成交明细、联名结算或可审计 SKU 数据出现时，才重开单次联名成效判断。
