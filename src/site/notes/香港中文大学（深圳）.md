# 香港中文大学（深圳）

香港中文大学（深圳）是经教育部批准、按中外合作办学条例设立的独立高等教育机构，传承香港中文大学办学理念和学术体系。

## 与当前实体的关系

- [[香港中文大学（深圳）理工学院\|香港中文大学（深圳）理工学院]]是校内学院节点。
- [[唐本忠\|唐本忠]]的学校管理职务应由任命公告核验；本页只建立机构端点。
- 模感科技材料使用“港中深招聘页”描述团队背景时，只能作为来源入口，不能证明公司隶属学校。

## 边界

本校与[[香港中文大学\|香港中文大学]]存在办学联系但法人独立；二者不能互作 alias，也不能把一校学籍写成另一校学籍。
