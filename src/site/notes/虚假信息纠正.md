# 虚假信息纠正

虚假信息纠正关注错误信念为什么在事实核查和反复澄清后仍然存在。核心问题不是“真相是否被提供”，而是事实能否进入已经由先验信念、主观信心和反馈经验组织好的认知系统。

## 观察

- PNAS 研究把假新闻判断视为动态学习过程：人们不只是单次判断真假，也会根据自己原有判断、信心强弱和奖励反馈继续学习。
- 高信心信念更难改变。低信心新闻更容易在反馈后被修正，而高信心判断即使面对负面反馈，也更倾向被坚持。
- 事实纠错的困难来自“信心结构”：纠正信息不只是新证据，也可能挑战个体对自己判断能力和世界模型的信任。
- 对 [[计算政治心理学\|计算政治心理学]] 来说，虚假信息纠正是政治态度、认知信心、强化学习和媒体环境交汇的样本；对 [[智能社会治理\|智能社会治理]] 来说，它说明平台治理不能只依赖真假标签。
- 纠错策略可能需要区分低信心错误和高信心错误：前者可以直接补充事实，后者可能需要降低防御性、增加可接受性，并让人有机会重新评估信息线索。

## 边界

- 当前来源是论文解读，实验样本为年轻成年人且任务设置受实验室约束；公共平台上的政治身份、社群关系、算法推荐和情绪动员可能改变纠错效果。
