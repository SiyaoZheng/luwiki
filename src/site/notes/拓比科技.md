# 拓比科技

拓比科技是湖南拓比科技有限公司面向具身智能数据采集使用的品牌。其公开产品页将头戴视觉、惯性测量、SLAM、全身动捕和腕部视角组合为 E6、E8、E2 与 Wrist Camera 等设备，服务于第一视角记录、精细操作与人形机器人遥操作数据采集。

## 产品路线

E6 是六相机头戴设备，厂商称其已量产，并可输出视频、带轨迹的 SLAM、IMU、时间戳、相机参数与音频。E8 在头戴第一视角之外可选配四节点全身动捕；E2 以较轻的双目设备面向轻量 Ego-view 采集。公司还把腕部相机与头戴设备组合，用头部全景和手部特写记录精细操作。

这条路线的价值在于把操作数据的入口做成可配置硬件，而不是只出售单一相机。它与[[具身智能数据基础设施\|具身智能数据基础设施]]相连，因为时间同步、动作／视角覆盖和导出格式会直接影响训练数据能否用于后续标注、映射与评测。

## 边界

量产状态、同步和定位指标、数据接口及适用场景均来自公司产品页。该页没有披露客户、出货量、任务数据集、许可证、模型增益或独立性能验证。因此，公开资料能够证明其产品矩阵和厂商的量产主张，不能证明数据已经形成可复用的训练优势或商业采用。
