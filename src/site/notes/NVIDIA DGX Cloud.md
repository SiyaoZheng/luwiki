# NVIDIA DGX Cloud

**NVIDIA DGX Cloud** 是 [[NVIDIA\|NVIDIA]] 旗下的云服务产品，不是独立公司、子公司或单独披露的业务分部。现行合同框架规定可由 NVIDIA Corporation 直接或经授权渠道与客户签约；各地区的实际接单资格并未公开。它在 2023 年以企业按月租用专用 AI 计算集群的产品形态推出；到 2026 年，NVIDIA 顶层产品页已把它首先定位为公司内部 AI 云和验证场，同时现行订阅条款、服务级别协议及部分云市场入口仍然存在。公开证据因此支持“产品定位发生变化”，但不支持“产品已正式停服”。

## 产品身份与运营主体

2023 年 3 月的发布材料把 DGX Cloud 描述为企业可从浏览器使用、按月租用的服务，并把 [[NVIDIA AI Enterprise\|NVIDIA AI Enterprise]] 软件包含在订阅中。发布时由 Oracle Cloud Infrastructure 首先实际托管；Microsoft Azure 只被写成“预计下季度”，Google Cloud 只被写成“随后”，不能把这两项未来表述当成当日已经交付。该发布及其首批合作结构单独记录于 [[2023 NVIDIA DGX Cloud发布与首批云伙伴\|2023 NVIDIA DGX Cloud发布与首批云伙伴]]。

现行 NVIDIA Cloud Agreement 明确，客户的合同相对方是 NVIDIA Corporation；购买可通过授权经销商、授权云市场或 NVIDIA 直接订单完成。服务专项条款把 DGX Cloud 定义为付费订阅，默认按节点计费，具体费用以 Order Form 为准。因而：

- DGX Cloud 是产品品牌，不是 NVIDIA Corporation 的别名，也不是云伙伴与 NVIDIA 合资经营的法人；
- 云厂商可以同时承担托管、连接、数据处理或采购渠道角色，但不因此拥有或共同控制产品；
- 2023 年发布时实例起价为每月 36,999 美元；这是历史起价，不是可沿用到 2026 年的统一现价；本轮没有找到现行公开价目表。

## 商业演变

| 时点 | 可核验状态 | 商业含义与边界 |
|---|---|---|
| 2023-03 | 面向企业发布按月租用的托管集群；OCI 首先实际托管 | 是发布时产品形态，不代表所有后续云伙伴同时上线 |
| 2023-10 至 2024-12 | OCI、Azure、Google Cloud、AWS 先后出现实际市场或可用性证据 | 四家上线时间不同；“expected”“soon”“coming”均不能提前写成已交付 |
| 2025-05 | 发布 [[NVIDIA DGX Cloud Lepton\|NVIDIA DGX Cloud Lepton]]，当时为 early access 的多云计算市场／平台 | Lepton 是相关但独立的产品形态，不是原 DGX Cloud 的改名或法人继承 |
| 2025 年下半年 | 独立报道援引知情人士称商业服务收缩、更多容量转向内部使用 | 属二级来源，需要来源归属；不能单独据此写 EOL |
| 2026 | 当前顶层页把 DGX Cloud 首先写成 NVIDIA 的 internal cloud、AI proving ground，并把运营经验连接到 [[NVIDIA DSX\|NVIDIA DSX]]／DSX OS | 当前公开定位已经改变，但 Azure 市场页和现行付费条款仍在，故不能写“已关闭” |

上述变化作为一个可持续追踪的商业事件记录于 [[2025 NVIDIA DGX Cloud定位变化与对外业务收缩报道\|2025 NVIDIA DGX Cloud定位变化与对外业务收缩报道]]。The Information 的两篇原始报道以及 Tom’s Hardware、Investing.com 和 TechRadar 的转述，把变化描述为收缩外部云业务、强化内部研发或重组团队；核心经营细节仍依赖匿名来源。当前 NVIDIA 页面提供了“内部云／验证场”这一方向的一手确认，却没有给出正式退市、停止接单或终止既有合同的日期。

## 云伙伴、托管与销售渠道

四家主要云伙伴的角色应按实际上线日期分别理解，而不是用 2023 年发布公告一次性归并：

| 云伙伴（纯文本） | 关系事件 | 可核验角色 | 不能推出 |
|---|---|---|---|
| Oracle Cloud Infrastructure | [[NVIDIA DGX Cloud与Oracle Cloud Infrastructure合作\|NVIDIA DGX Cloud与Oracle Cloud Infrastructure合作]] | 2023 年首个实际 host；同年经 Oracle Cloud Marketplace 私有报价购买，部分客户可使用 Universal Credits | OCI 拥有 DGX Cloud，或所有 OCI 客户都采用该产品 |
| Microsoft Azure | [[NVIDIA DGX Cloud与Microsoft Azure合作\|NVIDIA DGX Cloud与Microsoft Azure合作]] | 2023 年 11 月已有实际 Marketplace 可用性；当前列表仍由 NVIDIA Corporation 提供 | 3 月的“预计下季度”就是交付日，或市场列表证明活跃客户数 |
| Google Cloud | [[NVIDIA DGX Cloud与Google Cloud合作\|NVIDIA DGX Cloud与Google Cloud合作]] | 2024 年 3 月 H100 DGX Cloud 被宣布已在 Google Cloud GA；当前合作页仍列 DGX Cloud | Blackwell 当时的未来表述已经实现，或 Google 是产品所有者 |
| Amazon Web Services | [[NVIDIA DGX Cloud与Amazon Web Services合作\|NVIDIA DGX Cloud与Amazon Web Services合作]] | 2023 年仅公告 coming；2024 年 12 月才有 AWS Marketplace Private Offers 的实际可用性证据 | 预告日等于上线日，或 private offer 等于公开统一价 |

NVIDIA 的 2025 年数据处理附录还把 AWS、Google Cloud、Azure 和 OCI 列为 DGX Cloud 的托管、连接或身份支持相关服务方。这个合同清单能证明角色类型，不能证明每个地区都有容量、每家获得多少收入，也不能证明 NVIDIA 与其中任何一家成立合资企业。

这些云伙伴同时有第二重商业角色：AWS、Microsoft Azure、Google Cloud 与 OCI 都以自有 AI 训练、加速器或 GPU 云产品争夺相同企业预算和工作负载。它们与 NVIDIA 的托管／渠道合作是真实关系，但不等于双方没有竞争，也不代表各自产品与 DGX Cloud 完全等价。WSJ 在 2025 年把这种结构概括为云厂商一面从合作中取得收入，一面帮助潜在竞争服务；这是市场分析，不是合作协议的法律定性。

现行服务级别协议给出 99% Service Availability 与 95% Capacity Availability 目标，补救为未来 DGX Cloud 订单期限的 credit。它证明仍有面向订阅客户的合同框架；不等于每个客户都达到这些指标，也不是现金赔偿或平台实际可靠性的独立测量。

| CCC Intelligent Solutions | [[CCC Intelligent Solutions-NVIDIA DGX Cloud采用\|CCC Intelligent Solutions-NVIDIA DGX Cloud采用]] | NVIDIA 发布稿点名，CCC 投资者关系站转载同一稿件 | 转载不是独立审计，也没有合同金额或活跃席位／节点数 |

| Domyn（原 iGenius） | [[Domyn-NVIDIA DGX Cloud采用\|Domyn-NVIDIA DGX Cloud采用]] | 2025 NVIDIA 合作案例披露其使用超过 3,000 块 H100 完成模型继续预训练 | 规模与耗时是双方案例陈述，不是经审计的利用率或商业回报 |

这些案例跨越发布期和后续云伙伴上线期，说明 DGX Cloud 曾有外部企业使用；它们不能回答 2026 年一般企业新客户是否仍可直接购买、历史客户是否续约、外部与内部容量如何分配等问题。The Information 还记录 NVIDIA 曾把 Amdocs 与 ServiceNow、SAP 一同作为早期客户宣传；这只能作为媒体对厂商既往宣传的记录，不能升级为媒体独立核验的当前客户关系。

## 独立市场与竞争证据

独立来源对“产品存在及其竞争位置”的支持强于对“当前采用规模”的支持：

- Reuters 在 2023 年独立记录了 DGX Cloud 的发布、约 3.7 万美元月租报价及通过云伙伴提供访问的租赁模式，但其中客户与产品效果仍来自 NVIDIA／交易方；精确的 36,999 美元起价仍以 NVIDIA 发布稿为准；
- WSJ 在 2025 年明确指出 DGX Cloud 规模不清楚，NVIDIA 不拆分其收入或利润。该文随后对盈利可能性的推测没有可审计基础，本页不采用；
- 葡萄牙竞争管理局 2026 年分析把 DGX Cloud／Lepton 放进“芯片设计商向云服务扩张”的具体市场结构，并点名 CoreWeave、Crusoe、Nebius、Lambda 等 Lepton 供给伙伴。该文件讨论的是潜在竞争风险，不是对 NVIDIA 或伙伴违法的认定；
- The Information 的 2025 年报道提供了对外业务收缩和团队调整线索，但依赖匿名消息源，也没有披露客户数、利用率、续费或单品财务。

具体竞争边界需要按实体关系写：AWS、Azure、Google Cloud 与 OCI 是 DGX Cloud 的托管／渠道伙伴，同时以自有云平台竞争同一预算；CoreWeave、Lambda、Crusoe、Nebius 等是 Lepton 供给伙伴，同时经营与 DGX Cloud／Lepton 争夺工作负载的 GPU 云。这里的“伙伴兼竞争者”不是矛盾，也不能把容量采购、投资或市场上架金额误写成 DGX Cloud 收入。

## 收入、成本与采用边界

NVIDIA 的 FY2026 10-K 与截至 2026 年 4 月 26 日的 FY2027 Q1 10-Q 都没有单列“DGX Cloud”，公司只报告 Compute & Networking 与 Graphics 两个分部。公开文件也没有 DGX Cloud 的收入、ARR、毛利、订单、利用率、客户数或续费率。因此不得把以下数字改写为 DGX Cloud 业绩：

- Data Center 或 Compute & Networking 收入；
- 2026 年 4 月 26 日合并口径 31.17 亿美元递延收入——脚注明确混合了硬件／软件支持、云服务、许可与开发安排；
- 同日 300 亿美元多年云服务承诺——文件称主要用于 NVIDIA 自身研发，是采购义务而非客户订单、递延收入或产品销售额。

SEC 文件同时提示，云服务业务模式可能无法形成有意义收入，其他公司也可能以云服务竞争。这是公司层面的风险披露，不足以推算 DGX Cloud 单品亏损、盈利或市场份额。

## 产品治理与负责人

截至本轮可核验材料，NVIDIA 官方作者页将 [[Warren Barkley\|Warren Barkley]] 标为 DGX Cloud 产品管理副总裁。公开材料没有给出 DGX Cloud 独立报告单元、单独董事会或现任总经理的完整名单；该职称证明产品管理职责，不把 DGX Cloud 升格为子公司或独立业务分部。

## 与 Lepton、DSX 和 AI Enterprise 的边界

- [[NVIDIA DGX Cloud Lepton\|NVIDIA DGX Cloud Lepton]]：2025 年推出的多云计算市场／平台，连接开发者与 NVIDIA Cloud Partners。它扩展了 NVIDIA 的外部云供给组织方式，但官方没有把它定义为原 DGX Cloud 的改名或终止继承者。
- [[NVIDIA DSX\|NVIDIA DSX]]：2026 年发布的 AI factory 设计与运营平台。当前 DGX Cloud 页把内部运营经验与 DSX OS 联系起来；没有证据表明 DSX 收购、替代或关闭 DGX Cloud。
- [[NVIDIA AI Enterprise\|NVIDIA AI Enterprise]]：2023 发布时包含在 DGX Cloud 订阅中的企业软件。产品关系不等于永久捆绑，也不能把 AI Enterprise 的四个云市场入口、许可证客户或收入归给 DGX Cloud。

## 证据边界与待核验

已核验：运营／合同主体、历史发布起价、四家云伙伴的分阶段上线证据、当前付费合同框架、当前内部云／验证场定位、厂商或客户公开披露过的若干关系，以及 SEC 不单列财务结果。

尚未找到：官方 EOL 或停止接单公告、2026 年统一公开价格、一般新客户资格、外部与内部容量比例、活跃客户名册、单品收入与利润、当前续费率、完整现任管理团队，以及 2025 年战略变化的正式董事会／投资者披露。

重开条件：NVIDIA 发布产品退市或采购政策公告；现行 Marketplace 状态实质变化；SEC 开始单列云服务或 DGX Cloud 财务；NVIDIA 公布新的客户、价格、负责人或 DSX／Lepton 关系说明。
