# 机器人世界模型压力测试

机器人世界模型不能用一个“视频质量”分数验收。模型可能画面稳定却忽略动作，动作能解码却违反接触边界，短程可执行却在长程漂移，也可能在少数策略上的成功率相关很高、同时把具体失败自动修正成成功。

因此，可复用的最低评测单元不是单一 benchmark，而是从视觉到真机校准的分层压力测试。每层回答不同问题，低层通过不能替代高层证据。

## 七层压力测试矩阵

| 层 | 要回答的问题 | 最低可接受协议 | 能支持的结论 | 不能据此推出 |
|---|---|---|---|---|
| 视觉与语义 | 物体、指令和时序是否表面一致 | 多域初始条件；人工标签；幻觉、漂移、跳变分项；VLM 与人工分别报告 | 视频代理错误的类型和频率 | 动作可执行、接触正确、策略会成功 |
| 运动学 | 轨迹是否满足关节、速度、加速度和 jerk 边界 | ground-truth 视频先校准 action decoder；报告 joint error、越界率和消融 | 动作表示和局部轨迹是否合理 | 摩擦、质量、碰撞、力控正确 |
| 动力学敏感 | 模型是否对决定成功/失败的物理参数产生正确响应 | 物理参数 sweep 必须跨过 regime boundary；真实 physics 对照；seed、CI、正负控制 | 想象是否捕捉了某一动力学机制 | 总体预测准确或真机安全 |
| 接触与失败保持 | 抓空、滑移、碰撞或形变会不会被“修好” | 专门的失败轨迹、OOD/action shuffle、接触前后事件、成功 optimism | 模型是否忠实保持失败及动作因果性 | 长程稳定或跨本体泛化 |
| 长程误差 | 多步想象是否累积漂移，memory 是否有效 | 多个 horizon；可逆动作 round trip；有/无 memory；固定开环动作与闭环分开 | 漂移曲线和历史机制的净作用 | 接触动力学已正确 |
| IDM／动作可执行 | 视频能否恢复成完成任务的动作 | 先用 ground-truth 视频测 decoder ceiling，再对生成视频做 step-level 与 strict task success；分开 IDM、仿真与生成误差 | video→action→execution 链是否可用 | 真机成功或原视频物理完全正确 |
| 真机相关性 | imagined score 能否预测实际策略结果 | 多策略、多任务、足够 trial；real 与 imagined 同 success 定义；报告 n、r/ρ、CI、校准误差与裁判偏差 | evaluator 在给定分布中的排序/校准能力 | 单次 rollout 可信、因果关系或安全部署 |

还应增加一个前置的 **artifact 与许可证门**：固定代码 commit、checkpoint revision、数据 split、seed、成功定义和代码/权重/数据许可。仓库存在但 runner 在第一个 episode 前失败时，结果是 N/A，不是 0%。

## 现有 benchmark 分别覆盖什么

除下文明确标为“跨方法外部诊断”的结果外，本节数值均是方法或 benchmark 团队的作者自评。截至 2026-08-10，尚未找到同 checkpoint、同任务、同 seed 与同 success 定义的无作者重叠独立复现。

### DreamGen Bench 与 WFM-Eval：视觉代理层

**DreamGen（作者自评）**：[[DreamGen]] Bench 的 IF（Instruction Following，指令遵循）与 PA（Physics Alignment，物理一致性）由 GPT-4o、Qwen2.5-VL、VideoCon-Physics 或人类判断。其 48/50/47/30 是四组评测初始帧样本数，不是统一视频帧长；公开代码里 Qwen 与 GPT evaluator 看到的帧数也不同。GR1 的 IDM replay 只有定性展示，没有聚合执行成功率。它能筛查“看起来是否遵循指令和物理常识”，不能充当动作可执行性指标。

**WFM-Eval（跨方法外部诊断）**：把错误拆成 phantom appearance/disappearance、position drift/jump，并显示最佳 VLM judge 的 F1 只有 69.5%，completion rate 与人工仅 r=.287、p=.248。Predict2 在 GR1 的 HSS 排第 1、到 AgiBot 变第 5；单域排名会反转。其唯一政策对照是 Predict2 与 Predict2.5 的 single-pair test，不是普遍相关性研究。

这也限定了 [[GR00T-Dreams]] 的 DreamGenBench 环节：约 50 条/数据集的小样本 VLM 代理不能替代逐样本 IDM 回放、接触检查或失败保持。

### EVA 与 RoboWM-Bench：动作可执行层

**EVA（作者自评）**：将视频经 IDM 解码，使用速度、加速度、jerk 和动作边界构成 reward。作者报告 RoboTwin 成功率 46.2→52.6，真机 seen 52→64、OOD 42→60；ground-truth 视频的 IDM 模拟回放成功率为 89.52%。这证明运动学约束能进入执行链，但 interaction plausibility 仍是人评，reward 没有测力、摩擦、扭矩和碰撞。

**RoboWM-Bench（作者自评）**：更直接地把人手视频经 retargeting、机器人视频经 IDM 转成动作，再在重建仿真中报告 step-level 与 strict task success。其 sim+real IDM 在 ground-truth 视频上回放 95.7%，7 个 real-to-sim 任务的 140 条成功/失败轨迹得到 100% outcome agreement。通用 Cosmos-Predict2.5 在 8 个 robot tasks 多数只有 0–10%，每任务 50 条真实轨迹微调后升到 20–90%，说明视觉可接受不保证 embodied executability。

这类执行分数仍混合三种误差：生成视频、video-to-action 接口和 real-to-sim。contact-sensitive 或 near-boundary 任务尤其容易被很小的 pose/grasp 偏差翻转，所以必须先报告 ground-truth-video decoder ceiling。

### iKCE：动力学敏感层

**imagined Kinematic-Consistency Error（iKCE，作者自评）**不看视频观感，也不执行机器人任务。它在 DreamerV3 walker-walk 上把摩擦从 μ=.1 扫到 1.7；μ=.20 时真实 policy reward 已低于 μ=1 基线的 50%，因此 sweep 跨过论文的操作性失败区。T=64 时，真实 physics 的 iKCE slope 为 −.220，95% CI[−.301,−.142]，三套 imagined seed 却都近乎平坦；domain-randomized WM 仍未恢复摩擦响应。关节噪声正控制又显示模型并非对所有扰动都无反应。

这提供了最清楚的“运动学想象不等于动力学想象”诊断。但 iKCE 是结构 signature，不是准确率；平凡恒速预测器可得 0。它只在单一 DMC walker、(z,vz) 切片与短真实前缀上成立，不能替代接触任务、动作执行或真机评测。

### dWorldEval、WMBench 与 RoboWorld：失败、长程与相关性层

**dWorldEval（作者自评）**：直接加入失败与 OOD 动作。failure subset 的 ΔLPIPS 从 WorldEval .701、WorldGym .650、Ctrl-World .416 降到 .352；跨样本 action shuffle 使 LPIPS .215→.461、ΔLPIPS .324→.697。可逆动作 round trip 从 H=5 延长到 H=20，误差 .130→.243；去 memory 后为 .177→.411。它证明失败 self-correction 和长程漂移是独立压力轴，但实现、权重和数据尚未发布；success/progress 标签由 SEED-1.5VL 生成，相关性仍是作者自评。

**GigaWorld-1 / WMBench（作者自评）**：使用 2,989 条配对真实轨迹和 324K 生成片段。动作注入的 trajectory accuracy 为无动作 .1576、cross-attention .1620、ControlNet .2566、空间对齐 concat .3528，显示普通 action token 很容易被视觉 token 淹没。在 Wan2.1 的该协议中，40 秒 FID 由 40.58 上升至 121.61；memory 相对无 memory 的 316.77 较低，但不能据此推出一般性的长程解决方案。仓库、stage-1 模型与 toy data 已部分公开，但完整 WMBench、15 指标与 WMES evaluator 未全发，挑战数据还有非商业与禁止再分发限制。

**RoboWorld（作者自评）**：在 8 个策略、4,186 条 30 秒 rollout 上报告 Pearson r=.989、Spearman ρ=.970；相关性的有效样本是 n=8 个策略聚合点，不是 4,186 条独立样本。约 100 条人工核验发现 GPT-4o 比人类宽松约 1 分，加入 wrist view 后 ρ 降为 .862，并存在接触后物体解体或形变。高策略级相关性因此可以与严重的单轨迹接触错误并存。其代码仍为 coming soon。

### DreamGen／GR00T-Dreams

**作者自评**的真机与 RoboCasa 增益说明整个“生成→IDM→策略训练”链在其设置中可能有用，却没有隔离视频、IDM、筛选和训练 mixture。没有受控摩擦/质量/接触测试，也没有按 horizon 报告误差。RLDX-1 与 RoboCurate 属于**独立采用**：它们进一步说明视频过滤后仍需要 action replay 或动作—视频一致性过滤，但不是原链精确复现。

### DW0.5／OpenDW

**工件审计**显示当前 action horizon=32，执行 8 步后重规划，联合路径输出 9 帧视频；但是固定版本的两次前检都在 0 episode 结束，作者也未发布 matched baseline、真机结果或第三方复现。静态可读的 action/video 路径只能记为组件存在，不能在任何实验列打勾。

### DreamZero

**DreamZero 作者自评**联合生成动作与未来视频；AgiBot 与 DROID 动作块均约 1.6 秒。每块执行后以真实观察替换预测视频，因此其强真机闭环结果不测试纯生成 open-loop drift，也不是 imagined score—real outcome 相关性。**ManipArena 的跨方法外部诊断**在倒水、插线、按钮序列等精细接触任务出现多项 0% strict success，提示粗粒度进度与接触可靠性不同。

### Cosmos Policy

**Cosmos Policy 作者自评**直接输出动作、未来状态和 value；RoboCasa full 67.1、去掉 world+value 64.0、action-only 44.4，ALOHA 平均 93.6。它只预测 t+K 单个未来状态，规划时整块执行；终局真机 success 是闭环结果，不是 imagined score—real outcome 相关性，也不能证明多步动力学忠实。代码 Apache-2.0，发布权重为 NVIDIA NSCLv1 非商用。

## 最低执行顺序

1. 固定版本、数据 split、success 定义和许可证；不可执行的 artifact 标 N/A。
2. 用 ground-truth 视频校准 IDM/retargeting ceiling，避免把 decoder 误差算到世界模型。
3. 运行视觉、幻觉和时序诊断，但只把它当早期 gate。
4. 对生成视频做 step-level 与 strict task execution，并分别记录 generation、IDM、simulator failure。
5. 用失败轨迹、OOD/action shuffle 测 action causality 与 self-correction。
6. 用跨 regime-boundary 的摩擦、质量或接触参数 sweep 测动力学响应，配真实 physics、seed、CI 与正控制。
7. 在多个 horizon 上报告 round-trip、memory ablation 和固定开环/闭环差异。
8. 最后以同定义 real rollout 做校准，报告策略数、任务数、trial、r/ρ、CI、裁判偏差和失败 optimism。

这套顺序的核心是：**视觉合理、政策排名相关、动作可执行、接触动力学正确是四个不同命题。**
