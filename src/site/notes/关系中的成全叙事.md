# 关系中的成全叙事

关系中的成全叙事指亲密关系不以“持续在一起”作为唯一成功标准，而把彼此支持、共同成长、允许分离和保存尊重作为关系价值的一部分。它常出现在电影、音乐剧和社交媒体情感文本中，用来解释“相爱但不相守”的关系经验。

## 观察

- 这类叙事把爱情从占有和结局转向过程：两个人在某一段时间里成为彼此梦想的见证者、推动者或保护者，即使最后分开，关系仍然被写成有意义。
- 《爱乐之城》式文本常把梦想、城市、职业机会和时间错位放在同一结构里。关系冲突不是单纯“不够爱”，而是不同人生轨迹和现实成本互相拉扯。
- 与 [[亲密关系中的恨\|亲密关系中的恨]] 相比，成全叙事试图把分离从羞辱、背叛或报复中移开，改写成“我仍承认你对我生命的意义，但不继续占有你”。
- 这类叙事也可能带来浪漫化风险：它容易把不平等付出、长期缺席或现实压迫包装成“温柔成全”，需要区分真正尊重与被迫退让。
