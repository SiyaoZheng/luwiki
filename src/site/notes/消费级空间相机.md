# 消费级空间相机

消费级空间相机是一类把真实空间采集成可渲染、可编辑、可复用三维数据的硬件形态。它与普通相机的差别不在于更清晰的影像，而在于输出对象从二维照片/视频变成带几何、视角和空间关系的场景资产。

## 观察

- [[竹马创新\|竹马创新]] 显示，3D Gaussian Splatting、传感器降价、端云协同和 AI 原生交互正在把三维重建从专业测绘设备推向消费级硬件。
- 这类设备可能成为 [[AI 建筑设计工具\|AI 建筑设计工具]] 的现实输入层：设计师可以扫描室内空间，再把真实几何和材质导入渲染、方案迭代或可编辑模型流程。
- 对 [[具身智能数据基础设施\|具身智能数据基础设施]] 来说，消费级空间相机补的是环境数据。它不能替代动作、力触觉或任务轨迹，但可以低成本积累室内、家庭、商铺和公共空间的三维语料。
- 与 [[ABot-Earth\|ABot-Earth]] 的城市级生成相比，消费级空间相机更适合小尺度、近距离、高频率的真实空间捕获；与 [[World Labs\|World Labs]] 的持久 3D 世界路线相比，它更像现实世界采集入口。
- 当空间相机进入日常生活，[[MindSpace\|MindSpace]] 这类空间数据库/空间记忆产品就不只依赖专业采样，也可能获得更分散、更个人化的空间记录。
- [[MILO\|MILO]] 提醒，3DGS 采集链路的下一步不是只追求好看渲染，而是把高斯表示转成干净、轻量、可编辑的表面网格，便于进入设计、仿真和实时引擎。

## 边界

- 消费级三维采集不等于消费级世界模型。空间资产要进入机器人训练、AR 工作流或数字孪生，还需要尺度校准、语义标注、隐私授权、格式标准和任务接口。
- 家庭聚会、旅行和居住空间的三维记录会带来明显隐私问题，尤其是可从任意视角回放的空间记忆。
