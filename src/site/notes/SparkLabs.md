# SparkLabs

SparkLabs 是 Yuan-ManX 维护的开源 AI-native game engine 项目。它把 AI Agent、NPC cognition、叙事生成、工作流画布和游戏开发协作放进游戏引擎架构，而不是只在传统引擎外接一个聊天或资产生成工具。

## 观察

- SparkLabs 的核心叙事是“AI 不是插件，而是引擎底层”。这使它成为 [[AI NPC\|AI NPC]] 和 AI-native interactive content 的一个开源实验场。
- GitHub README 把项目描述为 agents 参与世界构建、叙事导演、NPC 认知和生产流程的引擎；公众号来源进一步整理了 SparkAgent、五层记忆、NPC 人格/情绪、AI 叙事和多 Agent 游戏开发团队等模块。
- 它目前更适合被看作实验性项目，而不是成熟游戏引擎。GitHub 公开信息显示项目为 MIT license，创建于 2026 年 3 月，stars 很少，不能把“首个 AI 原生游戏引擎”当作行业共识。
- SparkLabs 的价值在于把 [[AI 记忆系统\|AI 记忆系统]]、多 Agent、NPC 状态、叙事生成和开发工具链组织成一个具体架构原型，便于观察 AI 游戏开发会怎样变化。
