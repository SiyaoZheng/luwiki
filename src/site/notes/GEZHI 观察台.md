# GEZHI 观察台

GEZHI 观察台是一个弱信号智能体/异常队列原型节点。它把社会、消费或市场中的异常事件组织为可跟踪条目，并记录优先级、证据数量、来源多样性和查证状态。

## 观察

- 观察台的核心对象不是单条新闻，而是 anomaly queue：每个异常条目有领域、更新时间、分数、优先级、证据数、来源数和最新查证。
- 外卖骑手进小区履约受阻和沪铜期货价格异动两个样例说明，弱信号 agent 可以跨社会治理、消费品牌和金融商品等不同领域工作，但金融样例不应被提升为交易建议。
- “模拟查证员补入证据”提示该原型关注的是 evidence loop：发现异常之后，要不断补证、校正、降权或升级，而不是只生成一次性结论。
- 与 [[Agentive 系统\|Agentive 系统]] 相比，GEZHI 观察台更像被人类设计的 agentic workflow：目标、队列和查证规则由系统外部定义，尚不能说明其拥有内生目标或自我学习能力。
- 对 [[社会世界模型\|社会世界模型]] 来说，弱信号观察台是一种输入层：它把分散的社会/市场事件转成可以被追踪、解释和干预的状态对象。

## 边界
