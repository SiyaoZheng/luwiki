# 情绪调节过程模型

情绪调节过程模型把情绪调节放在情绪生成过程的不同时间点上理解：人可以在情境出现前、注意分配时、意义解释时，或反应已经形成后进行调节。它不是一种单一疗法，而是一张描述“情绪在哪里被改变”的机制地图。

## 观察

- James J. Gross 的过程模型通常区分五类策略：情境选择、情境修正、注意部署、认知改变和反应调节。前四类更接近前置调节，最后一类更接近情绪反应已经启动后的调节。
- 认知重评属于认知改变：它不是压住反应，而是改变人对事件意义、可控度、责任归因或未来后果的解释。表达抑制则更接近反应调节，通常发生在情绪体验已经形成之后。
- 对 [[情绪计算\|情绪计算]] 来说，这个模型提供了一个重要边界：识别“用户很愤怒/焦虑”只是情绪测量，判断系统应该帮用户改变情境、转移注意、重构解释还是调节表达，才涉及情绪干预。
- 对 [[AI 与大脑情绪系统\|AI 与大脑情绪系统]] 来说，过程模型提醒计算模型不能只看价度输出；情绪形成前后的时间位置、注意、解释和反应通道都会影响最终行为。
- 对人机互动系统，最危险的误用是把情绪调节简化成“让用户冷静”。真正的问题通常是：调节对象是什么、由谁授权、调节是否可撤销、系统是否承认不确定性。

## 边界

- 过程模型是心理学框架，不是临床诊断工具。具体干预需要专业评估和情境判断。
- AI 产品引用情绪调节框架时，应避免未经授权地推断心理状态或把用户情绪当作可操控对象。
