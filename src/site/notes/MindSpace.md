# MindSpace

MindSpace 是一个围绕物理空间智能层的网页/产品原型节点。两个来源页面都把它表达为 “Give Space a Mind” 和 “The Intelligence Layer for Physical Space”，并展示 Video、Database、Trial Version 三个入口。

## 观察

- MindSpace 的当前网页信息量很少，但核心定位明确：它把空间样本、传感信号和心理响应组织成可检索的空间数据库或空间记忆层。
- 这个定位连接 [[世界模型\|世界模型]] 与 [[人本城市模拟\|人本城市模拟]]：空间不只是几何场景，还可以包含传感信号、心理响应和可检索记忆。
- [[ABot-Earth\|ABot-Earth]] 提供了相邻但不同的空间路线：它更偏城市级 3D 世界生成，MindSpace 更偏空间数据库、传感和心理响应层。两者都说明物理空间正在被组织成 AI 可调用的对象。
- [[WUDAPT\|WUDAPT]] 则补充城市气候和形态分类数据，提示空间数据库不一定只存几何和感知，也可以包含热环境、建筑形态和公共健康相关分类。
- [[DataShareClub\|DataShareClub]] 进一步补充动态天气/AQI 数据，说明空间记忆层可以同时包含静态形态、实时环境和人的心理/行为响应。
- [[消费级空间相机\|消费级空间相机]] 补充了小尺度真实空间采集入口：如果室内和家庭空间能被普通用户低成本扫描，空间数据库就可能从专业样本扩展到日常空间记忆。
- [[建成环境具身智能感知\|建成环境具身智能感知]] 为这类数据库给出可复用的最小结构：空间形态与具身感知两类数据，应能沿采集、分析、评价和预测四个环节追溯。心理响应标签还必须保留测量方法、时间同步、同意范围和不确定性，不能只存一个脱离情境的分数。

## 截至 2026-08-10 的产品答案

- 公开入口仍是信息量有限的网页原型；本轮未找到公开 schema、API、数据集、模型卡、采集协议、心理测量量表、隐私条款、产品定价或客户案例。
- 因而当前只能确认“空间智能层/空间数据库”这一产品假设，不能确认空间样本采集、心理响应同步与校准、数据库服务智能体的实际管线，也不能确认 Human Model 已实现。
- 重开条件是出现公开技术文档、数据/模型制品、测量协议、隐私条款、可运行产品或客户侧部署；没有这些材料时不重复挂泛化问题。

## Human Model 产品草案

- 2026-08-04 的私聊中，MindSpace 创始人把 Human Model（人类模型）描述为一套产品/研究框架：同步采集第一视角视觉、多模态神经生理电信号和行动选择，并设想向机器人提供状态/反应预测能力、向世界模型或 AIGC 提供“人类真实感评价层”。这是产品草案和研究问题，不是已实现能力。
- 草案把 Human Model 称为 LLM、World Model 之外的“第三条基础方向”，但现有外部资料只能支持若干相邻研究路线，不能证明学界已形成这一公认分类或模型代际。
- 同步多模态记录首先建立时间对齐和统计预测条件；它不自动证明系统能够读取潜在意图、动机或情绪，也不自动识别“感知→神经表征→意图→行动”的因果链。此类主张还需要预注册意图标签、跨被试/场景留出、模态消融、伪同步对照、校准/拒答以及随机化干预。
- [[EgoBrain\|EgoBrain]] 是一项相邻但更窄的证据：其公开任务以第一视角视频和 32 通道 EEG 进行 29 类受控日常动作分类，官方数据页另含 IMU。
- EgoBrain 的公开模态没有 EMG 或 ECG；这项任务可以检验生理模态对动作分类的贡献，但不能验证完整三轨系统、意图读取或因果链。
- [[Conduit\|Conduit]] 提供另一种相邻但不同的神经—语言对齐样本：参与者在非侵入式头戴设备下打字或说话，神经数据与文本/音频时间对齐。
- Conduit 的约一万小时数据与 zero-shot 示例均是公司第一方声明，不能据此证明 Human Model 已能读取意图、预测身体反应或完成机器人闭环。

## 合作信息边界

2026-08-04 的私聊中，创始人口述正在准备与“乐享科技”和“及物空间”签框架协议。截至 2026-08-10，没有找到官网公告、联合新闻稿、合同/采购公告、共同专利、产品集成页或共同论文；两个名称的法律主体与合作范围也未完全核验。因此这里只保留为未获公开证明的创始人口述，不能写成已签署合作，也不建立机构图谱边。仅在合同可公开版本、双方公告或可核验共同制品出现时重开。
