# 中国科学技术大学

中国科学技术大学是[[中国科学院\|中国科学院]]所属、以前沿科学和高新技术为主的理工科大学。

## 与当前实体的关系

- [[姜大昕\|姜大昕]]的中科大教育经历已由中国科学技术大学校友总会确认：1993 年入学、1998 年获学士学位；该关系从媒体履历升级为学校一侧已核验。
- [[中国科学院软件研究所\|中国科学院软件研究所]]也是中科院所属机构，但不是中科大的下属单位。

## 边界

“中科院体系”不能压平为单一机构；大学学籍、研究所任职和公司创业必须分别建边。
