# 上海期智研究院

上海期智研究院是上海市科学技术委员会所属事业单位，聚焦人工智能、现代密码学、高性能计算、量子计算与交叉研究。

## 与当前实体的关系

- [[姚期智\|姚期智]]担任研究院院长，官方简介支持这一机构领导关系。
- 研究院公开与清华、复旦、上交、同济等高校开展科研、人才和学生培养合作；它不是这些大学的下属院系。

## 边界

高校合作、联合培养或共同活动不能自动推出具体师生、任职、项目知识产权或公司投资关系。
