# AlphaBrain Platform

AlphaBrain Platform 是覆盖具身数据、训练、模型架构、评测和部署工具链的开源平台节点。平台官网直接导向 `AlphaBrainGroup/AlphaBrain` 仓库；仓库采用 MIT License，并把软件作者写作 `AlphaBrain Community`。这证明公开代码和社区入口已经存在，但不等于平台本身是独立法律主体。

## 身份与层级

- **平台/社区**：官网与 GitHub 把 AlphaBrain Platform 表述为一站式具身模型开源社区；仓库 citation 使用 `AlphaBrain Community`，没有给出公司注册名、隐私政策或服务条款。
- **公司产品线**：[[智平方科技\|智平方科技]] 官网把 AlphaBrain 写作公司自主研发的具身大模型；公开发布材料把 AlphaBrain Platform 归入其技术发布。由此可确认产品/技术发布关系，不能把 `AlphaBrain Community` 自动当作智平方的法律别名。
- **开源制品**：仓库提供训练、评测、部署目录与文档，列明主要 fork 自 starVLA，并以 MIT License 发布。许可证只覆盖仓库代码的许可范围，不自动覆盖所有上游模型权重、数据集或第三方组件。

## 当前网络角色

- [[智平方科技\|智平方科技]]：技术平台与公司关系。
