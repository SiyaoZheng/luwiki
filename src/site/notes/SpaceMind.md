# SpaceMind

SpaceMind 是科大讯飞面向智慧空间的 Agentic 架构/产品节点。它把家庭或商业空间看作一个能持续感知、记忆、决策和执行的 agent，而不是一组等待语音命令的联网设备。

## 观察

- SpaceMind 的核心对象是“空间作为 agent”：空间感知、语义理解、长期记忆、智能决策和设备执行被组织成闭环。
- 毫米波雷达被放在感知核心位置，说明智慧空间并不一定以摄像头作为默认入口。其价值在于在不采集图像和人脸的前提下感知位置、人数、微动和跌倒等状态，这直接连接 [[AI Agent 安全\|AI Agent 安全]] 中的隐私边界。
- 双路由架构把本地控制和云端推理解耦：灯光、窗帘等高频设备控制走低延迟本地路径，复杂语义、长期记忆、日程和规划走云端推理路径。这个设计说明物理空间 agent 不能只追求“模型更聪明”，还必须满足实时性、稳定性和确定性。
- SpaceMind 把 [[AI 记忆系统\|AI 记忆系统]] 从聊天或企业任务推进到物理环境：长期记忆记录的不只是用户偏好，还包括家庭成员、空间结构、场景历史和设备使用方式。
- 对 [[以人为中心的具身智能\|以人为中心的具身智能]] 来说，SpaceMind 是“理解人”的空间侧版本。它不移动身体，但它需要理解人的位置、状态、习惯和打扰边界。
- [[建成环境具身智能感知\|建成环境具身智能感知]] 提供一条更窄但可审计的前置链：从空间形态与人的具身感知出发，完成采集、分析、评价和预测。SpaceMind 在此之上又加入长期记忆、决策与设备执行；仅有占用感知或状态预测，还不足以证明空间已经成为 agent。

## 边界

- 截至 2026-08-10，科大讯飞官方发布已明确列出 60GHz 毫米波雷达、5 厘米定位、700 毫秒本地控制、持久记忆、Marketplace、创新应用大赛、Matter/Google Home/Amazon Alexa 兼容口径，以及 WallEX 终端进入中东、拉美和东南亚市场的公司说法。它只支持“科大讯飞已发布这些功能与市场口径”，不支持具名客户部署数、型号级兼容范围或独立性能结论；仅在具名客户案例、设备型号清单、协议认证或第三方评测出现时重开。
- SpaceMind 是智慧空间架构，不应直接等同于通用具身智能或机器人世界模型。
