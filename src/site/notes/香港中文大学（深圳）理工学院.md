# 香港中文大学（深圳）理工学院

香港中文大学（深圳）理工学院是[[香港中文大学（深圳）\|香港中文大学（深圳）]]的院系节点，覆盖数学、物理、化学、材料、计算机、人工智能与机器人等方向。

## 与当前实体的关系

- [[唐本忠\|唐本忠]]的副校长和理工学院相关职务需以学校任命和人物页面为准；当前机构身份已由学院官网确认。
- 模感科技团队背景材料提及港科大、帝国理工、浙大等，并非港中大（深圳）理工学院团队；招聘页作为来源不等于组织关系。

## 边界

学院是港中大（深圳）下设单位，不是香港中文大学本部学院，也不应从招聘信息推断企业孵化关系。
