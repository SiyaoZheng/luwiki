# 浙江大学电气工程学院

浙江大学电气工程学院是 [[浙江大学\|浙江大学]] 的院系节点，开展电气工程、电力系统等教学科研。

## 与当前实体的关系

- [[章谦之\|章谦之]]的学院任职由其浙江大学官方个人主页支持，属于已核验任职关系。
- Iowa State、Cornell 与 Alabama 等履历属于章谦之个人训练/任职线，不是学院的组织层级。

## 边界
