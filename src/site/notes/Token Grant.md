# Token Grant

Token Grant 是真格基金与十字路口 Crossing 发起的早期 AI 创业支持计划，核心资源不是传统办公室、工资或孵化场地，而是模型 token 与算力试错额度。

## 观察

- Token 成本正在成为 AI 原生创业的早期燃料。对一个人或小团队来说，反复调用模型、测试 agent、构建 demo 和验证产品方向，可能比传统办公资源更先成为约束。
- 该计划把每个入选项目的支持表述为五万元人民币 token 费用，说明投资/孵化机构开始把模型调用能力看成种子期基础设施。
- Token Grant 的门槛叙事是“已经做出第一版产品、正在用 AI 探索新可能”，而不要求必须先成为完整公司。这与 [[人工智能超级个体\|人工智能超级个体]] 和轻量化 AI 创业主体相邻。
- 对 [[Agentic 软件开发工作流\|Agentic 软件开发工作流]] 来说，Token Grant 支持的不是抽象想法，而是能持续运行、迭代和展示的 agent 原型。模型调用成本、运行日志和迭代节奏会进入创业评估。
- Token 资助也会改变投资人和 builder 的互动：讨论对象从商业计划书前移到 demo、运行轨迹、模型选择和实际用户反馈。
- [[Token-maxxing\|Token-maxxing]] 是 Token Grant 的组织级对照面：前者把 token 当作可控试错燃料，后者显示大组织可能把 token 消耗卷成成本和安全压力。

## 边界

- Token Grant 是具体机构计划，不是普遍性的创业融资标准。申请流程、资助金额和资源兑现要以官方入口为准。
- Token 支持能降低试错成本，但不能替代产品需求、数据权限、安全边界和真实分发能力。
