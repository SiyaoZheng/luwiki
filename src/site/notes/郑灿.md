# 郑灿

郑灿（Can Zheng）是[[线性资本]]董事总经理。线性资本团队页称其曾参加 Tata Consultancy Services 的领导力项目并从事业务发展、咨询和新服务引入；后成为[[Morgan Stanley]]中国 IT 团队创始成员，负责多个亚洲市场的交易后平台开发。

其教育端点包括[[浙江大学]]计算机学士、[[上海交通大学]]计算机工程硕士及[[芝加哥大学]] MBA。
