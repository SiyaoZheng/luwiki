# 重庆大学建筑城规学院

重庆大学建筑城规学院是 [[重庆大学\|重庆大学]] 的建筑、城乡规划和风景园林教学科研院系。学院官方介绍列出建筑系、城乡规划系、风景园林系、建筑技术系和建筑历史与理论研究所等组织单元。

## 与当前人物的关系

- 重庆大学官方英文报道记录 Sheng Huaxing 为该院 2014 级本科生。
- 该英文名与 [[盛华星\|盛华星]] 后续在东南大学建筑学院的公示和研究时间线高度吻合，作为本科教育端点记录。

## 证据状态与边界

- 本科经历是高置信跨源匹配，但尚无 ORCID 等唯一标识完成机器级身份穿透。
- 教育经历不代表学院参与、资助或背书 2026 年目标论文。
