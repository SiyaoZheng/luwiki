# Profound

Profound 是面向 AI 搜索和 Agent 时代的营销技术公司节点。它把品牌在 ChatGPT、Claude、Gemini 等模型回答中的出现、引用来源、语境、情绪和竞争对比做成可观测对象。

## 观察

- Profound 的核心问题不是传统网页排名，而是品牌如何被模型和 agent 理解、引用、比较和推荐。这使它与 [[生成引擎优化\|生成引擎优化]] 直接相关。
- Agent-led Growth 把营销对象从“人类点击者”扩展到“替人搜索、判断、推荐和执行的 agent”。企业内容不只要被人看懂，也要被模型消费、复述和用于决策。
- 不同模型的信息偏好可能不同：来源访谈中把 Gemini、ChatGPT、Claude 的引用偏好描述为差异化物种。这意味着 GEO 不能只套用一套 SEO 关键词逻辑，而需要监测模型、问题、语境和证据链。
- 原创洞见成为品牌内容的核心资产。若公开互联网已经被模型充分吸收，品牌需要提供模型尚不知道的新事实、新产品细节、真实用户反馈和可核验证据。
- 对 [[AI 服务市场\|AI 服务市场]] 来说，Profound 这类平台说明 AI 时代的营销服务会从“内容生产”扩展到“模型可见性监测 + agent 化执行 + 证据链优化”。

## 边界

- “SEO 已死”是行业访谈话术，不应理解为搜索引擎优化已经完全消失。更稳妥的观察是，传统 SEO 正在被 AI 搜索、对话式推荐和 agent 决策入口重新分层。
- 对比榜单、长尾落地页和 AI 内容规模化可能短期有效，但也会带来内容污染、激励塌陷和 dead internet 风险。
