# Tripo Studio

Tripo Studio 是 [[VAST\|VAST]] 围绕 [[Tripo AI\|Tripo AI]] 构建的 AI 原生 3D 工作空间，整合生成、分割、重拓扑、贴图、绑定和导出等环节。

## 关系与边界

- **所属公司**：[[VAST\|VAST]]。这是公司—产品关系，不是同一实体。
- **底层产品体系**：[[Tripo AI\|Tripo AI]]。官方文档说明 Studio 与 API 使用同一产品体系，但二者入口和使用场景不同。
- **边界**：Studio 是工具工作流；Tripo H3.1、Tripo P1.0 等是模型版本。它们均不应作为 VAST 的 alias。
