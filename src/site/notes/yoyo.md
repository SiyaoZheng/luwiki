# yoyo

yoyo 是一个以“超越 Claude Code”为目标叙事的自进化编程智能体实验。它把 agent 作为公开运行、持续迭代、接受 GitHub issues 反馈并自我修改代码的对象来展示。

## 观察

- yoyo 的实验价值不在于已经证明它比 Claude Code 更强，而在于它把 [[自进化智能体\|自进化智能体]] 的关键问题具体化：agent 是否能在固定 harness 中读写文件、运行命令、使用 skills、吸收反馈并持续改变自身。
- [[Harness Engineering\|Harness Engineering]] 在这里接近软件工程约束系统。它让 agent 拥有行动空间，也限制它能访问什么、能改什么、如何留下记录。这与 [[Agentic 软件开发工作流\|Agentic 软件开发工作流]] 中的权限、日志和验证循环相邻。
- yoyo 的 human feedback 机制通过 GitHub issues 和社区投票进入进化过程，说明自进化 agent 并不一定是完全离开人类的自主系统；更常见的形态可能是人类反馈、公开记录和 agent 自我修改共同组成的半开放系统。
- 拒绝参考泄漏源码的叙事把 build in public、可审计性和来源边界带入 coding agent 竞争。这与 [[AI Agent 安全\|AI Agent 安全]] 中的权限、来源洁净性和审计要求相关。
- yoyo 被真格 [[Token Grant\|Token Grant]] 资助，说明 agent 本身开始被当作需要 token 供养、拥有运行成本和成长轨迹的创业对象，而不只是人类开发者的工具。

## 边界

- yoyo 的人格化表达应理解为产品叙事和交互设计，不等于它拥有主体地位或真实心理状态。
- 自我增长的代码行数、项目分裂和直播展示不能直接证明软件质量、任务可靠性或安全性。
