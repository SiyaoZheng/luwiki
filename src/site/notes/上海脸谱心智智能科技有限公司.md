# 上海脸谱心智智能科技有限公司

上海脸谱心智智能科技有限公司是[[脸谱心智\|脸谱心智]]的中国运营主体，成立于2023年6月6日。公司由[[陆弘远\|陆弘远]]和[[韦怡然\|韦怡然]]共同创办，业务从大语言模型研究和[[叠叠社\|叠叠社]]等数字角色产品，逐步延伸到[[Looped World Models\|Looped World Models]]与[[Ego-NeuroLoop\|Ego-NeuroLoop]]。品牌页承载产品与技术历史，本页记录法律、融资和治理结构。

## 融资形成的股东结构

公司公开融资历史包括奇绩创坛参与的2024年天使轮、360参与的2025年Pre-A轮，以及星连资本新投、360追加的2026年数千万元融资。当前工商名册已出现北京奇绩创坛二期创业投资中心、北京奇虎科技和北京星连鼎森三类法律载体，使投资报道与直接持股形成对应；但星连资本品牌与北京星连鼎森的管理关系、各轮交割日、金额、估值和稀释过程仍不能仅凭当前名册完整还原。

2026年融资在不同报道中被称为Pre-A或Pre-A+。这种轮次标签差异不会改变工商股东事实，也不应被强行统一。详见[[脸谱心智早期融资\|脸谱心智早期融资]]。
