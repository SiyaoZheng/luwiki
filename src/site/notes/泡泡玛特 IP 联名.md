# 泡泡玛特 IP 联名

泡泡玛特 IP 联名是潮玩角色通过跨品牌、跨风格或跨品类合作制造新鲜感和稀缺性的运营机制。当前来源同时呈现了 [[LABUBU\|LABUBU]] 与三丽鸥联名，以及 SKULLPANDA 与郭培高定视觉结合的两个案例。

## 观察

- 联名的核心不是简单换装，而是风格冲突：LABUBU 的“怪萌”与三丽鸥的甜美，SKULLPANDA 的暗黑幻想与郭培高定的华丽叙事，都在制造社交媒体可讨论的反差。
- 限量发售、隐藏款概率、二级市场溢价和平台讨论共同构成联名热度机制。消费并不只围绕玩具本身，也围绕抢购、晒图、价格波动和身份表达。
- 与 [[Zimomo\|Zimomo]] 的周年系列相比，联名机制更依赖外部 IP 或设计师资源；周年系列更依赖品牌内部角色矩阵和时间叙事。
- [[泡泡玛特\|泡泡玛特]] 的更大机制是把角色放进不同文化场景里反复再语境化。跨品牌联名、体育事件、快餐渠道和设计师合作都可以成为角色传播的外部舞台。
- [[沛纳海\|沛纳海]] 提供了另一个稀缺性管理样本：腕表和潮玩都可以通过限量、识别度和二级传播制造热度，但长期品牌资产取决于消费者是否相信品牌会持续兑现稀缺叙事。

## 边界

- 2025 年报可以核验 THE MONSTERS、授权 IP 和产品品类收入，不能把收入分配到某次三丽鸥联名或某个 SKU。
- 不应把短期溢价直接等同于长期 IP 价值。

## 截至 2026-08-10 的成效答案

- 年报显示 2025 年 THE MONSTERS 收入 141.611 亿元、授权 IP 收入 33.820 亿元、毛绒品类收入 187.081 亿元。这支持“IP 矩阵 + 授权合作 + 品类扩展”已具有显著商业规模。
- 年报没有披露 LABUBU×三丽鸥或 SKULLPANDA×郭培的单项目销量、收入、结算和退货，也没有平台成交数据。因此“一分钟售罄”和二级市场溢价仍停留在媒体/报价层，不升级为联名成效事实。
- 仅在品牌项目复盘、授权结算、可审计 SKU 销售或平台实际成交数据出现时重开具体联名判断。
