# 中国人民大学

中国人民大学是以人文社会科学为重要特色的高校。本页作为学校级父节点，承接院系、实验室和创业团队训练线索。

## 与当前实体的关系

- [[中国人民大学信息学院\|中国人民大学信息学院]]是学校院系节点。境瞳科技报道所称“中国人民大学社会计算与社会智能实验室”未出现在当前学院官方科研目录中，因此只保留为纯文本媒体标签，不建立实验室图边。
- 境瞳科技团队被媒体描述为脱胎于人大信息学院社会计算/社会智能研究网络；这不等于学校投资或持股。

## 边界

“人大系团队”必须拆成具体学籍、任职、实验室或共同项目证据，不能作为模糊背书标签。
