# 张吉

张吉是 [[竹马创新\|竹马创新]] 创始人兼 CEO。36 氪履历材料把其长期经历放在 3D 图形、空间设计软件、产品商业化和消费级空间硬件之间。

## 关系网络

- **创业**：[[竹马创新\|竹马创新]] 创始人兼 CEO；公司官网给出杭州竹马创新科技有限公司 / Hangzhou Bampony Co., Ltd. 的品牌与主体信息。
- **教育**：36 氪与 21 财经均称其毕业于 [[西安交通大学\|西安交通大学]] 计算机相关专业。截至 2026-08-10，学校侧没有可唯一匹配记录，因此保持两家媒体交叉支持，不补写学位、年份和历史院系正式名称。
- **前任职**：两家媒体把其连接到 [[群核科技\|群核科技]] 副总裁与更早的 [[广联达\|广联达]] 任职。截至 2026-08-10，前雇主侧未见人事档案，故确认公开履历叙述，不补写任职起止时间，也不推出竹马创新获得投资或技术承继。

## 边界

- 不能由个人前任职自动推出原雇主投资、技术授权、团队整体迁移或现任员工之间的同事关系。
- “首位同时负责产品与业务的高管”保持媒体引述，不作为机构侧已核验职级；仅在前雇主公告或可核验档案出现时升级。
