# 脸谱心智

脸谱心智（Facemind）是围绕世界模型和人类闭环数据展开的具身智能公司节点。[[陆弘远\|陆弘远]] 的第一人称访谈把自己与 [[韦怡然\|韦怡然]] 列为 founding team，分别负责算法和工程；论文作者单位与工商/融资资料提供了独立的姓名—公司交叉证据。

## 观察

- 脸谱心智把问题从 prompt/agent 的 loop engineering 推到机器人：机器人不只需要任务循环，还需要在视觉、视线、神经信号、肌肉执行和反馈修正之间建立物理闭环。
- 其 [[Looped World Models\|Looped World Models]] 叙事试图把 loop 放进模型架构，通过参数共享的 transformer block 对 latent state 进行多轮 refinement。该模型效果和“世界首个”定位仍以论文/报道为证据口径。
- 其 [[Ego-NeuroLoop\|Ego-NeuroLoop]] 数据范式更值得沉淀：它把第一视角视觉、gaze、EEG 和 sEMG 放到同一时间轴上，试图记录人类如何形成意图、执行动作并根据反馈修正。
- 公司叙事说明 [[具身智能数据基础设施\|具身智能数据基础设施]] 正在继续细分：不只是采集“人做了什么”，而是采集“人为什么这么做、何时意识到偏差、如何修正”。
