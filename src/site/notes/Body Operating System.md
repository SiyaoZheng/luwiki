# Body Operating System

Body Operating System（BOS）是 [[XintLabs\|XintLabs]] 展示的人体智能产品平台。它以运动场景中的身体追踪、动作分析和个体化反馈为切入点，是“[[人体模型\|人体模型]]”这一更一般机制的公司化实现之一。

## 关系与边界

- **所属公司**：[[XintLabs\|XintLabs]]；BOS 与公司不是同一实体。
- **对应概念**：[[人体模型\|人体模型]]；概念可包含其他组织和技术路线，不能反向等同于 BOS。
- **产品能力**：官网展示身体关节点追踪、运动分析和高尔夫场景服务。这些是公司自述，临床、康复或保险用途不能据此视为已验证效果。
