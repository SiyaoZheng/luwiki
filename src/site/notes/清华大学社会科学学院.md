# 清华大学社会科学学院

清华大学社会科学学院是[[清华大学\|清华大学]]的院系节点，2012 年在原人文社会科学学院基础上成立。

## 与当前实体的关系

- [[柯罗马\|柯罗马]]的清华学习和创业转向由学院公开文章支持；具体项目、学位类型和时间应以原文为准。
- 彩丞科技与学院之间的联系经柯罗马个人经历中转，不能写成学院投资或校办企业。

## 边界

学院文章中的校友/学习经历不自动证明同学关系、导师关系或公司获得学校背书。
