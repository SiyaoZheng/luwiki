# 林芝永创信息科技有限公司

林芝永创信息科技有限公司是[[林芝永信科技有限公司]]全资持有的投资法律主体。香港交易所申请文件把其纳入[[腾讯]]投资链；上交所文件则确认其是[[上海火脉投资中心]]的直接有限合伙人。

## 层级与基金份额

- 集团层级：[[腾讯]] → [[林芝永信科技有限公司]] → 本公司。
- 基金层级：本公司认缴[[上海火脉投资中心]] 5,000 万元，占最新出资协议口径的 11.28%。
- 因此正确路径是“腾讯—中间控股主体—直接 LP—基金”，不能缩写为“腾讯直接持有上海火脉 11.28%”。

## 证据口径差异

企查查工商穿透未返回本公司的单一实际控制人；香港交易所文件按集团控制与证券权益披露口径把本公司纳入腾讯链。两类记录回答的问题不同，应并列保存，不能因一方未返回控制人而否定另一方的集团归属披露。
