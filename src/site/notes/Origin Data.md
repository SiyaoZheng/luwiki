# Origin Data

Origin Data 是 [[OriginFlow\|OriginFlow]] 官网 `Solutions` 层的具名采集后数据工作流／交付方案。官方未给出中文产品名。它承接现场记录采集后的质量检查、多模态时间对齐、标注、存储和数据集交付，把记录整理为训练或评估数据集；它不是公司、公开数据目录、数据交易市场，也不是一个固定数据集。

## 产品层级与处理边界

| 层级 | 官网定位 | 可核验关系 |
|---|---|---|
| OriginFlow | 面向 Physical AI 的真实世界数据基础设施品牌／业务 | 对外展示并接洽 Origin Data |
| NeuroScale | `Core Technology` 下的数据采集范式 | 官网称其把肌电、惯性与视觉记录组织为动作、姿态及接触相关信号；该名称不等于独立公司或 Origin Data 的 alias |
| [[Origin Kit\|Origin Kit]] | 同步采集套件 | 官网列出的记录模态包括 sEMG、IMU 与第一视角视频 |
| Origin Data | 采集后数据工作流／交付方案 | 执行质检、跨模态对齐、标注、存储与数据集交付 |

这条链只能用于高层识别产品。官网没有证明 Origin Data 只能处理 Origin Kit 记录，也没有披露三者必须捆绑采购、每个步骤由同一主体完成，或每个项目都包含全部模态。地域、参与人数、任务目录、记录时长、标注团队、质量阈值和实际交付规模均未公开。

## 运营主体与采购入口

OriginFlow 自有 Terms 与 Privacy Policy 只使用品牌名，未写出提供 Origin Data 的法律主体。联想新视界合作链与独立现场报道把 OriginFlow／渊澈太初对应到北京渊澈太初智能科技有限公司；这能支持中国业务主体的识别，但不能单独证明该公司是所有地区、所有 Origin Data 订单的唯一签约方或许可方。更稳妥的图谱路径是 Origin Data → [[OriginFlow\|OriginFlow]] → 该法律主体。

官网公开采购入口只有 `Book a Demo` 联系表单，并称会与少量 builders 接洽。表单收集公司、职位和需求说明；截至 2026-08-12，未发现 Origin Data 的公开 SKU、价目表、计量单位、标准订单、数据目录或自助购买入口。因此可写“销售接洽式入口”，不能据此断言按小时、按记录、按项目、订阅或许可证收费。

媒体在 2026 年 5 月所称约人民币 1,000 元，对象是“一套数据采集设备”，不是 Origin Data 数据服务、数据集或许可的公开价格。设备价格与采集后服务价格不能互换。

## 许可与数据权利边界

OriginFlow 通用 Terms 称，经服务提供的内容、软件、模型、数据和材料由 OriginFlow 拥有或获许可，并限制未经授权利用服务开发竞争产品或数据集。但该页面仍保留准据法占位文本，且没有识别法律主体；它不是 Origin Data 的专项 order form、数据许可证、DPA 或 SLA。

公开文件没有分别说明现场原始记录、客户上传内容、sEMG／IMU／视频、标注结果、派生数据与交付数据集的权属，也没有披露训练权、再许可、转售、排他、删除、返还或项目终止安排。通用 Privacy Policy 面向网站与相关服务使用者，没有专门说明现场作业参与者的招募、同意、补偿、撤回、二次训练或 controller／processor 分工。以上是公开透明度边界，不构成无授权、侵权或违法的证据。

## 合作、供应与交付状态

- 2026-06-30，OriginFlow 与联想新视界已签战略合作，范围包括机器人数据采集、模型训练、工业场景实践及标准化动作数据集共建。公告没有点名 Origin Data，后续工作使用未来时，也没有采购金额、数据集完成或客户验收证据。
- 独立现场报道确认百度云为 OriginFlow 提供云资源、云存储，并协助数据采集、数据后处理与模型训练；行业媒体和投资方材料称双方在 WAIC 期间签署战略合作。该公司级关系支持基础设施供应与协作，不支持把百度智能云写成 Origin Data 买方、数据所有者或已完成集成的客户。
- 58 集团与未具名制造企业的公开口径不一：5 月媒体写“正在合作”，6 月 36 氪主持人把两个场景描述为已经落地，而创始人没有逐项确认订单或验收。两种材料均缺少客户侧订单、金额、验收与 Origin Data 专项命名，故不建立产品—客户图谱边。

2026 年 7 月的独立现场报道确认 OriginFlow 在百度智能云展台演示。该材料最多支持“公开演示”，不能提升为 Origin Data 的 GA、公开下载、付费交付、客户验收、稳定产能或收入。

## 公开可用性核验

| 维度 | 截至 2026-08-12 的公开证据 | 不能推出 |
|---|---|---|
| 产品存在 | 官网已把 Origin Data 列为具名 Solution | 正式发布时间、GA 或普遍可采购 |
| 数据资产 | 名称相符且反向链接官网的 Hugging Face 组织页显示 `None public yet` | 没有私有数据、内部模型或商业交付 |
| 演示 | WAIC 现场演示有独立报道 | 被演示对象必为 Origin Data，或已公开下载、售出、由客户验收 |
| 定价 | 未找到产品公开价格；设备约千元报道属于采集设备 | Origin Data 免费、定价为千元或采用某种计费单位 |
| 客户 | 未找到具名付费客户、订单、中标或验收材料 | 从未有客户或私人合同 |
| 许可 | 只有通用 Terms／Privacy | 客户取得所有权、再许可、转售或排他权 |

## 证据边界

- 官网的“可扩展”及媒体／投资方材料中的“高质量、低成本”均属公司侧定位；未找到公开基准、客户验收或独立审计。
- 合作签署、云资源支持、场景共建、现场演示、采购、数据交付和收入是不同状态，不得互换。
- Hugging Face 的公开页面状态只能说明该账户当时没有公开数据集，不能证明 OriginFlow 没有私有资产或商业交付。
- 本页只写识别产品与商业关系所需的高层处理链，不扩展采集实现、模型、接口或工程部署。
