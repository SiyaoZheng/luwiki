# Psi Data

Psi Data 是 [[灵初智能\|灵初智能]] 官网列出的一站式数据采集平台，面向真实世界灵巧操作数据的采集、标注与持续生产。

## 关系与边界

- **所属公司**：[[灵初智能\|灵初智能]]。
- **相邻方案名**：灵初智能 2026 年公司材料仍使用 [[Psi-SynEngine\|Psi-SynEngine]] 描述具身数采引擎，同时官网为 Psi Data 保留独立产品页。二者同属公司的数据路线，但公开资料没有给出同一产品、前后版本或上下位模块关系。
- **数据集**：[[SynData\|SynData]] 是公开数据集，不等于 Psi Data 平台或公司全部数据储备。
- **边界**：人效、产量和质量属于公司产品口径，仍需部署和第三方评测支持。
