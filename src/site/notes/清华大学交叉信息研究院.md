# 清华大学交叉信息研究院

清华大学交叉信息研究院是[[清华大学\|清华大学]]的教学科研机构，成立于 2011 年，研究领域覆盖计算机科学、量子信息和人工智能。

## 组织层级与关系

- 研究院官方材料将[[清华大学理论计算机科学研究中心\|清华大学理论计算机科学研究中心]]和[[清华大学量子信息中心\|清华大学量子信息中心]]列为其研究机构。
- [[姚期智\|姚期智]]是研究院核心创办和领导人物；这一关系由研究院官方页面支持。
- 研究院人才网络有助于理解清华 AI 创业生态，但不能把“姚班/交叉信息院”泛化为公司关系标签。

## 边界

入选项目、同院学习或参加活动不等于姚期智个人导师关系，也不等于研究院对创业公司投资或背书。
