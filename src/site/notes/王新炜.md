# 王新炜

**王新炜**（Xinwei Wang）是材料科学家、[[北京大学深圳研究生院\|北京大学深圳研究生院]]特聘研究员和博士生导师，研究原子层沉积、薄膜电子材料与光电器件。他于 2008 年在[[北京大学\|北京大学]]获得物理学学士学位，2012 年在[[哈佛大学\|哈佛大学]]获得化学硕士和化学物理博士学位，博士阶段师从原子层沉积研究者[[罗伊·戈登\|罗伊·戈登]]。

王新炜在深圳建立的研究团队把原子层尺度的薄膜生长用于晶体管、光电探测和能源器件。2015 年，团队成员[[高源鸿\|高源鸿]]获得国家奖学金；2016 年，高源鸿、孟鸿与王新炜等人以超薄氧化钒界面层改善有机场效应晶体管的电荷注入；2019 年，高源鸿又与[[李佳\|李佳]]、王新炜、[[孟鸿\|孟鸿]]等人在 *Advanced Materials* 发表混合层有机光电晶体管研究。师生与协作关系由此把原子层沉积、光敏层和器件集成接入汉辉芯辰后来的红外探测路线。
