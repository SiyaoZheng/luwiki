# EMOTIV

EMOTIV 是一个无线 EEG / BCI 设备和平台节点。它把脑电采集从实验室仪器推进到可穿戴产品和真实场景研究，强调传感器可以在有动作和环境干扰的场景中采集人体脑信号。

## 观察

- EMOTIV 的公开产品矩阵覆盖多种 EEG 形态：Epoc X 是 14 通道专业 EEG 头戴设备，MN8 是 2 通道耳机形态，Flex 2.0 提供 32 通道覆盖，Insight 是 5 通道 EEG 头环。
- 这种产品线说明 [[脑电与具身智能\|脑电与具身智能]] 所说的人体状态数据并不只来自一次性实验，也可能来自可穿戴、移动、真实场景的长期采集。
- 对 [[NeuroAI\|NeuroAI]] 来说，EMOTIV 代表设备和平台层：模型能否理解脑反应，前提之一是有足够稳定、可重复、跨场景的采集硬件和数据链路。
- 对 [[以人为中心的具身智能\|以人为中心的具身智能]] 来说，可穿戴 EEG 提供了观察专注、疲劳、认知负荷或交互状态的可能，但也会放大隐私、授权和误读风险。
- EMOTIV 也暴露 [[EEG 数据共享困境\|EEG 数据共享困境]] 的现实面：设备生态越丰富，真实场景数据越容易采集，但通道数、形态、信噪比、平台协议和商业数据边界也会增加跨数据集比较难度。

## 边界

- 当前来源是官网首页抽取，未核验具体设备规格、数据格式、SDK、隐私政策和研究复现质量。
- 官网中的“World's #1”等表述属于产品营销口径，不作为 wiki 中的独立事实结论。
- 可穿戴 EEG 能采集真实场景信号，不等于这些信号已经稳定提升机器人训练、情绪识别或 BCI 控制表现。
