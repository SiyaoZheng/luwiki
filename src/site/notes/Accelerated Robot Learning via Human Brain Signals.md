# Accelerated Robot Learning via Human Brain Signals

Accelerated Robot Learning via Human Brain Signals 是 2020 年 ICRA 论文，作者为 [[Iretiayo Akinola\|Iretiayo Akinola]]、[[Zizhao Wang（EEG-RL）\|Zizhao Wang（EEG-RL）]]、[[Junyao Shi（EEG-RL）\|Junyao Shi（EEG-RL）]]、[[Xiaomin He（EEG-RL）\|Xiaomin He（EEG-RL）]]、[[Pawan Lapborisuth\|Pawan Lapborisuth]]、[[Jingxi Xu（EEG-RL）\|Jingxi Xu（EEG-RL）]]、[[David Watkins-Valls\|David Watkins-Valls]]、[[Paul Sajda\|Paul Sajda]] 与 [[Peter K. Allen\|Peter K. Allen]]。论文把人观察机器人错误时产生的 EEG 错误相关信号用于稀疏奖励导航的早期策略引导。

## 机构与后续碰撞

论文时点作者均标注 [[哥倫比亞大學\|哥倫比亞大學]] 的计算机、Biomedical Engineering 或 Data Science Institute。[[Iretiayo Akinola\|Iretiayo Akinola]] 后续进入 [[NVIDIA\|NVIDIA]]，形成“学术 EEG 机器人反馈研究—商业机器人学习基础设施”的跨时间人物桥梁；这不是 Columbia 与 NVIDIA 的机构合作关系。

## 关键边界

7 名被试中，作者报告 5 名的 ErrP 分类准确率 0.60—0.67 可形成有效引导，另 2 名的 0.56—0.57 未形成有效策略。该结果说明个体差异和解码质量会决定反馈是否有用，不能只引用成功被试。
