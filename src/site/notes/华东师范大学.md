# 华东师范大学

华东师范大学是教育部直属并与上海市共建的高校。本页是学校级父节点。

## 与当前实体的关系

- [[华东师范大学政治与国际关系学院\|华东师范大学政治与国际关系学院]]是校内院系节点，[[华东师范大学世界政治研究中心\|华东师范大学世界政治研究中心]]是相关研究平台。
- [[刘擎\|刘擎]]在该校政治学系任教并担任世界政治研究中心主任；具体职务应按官方人物页和日期更新。

## 边界

任教和研究中心关系不能扩展为对刘擎公共观点的校方背书，也不能从同校自动推断具体同事关系。
