# 香港大学计算与数据科学学院

香港大学计算与数据科学学院是[[香港大学\|香港大学]]于 2024 年成立的学院，整合计算机科学、统计与精算等教学科研力量。

## 与当前实体的关系

- 学院官方体系确认[[李弘扬\|李弘扬]]在港大计算与数据科学领域任职。
- [[香港大学数据智能实验室\|香港大学数据智能实验室]]由数据科学研究院人物页和研究页确认；负责人同时任职本学院。现有页面支持研究院侧归类，不把实验室超写为学院行政系所。
- OpenDriveLab 与学院的当前联系经李弘扬人物关系中转；尚无组织章程支持把平台设为学院下属机构。

## 边界

学院、实验室、开放研究团队和源策未来必须分别建模。
