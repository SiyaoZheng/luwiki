# 中国科学院

中国科学院是国家科学技术界最高学术机构、国家科学技术思想库和国家战略科技力量，所属机构包括大学与研究所。

## 组织层级与关系

- [[中国科学技术大学\|中国科学技术大学]]、[[中国科学院大学\|中国科学院大学]]、[[中国科学院软件研究所\|中国科学院软件研究所]]和[[中国科学院上海微系统与信息技术研究所\|中国科学院上海微系统与信息技术研究所]]都是中科院体系节点，但大学、研究所与院级组织彼此不能互作 alias。
- 阶跃星辰创始人的中科院软件所训练经历必须落到具体研究所，而不能只写“中科院背景”。
- NeuraInsight 团队数据库中的“中科院”教育标签需要确认具体院所。
- 香港中文大学（深圳）官方人物页将[[唐本忠\|唐本忠]]列为中国科学院院士；这是公开成员身份，不等于其任职单位属于中科院体系。
- [[上海科技大学\|上海科技大学]]由上海市人民政府与中国科学院共同举办、共同建设；这是共建关系，不是学校对中科院的简单隶属关系。
- 刘义晛 2018 年论文的机构署名分别落在上海微系统所、中国科学院大学和上海科技大学信息学院页面；院级页面不直接替代这些细分关系。

## 边界

“中科院”不是所有研究所、大学、实验室和投资机构的可互换 alias；具体关系必须落到最细可核验单位。论文联合署名也不能自动证明学位、雇佣或联合培养合同。
