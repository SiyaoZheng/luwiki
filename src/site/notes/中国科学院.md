# 中国科学院

中国科学院是国家科学技术界最高学术机构、国家科学技术思想库和国家战略科技力量，所属机构包括大学与研究所。

## 组织层级与关系

- [[中国科学技术大学\|中国科学技术大学]]和[[中国科学院软件研究所\|中国科学院软件研究所]]均为中科院体系节点，但彼此不是上下级。
- 阶跃星辰创始人的中科院软件所训练经历必须落到具体研究所，而不能只写“中科院背景”。
- NeuraInsight团队数据库中的“中科院”教育标签需要确认具体院所。
- 香港中文大学（深圳）官方人物页将[[唐本忠\|唐本忠]]列为中国科学院院士；这是公开成员身份，不等于其任职单位属于中科院体系。

## 边界

“中科院”不是所有研究所、大学、实验室和投资机构的可互换 alias；具体关系必须落到最细可核验单位。
