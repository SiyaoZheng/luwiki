# 西安交通大学计算机科学与技术学院

西安交通大学计算机科学与技术学院是[[西安交通大学\|西安交通大学]]的计算机学科学院节点。西安交大官方专业介绍确认了学院名称及其计算机科学与技术学科培养体系。

## 层级与关系类型

- `学院—大学`：校内院系隶属关系，官方页面已核验。
- 媒体称张吉毕业于“西安交通大学计算机系”，但未说明就读年代或当时院系的正式名称；在完成历史沿革与校方履历核验前，本页不建立人物边，更不能建立公司边。

## 证据状态与边界

- 学院主体和上级学校已由西安交大官方页面确认。
- 当前没有学院人物页、校友名录或学位信息确认张吉；不能把媒体中的“计算机系”直接升级为现行学院的学籍记录。
- 即使未来确认张吉曾在此学习，也只能建立个人教育经历边；不能由此推出其所创公司获学校孵化、投资、技术转让或官方背书。
