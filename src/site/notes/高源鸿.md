# 高源鸿

**高源鸿**（Yuanhong Gao）是光电探测器研究者和红外芯片创业团队成员，现任[[汉辉芯辰红外科技（杭州）有限公司\|汉辉芯辰红外科技（杭州）有限公司]]董事。他的研究经历连接[[北京大学深圳研究生院\|北京大学深圳研究生院]]、[[中国科学院深圳先进技术研究院\|中国科学院深圳先进技术研究院]]与[[汉辉芯辰\|汉辉芯辰]]，主线从原子层沉积、有机光电晶体管延伸到超薄 X 射线探测和量子点红外成像。

高源鸿在北京大学深圳研究生院进入[[王新炜\|王新炜]]课题组，2015 年获得国家奖学金。2016 年，他与王新炜、[[孟鸿\|孟鸿]]等人以低温原子层沉积的超薄氧化钒界面层改善有机场效应晶体管的电荷注入，把薄膜生长、能级调控和有机半导体器件结合起来。

2019 年，高源鸿在中国科学院深圳先进技术研究院与[[李佳\|李佳]]合作，并与王新炜、孟鸿等人在 *Advanced Materials* 发表混合层有机光电晶体管研究。该器件以高迁移率有机半导体负责载流子输运，以体异质结光敏层产生光生电荷，再用超薄无机界面层促进空穴注入并抑制复合，形成覆盖紫外到近红外的高灵敏探测。2021 年，他作为第一作者和通讯作者之一继续在 *Advanced Materials* 发表超薄异质结光电晶体管 X 射线探测器，将约 50 纳米光敏层、机械柔性和高分辨成像组织进同一器件结构。

2023 年，高源鸿与孟鸿等人申请有机异质结晶体管光电探测器和有机紫外光电探测器专利。2025 年，他进入汉辉芯辰杭州公司的董事会；同年 11 月，北京大学深圳研究生院在高交会展示孟鸿团队成果转化的量子点及有机红外成像芯片。由此，高源鸿早期形成的界面层、光电晶体管和柔性探测研究，进入短波与中波红外芯片的产业转化链。
