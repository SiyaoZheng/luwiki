# 重庆明月湖智能科技发展有限公司

重庆明月湖智能科技发展有限公司是重庆市科技局公开名单所列的 [[明月湖国际智能产业科创基地\|明月湖国际智能产业科创基地]] 运营管理机构。

## 关系与边界

- `运营公司—基地`：2023 年重庆市众创空间拟认定名单直接支持。
- 当前来源不足以穿透公司股东、实际控制、具体基金管理或其与 XbotPark 其他地区平台的法律关系。
- 基地品牌、运营公司和具体孵化基金不得互作 alias；涉及项目支持时由独立事件页中转。
