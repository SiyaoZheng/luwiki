# 街景视域因子

街景视域因子把街道行人视角中的天空、树木和建筑可见比例转成可计算城市环境变量。典型指标包括天空开阔度 Sky View Factor（SVF）、树木视域 Tree View Factor（TVF）和建筑视域 Building View Factor（BVF）。

## 观察

- 街景图像让城市环境测量从俯视或 3D-GIS 模型推进到行人视角。SVF、TVF 和 BVF 描述的是人在街道峡谷中实际能看到的天空、树冠和建筑关系。
- 基于 Google Street View 的方法可以先把街景全景图转换为鱼眼图像，再用语义分割模型识别天空、树木和建筑，最后计算视域因子。
- 来源中的香港研究用实地半球摄影验证 GSV 方法，说明街景深度学习测量可以与现场测量形成可比证据，而不只是生成漂亮地图。
- GSV 与 3D-GIS 的 SVF 差异提示：三维城市模型如果缺少行道树，会高估天空开阔度。树木不是环境装饰，而会直接改变热环境、可见性和空间体验测量。
- 对 [[人本城市模拟\|人本城市模拟]] 来说，街景视域因子提供了身体尺度的环境变量；对 [[WUDAPT\|WUDAPT]] 来说，它补充了 LCZ 等城市形态分类之外的街道微环境测量。
- 对 [[城市环境犯罪因果效应\|城市环境犯罪因果效应]] 来说，街景视域因子说明街景并不只用于感知评分，也可以被拆成更可解释的物理/视觉结构变量。

## 边界

- 街景数据受拍摄时间、覆盖范围、图像质量、季节、树木遮挡和平台更新频率影响。
- SVF、TVF、BVF 是环境测量变量，不等于人的舒适度、幸福感或安全感本身；这些心理/行为结果仍需要额外测量和理论模型。
