# 华南理工大学

华南理工大学是教育部直属高校，设五山、大学城和[[华南理工大学广州国际校区\|华南理工大学广州国际校区]]等校区。

## 与当前实体的关系

- [[吴贤铭智能工程学院\|吴贤铭智能工程学院]]是广州国际校区学院节点，由华南理工大学与密西根大学安娜堡分校共建。
- 共建学院不改变学院属于华南理工大学的基本组织层级，也不使合作高校成为同一法人。
- [[唐本忠\|唐本忠]]的学校官方履历记载其于 1982 年获华南理工大学学士学位；这支持个人教育经历，不推出具体同学、导师或现行任职。

## 边界

校区、学院、合作大学和企业合作必须分别建模；不能把广州国际校区写成独立大学。
