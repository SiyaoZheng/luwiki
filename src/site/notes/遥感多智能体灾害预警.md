# 遥感多智能体灾害预警

遥感多智能体灾害预警指把卫星观测、轻量早筛、专题专家模型和决策融合 agent 组合起来，在带宽与星上算力受限条件下完成灾害检测、解释和预警。

## 观察

- 灾害遥感的瓶颈不只是检测精度，也包括时效、带宽、星上算力和多模态数据选择。把全部数据传回地面再统一处理，会牺牲早期预警窗口。
- 分层多智能体框架把任务拆成 Early Warning Agent、Specialist Agents 和 Decision Agent：先低成本判断是否触发，再按灾种调用光学、SWIR、SAR 等专家分析，最后融合证据做决策。
- 事件驱动机制是核心：无灾害或低风险场景不必调用全部复杂模型，这使资源受限环境中的 agent 设计更接近 [[Harness Engineering\|Harness Engineering]] 和边缘计算问题。
- 这种路线把 [[AgentSociety²\|AgentSociety²]] 中的灾害响应场景进一步推向真实传感器和遥感基础设施：agent 不只模拟人群行为，也可以参与环境观测和预警链路。
- 对 [[智能社会治理\|智能社会治理]] 来说，遥感多智能体预警提供了公共风险治理样本：它需要把模型判断、解释、延迟、误报漏报和响应流程一起设计。

## 边界

- 当前来源是论文解读，实验指标和系统可部署性需要回到 arXiv 原文、代码和星上硬件条件核验。
- “卫星自己思考”是传播性表达，更准确地说是把部分推理和决策前移到星上或边缘遥感处理链路。
