# Oracle Corporation

Oracle Corporation 是一家在美国特拉华州注册、主要执行办公室位于得克萨斯州奥斯汀的上市科技公司。公司以企业数据库、云基础设施、企业应用、硬件和服务为主要业务。Oracle、甲骨文等品牌称谓不能自动替代具体产品、地区签约法人或集团子公司。

## 法律身份与上市主体

- FY2026 Form 10-K 披露的注册人为 **Oracle Corporation**，EIN 54-2185193，主要执行办公室为 2300 Oracle Way, Austin, Texas 78741。
- 普通股在纽约证券交易所交易，代码 **ORCL**。10-K 还列有代表 Series D 强制可转换优先股权益的存托股份 ORCL-PRD；这一证券清单本身不提供该优先股的全部投票或控制条款。
- 截至 2026 年 6 月 12 日，10-K 列示 2,880,471,000 股普通股在外流通。公司、普通股、优先股和具体子公司的法律权利不能合并成同一个“Oracle”节点。

## 起源、名称与总部时间线

- Oracle 官方公司历史把经营起点追溯至 1977 年：Larry Ellison、Bob Miner 和 Ed Oates 创办 Software Development Laboratories。
- 官方公司时间线把 Relational Software Inc. 改称 Oracle Corporation 放在 1982 年；Oracle 数据库官方历史材料则写作 1983 年 RSI 先改为 Oracle Systems Corporation，之后才成为 Oracle Corporation。两条官方材料的年份和中间名称不完全一致，本页保留冲突，不把它们拼成未经证明的单一法定承继链。
- FY2026 10-K 列示的主要执行办公室位于 Austin；该口径不等同于逐州工商注册记录或所有运营地点。

## 股权集中与治理

- 2025 年 proxy 以 **2025 年 9 月 19 日**为记录日，披露 [[Larry Ellison\|Larry Ellison]] 受益持有 1,158,232,353 股普通股，占 40.6%；其中 346,000,000 股被质押以担保其个人债务。该值是普通股的日期化快照，40.6% 不是过半持股，也不能被写成 2026 年实时持股或“绝对法定控制”。
- 当前 Oracle 领导页列 Larry Ellison 为执行董事长兼首席技术官；Safra Catz 为董事会执行副主席；Clay Magouyrk 与 Mike Sicilia 为共同首席执行官；Hilary Maxson 为首席财务官。
- 2025 年 9 月 22 日的管理层变更公告显示：Catz 自 2014 年起担任 CEO，随后转任执行副主席；Magouyrk 与 Sicilia 升任共同 CEO。公告当时还把 Doug Kehring 称为 Principal Financial Officer，而现行领导页列 Maxson 为 CFO，两个时点和头衔不能互相覆盖。

## 业务与产品层级

FY2026 10-K 把经营活动分成三个业务／经营分部：cloud and software、hardware、services；损益表又按 cloud、software、hardware、services 四类收入列示。经营分部、收入类别、产品品牌和法律主体不是同一层级。

- Oracle Cloud 由 [[Oracle Cloud Applications\|Oracle Cloud Applications]] 与 [[Oracle Cloud Infrastructure\|Oracle Cloud Infrastructure]]（OCI）组成。前者承接企业应用订阅，后者承接计算、存储、网络、数据库及其他基础设施服务；两者都是产品／业务组合，不是独立上市法人。
- [[Oracle Database\|Oracle Database]] 是数据库产品家族；[[Oracle Database@Google Cloud\|Oracle Database@Google Cloud]] 是把 Oracle 数据库服务放到 Google Cloud 数据中心、并通过双方渠道销售的联合多云产品，不能当作合资公司。
- [[Oracle Health\|Oracle Health]] 是医疗健康业务与产品品牌；其与历史 Cerner 法律主体、监管登记和客户合同需要分层。
- [[Oracle NetSuite\|Oracle NetSuite]] 是云应用品牌／业务组合。Oracle 2016 年完成 NetSuite 收购，不等于当前所有 NetSuite 产品、合同和人员都由一个可由品牌名直接识别的法人承接。

## FY2026 财务口径

截至 2026 年 5 月 31 日的财年，10-K 合并损益表列示：

| 收入类别 | FY2026 收入 |
|---|---:|
| Cloud | 339.89 亿美元 |
| Software | 245.41 亿美元 |
| Hardware | 30.84 亿美元 |
| Services | 57.43 亿美元 |
| **合计** | **673.57 亿美元** |

- FY2026 GAAP 净利润为 170.87 亿美元。云收入内部，cloud applications 为 158.88 亿美元，cloud infrastructure 为 181.01 亿美元。
- Oracle 的 FY2026 业绩稿把剩余履约义务（RPO）列为 6,380 亿美元，并把自由现金流列为负 236.86 亿美元。RPO 是尚未确认的合同履约承诺，不是当期收入、现金余额或利润；自由现金流也不能归因到某个单一产品或客户。
- 10-K 明确称 FY2026、FY2025 和 FY2024 均无单一客户贡献总收入的 10% 或以上；同时又提示部分 OCI 产品对若干大型客户更集中，并涉及大型长期云安排和基础设施投入。因此，“没有单一 10% 客户”不等于没有客户集中或大合同风险。

这些链接只表示它们被 Oracle 的 SEC 附件列为集团子公司，不表示全部由母公司直接持有，也不提供逐层股权比例、职能或完整集团清单。尤其不能把当前 Exhibit 中的 Oracle Systems Corporation 与 1980 年代历史材料里的同名／近名主体直接互作 alias。

Oracle 官方合同体系通常由 master agreement、order document 与相关服务政策共同构成。部分美国在线云、软件许可与 NetSuite 范本以 Oracle America, Inc. 作为“Oracle”签约方；这只能证明相应范本和地区的合同角色，不能外推为 Oracle Corporation 母公司或 Oracle America 是全球所有客户的唯一合同相对方。

## Cerner 收购与医疗业务

- Oracle 与 Cerner 于 2021 年 12 月 20 日公告收购协议，报价为每股 95 美元、约 283 亿美元股权价值；交易于 2022 年 6 月 8 日完成。固定关系路径为 **Oracle Corporation → [[2022 Oracle 收购 Cerner\|2022 Oracle 收购 Cerner]] → Cerner Corporation**，不以公司之间的直连替代交易事件。
- Oracle 当前法律说明把 Cerner Corporation 称为 Oracle 的全资子公司，并说明部分健康 IT 认证与医疗器械登记仍由 Cerner Corporation 持有。这支持把 Oracle Health 品牌与 Cerner 法律主体分开；不能推出所有合同、员工、资产和监管登记都已迁移到 Oracle Health 品牌下。

## 与 Google Cloud 的合作关系

2024 年 6 月，Oracle 与 [[Google Cloud\|Google Cloud]] 宣布多云合作；同年 9 月，Oracle Database@Google Cloud 在美国和欧洲四个 Google Cloud 地区正式可用。公开安排支持以下商业关系：

- Oracle 在 Google Cloud 数据中心内直接运营和管理 Oracle 数据库服务；
- 双方对 Oracle Database@Google Cloud 共同 go-to-market，并提供联合客户体验和支持；
- 客户可经 Google Cloud Marketplace 采购，并使用既有 Google Cloud commitments 与 Oracle 许可优惠；
- Oracle Interconnect for Google Cloud 连接 OCI 与 Google Cloud。

截至 2026 年 4 月，Oracle 公告称该产品已覆盖 15 个地区，并把 Worldline 列为使用案例。Worldline 的采用与效益是供应商托管的客户证言，只能作为公开采用线索，不能推出合同金额、完整迁移、独立绩效或收入归属。

公开 Service Description 显示至少三种结算路径：普通 annual credits／PAYG 由 Google 向客户开票、客户向 Google 付款；direct funded allocation 由 Google 按月计费／出账，但客户向 Oracle 付款；partner PAYG／funded allocation 则由 Google 向 Oracle Partner 开票，Partner 再向客户开票。公开材料没有给出 Oracle 与 Google 的收入分成、总额／净额会计、排他性或单一全球签约主体。

因此，这是一条可核验的联合产品、渠道和运营关系，不是合资、持股或并购关系；双方在底层云基础设施和企业客户预算上仍可同时竞争。

## 竞争与客户边界

- 10-K 把 Adobe、Alphabet、Amazon、Cisco、Intel、IBM、Microsoft、Salesforce、SAP、HPE 与 Workday 等列为不同业务线的直接竞争者；医疗 IT 领域还列举 Epic、athenahealth、InterSystems 等。该清单来自公司风险披露，不是独立市场份额测量。
- 合作和竞争可以并存。Oracle 与 Google Cloud 的特定多云安排不消除 Oracle 与 Alphabet 在其他企业云和软件业务上的竞争。
- Oracle 的全球客户包括企业、政府、教育机构和经销商。公开客户故事或联合新闻稿不能自动证明付费金额、合同相对方、续约、排他性或可归因收入。

## 证据等级与不能推出

- **A级**：SEC 10-K、definitive proxy、Exhibit 21；可支持法定身份、证券、日期化持股、合并财务和被披露子公司集合。
- **A／B级**：Oracle 与 Google Cloud 双方公告、Oracle 合同文件；可支持产品运营、联合销售、Marketplace 和结算路径，但不公开收入分成与客户合同额。
- **公司口径**：Oracle 历史、客户采用、产品能力和未来扩区；需要保留宣传来源与前瞻性边界。
- 不把 40.6% 受益持股写成过半或绝对控制；不把 OCI、OCA、Oracle Database、Oracle Health、NetSuite 写成独立上市法人；不把 Exhibit 21 当作完整直接持股图；不把联合产品写成合资；不从总云收入、RPO 或客户案例倒推出某产品收入与利润。

## 历史管理人物：Rodrigo Liang

[[Rodrigo Liang\|Rodrigo Liang]] 在 2010 年 Oracle 完成收购 Sun 后进入 Oracle 管理体系；Oracle 官方会议页曾把他列为 **SVP, Hardware Development**，白宫 PCAST 讲者简介则称其负责 SPARC Processor 与 ASIC development。两种表述是同一高管职责的不同摘要，不据此拆成多个职位。[[2010 Oracle收购Sun Microsystems\|2010 Oracle收购Sun Microsystems]]承载组织承继事件；公开材料没有披露 Liang 的精确离职日或具体雇佣子公司，因此本页不把 Oracle Corporation 母公司自动写成其唯一法定合同雇主，也不由这段履历建立 Oracle 与其更早雇主或后来创办公司的直边。
