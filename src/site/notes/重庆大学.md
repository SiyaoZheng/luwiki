# 重庆大学

重庆大学是中央直管、教育部直属的综合性重点大学，具有建筑与工程教育传统。

## 与当前实体的关系

- 建筑学长 AI 创始人文怀伟的重庆大学建筑学研究生训练来自公开报道。截至 2026-08-10，本轮未找到学校人物/校友页或学位档案，因此保持媒体等级，不补写学位与年份；仅在校方记录出现时升级。
- 公司与学校之间没有已核验投资、孵化或知识产权关系。
- [[重庆大学建筑城规学院\|重庆大学建筑城规学院]] 是重庆大学的学院节点；盛华星的本科阶段公开线索通过该学院连接，不据此建立其与重庆大学其他项目或公司的关系。
- 重庆大学官方英文报道记录 [[盛华星\|盛华星]] 为建筑城规学院 2014 级本科生；结合东南大学公示与后续署名，这是高置信跨源匹配，但尚无 ORCID 唯一标识。
