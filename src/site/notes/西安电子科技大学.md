# 西安电子科技大学

西安电子科技大学是以信息与电子学科为主的教育部直属高校。

## 与当前实体的关系

- 星尘智能创始人来杰的西电本科经历由多家媒体报道支持。截至 2026-08-10，本轮未找到学校人物或校友页，因此该人物—学校关系保持媒体等级；仅在校方档案出现时升级。
- 该训练线索与后续百度、腾讯机器人团队经历是不同关系边。

## 边界

同校背景不等于星尘智能由西电孵化、投资或获得技术授权，也不能自动推出校友团队成员关系。
