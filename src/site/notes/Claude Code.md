# Claude Code

Claude Code 是 [[Anthropic\|Anthropic]] 开发运营、归入 Claude 品牌组合的商业产品。它在 2025-02-24 以有限研究预览亮相，2025-05-22 由 Anthropic 宣布核心产品正式可用。它不是独立公司、独立融资主体或开源项目；产品身份、合同主体、销售渠道与公司整体财务必须分开。

官方 `anthropics/claude-code` 仓库的 `LICENSE.md` 标注 © Anthropic PBC、All rights reserved，并把使用约束指向商业条款；公开仓库或个别开源组件不等于核心产品采用开源许可证。

## 从研究预览到商业产品

| 日期 | 事件 | 边界 |
|---|---|---|
| 2025-02-24 | Anthropic 首次公布 Claude Code，称为 limited research preview 和 early product | 不是正式商用发布 |
| 2025-05-22 | Anthropic 宣布 Claude Code generally available | 指核心产品；不能自动外推到后来每个网页、桌面或第三方入口 |
| 2025-09-02 | 公司称产品已于 5 月 fully launched，run-rate 超过 5 亿美元 | 这是公司自报年化口径 |
| 2025-12-03 | 公司在 [[Anthropic收购Bun\|Anthropic收购Bun]] 公告中称 11 月达到 10 亿美元 run-rate | 收入节点与收购事件同时披露，但不是收购价格或估值 |
| 2026-02-12 | 公司称产品 run-rate 超过 25 亿美元 | 截至 2026-08-11 仍是最后一个公开的产品专属数字 |

后续某些入口仍可能处于 Beta 或 research preview。官方页面对 2026 年 Desktop 状态也存在“已 GA”与“仍为 Beta”的冲突，因此本页只把 2025-05-22 视为核心产品正式可用时点。

## 采购入口与价格

截至 2026-08-11，Claude Code 同时进入个人订阅、团队席位、企业合同、按量采购和云市场渠道。

| 入口 | 当前公开口径 | 交易边界 |
|---|---|---|
| Pro | 年付 200 美元，折合 17 美元/月；或月付 20 美元 | Claude 与 Claude Code 共用计划额度；独立按量使用另计 |
| Max | 5x 为 100 美元/月；20x 为 200 美元/月 | 只提供月付，移动端价格可能不同 |
| Team | 2—150 席；Standard 年付 20／月付 25 美元每席每月，Premium 年付 100／月付 125 美元 | 当前每个 Team 席位均包含 Claude Code；2025 年 premium-only 是历史规则 |
| Enterprise | 新版公开入口为年付 20 美元/席/月，使用量另计 | 自助与销售协商合同并存；旧客户可能保留历史席位 |
| 按量与云渠道 | Anthropic 直接采购，以及 [[Amazon Web Services\|Amazon Web Services]]、[[Google Cloud\|Google Cloud]] 和微软云渠道 | 渠道与账单路径不等于产品所有权或终端客户关系 |
| [[AWS Marketplace\|AWS Marketplace]] | 公共 12 个月示例为 20 席、4,800 美元，使用量另计 | 可以定制报价，公开 listing 不是所有客户的实际合同 |

价格会变，也不能覆盖税费、折扣、历史合同与全部协商条件。网页标价不等于确认收入或客户付款。

## 谁与客户签约

产品品牌不等于唯一法律主体。消费者条款把个人服务合同方写为 Anthropic, PBC；商业条款则规定：

- 欧洲经济区、瑞士和英国的直接商业客户原则上由 [[Anthropic Ireland, Limited\|Anthropic Ireland, Limited]] 签约；
- 其他地区的直接商业客户原则上由 Anthropic, PBC 签约；
- 云市场与第三方渠道交易还适用渠道方条款和客户既有协议。

因此，“Claude Code 客户”不能自动画成所有客户与 Anthropic, PBC 直接签约。商业条款下的输入／输出权利安排，也不赋予客户 Claude Code 软件、品牌或源码的所有权。

## 收入与采用：只能按公司口径解释

| 截点 | Claude Code 公司自报 | 同期不能归给产品的公司级数字 |
|---|---|---|
| 2025-09 | run-rate 超过 5 亿美元；三个月使用量增长超过 10 倍 | Anthropic 超过 30 万商业客户、全公司 run-rate 超过 50 亿美元 |
| 2025-11（12 月披露） | run-rate 达到 10 亿美元 | 公告点名客户，但没有披露席位、留存或合同金额 |
| 2026-02 | run-rate 超过 25 亿美元；周活跃用户自年初翻倍、商业订阅四倍、企业使用贡献过半收入 | Anthropic 全公司 run-rate 140 亿美元、500 多家年化支出逾 100 万美元客户 |
| 2026-05 | 没有更新产品专属数字 | Anthropic 全公司 run-rate 超过 470 亿美元 |

Run-rate 是把当时收入节奏年化，不是审计后的 GAAP 收入、ARR、利润、现金回款、订单或市场份额。公司整体客户数、融资和估值也不能自动分配给 Claude Code。

## 客户证据的强弱

### 客户侧确认

- [[Rakuten Group\|Rakuten Group]] 确认采用 Claude Code，并称某项目周期从 24 天缩短到 5 天；这是客户内部口径，不是独立因果评估。
- [[Salesforce\|Salesforce]] 在 2025 年确认全球工程组织部署，2026 年又称已向所有工程师 rollout、内部 adoption 超过 90%；生产率数字仍是客户自报。
- [[ServiceNow\|ServiceNow]] 称 Claude 覆盖 29,000 多名员工，并把 Claude Code rollout 到工程、开发和技术团队；29,000 不是 Claude Code 席位数。
- [[PwC\|PwC]] 宣布从美国开始 rollout，并计划扩大到全球、培训认证 30,000 人；这是未来扩展计划，不是已完成活跃用户数。
- [[Cognizant\|Cognizant]] 宣布采用 Claude，计划最多覆盖 350,000 名员工，并在工程工作中使用 Claude Code；计划上限不是已部署席位。
- [[Coinbase\|Coinbase]] 称到 2026 年初所有工程师都可访问 Claude Code、[[Cursor\|Cursor]]、[[GitHub Copilot\|GitHub Copilot]] 和 OpenCode；access 不等于使用、付费席位、留存或独家标准。

### 厂商案例与点名

- Anthropic 与 [[Accenture\|Accenture]] 的客户案例称 [[Cox Communications\|Cox Communications]] 约有 2,500 名 Claude Code 用户，且过半为非技术人员；这是厂商托管案例。
- Anthropic 在 Bun 收购公告中点名 [[Netflix\|Netflix]]、[[Spotify\|Spotify]]、[[KPMG\|KPMG]]、[[L'Oréal\|L'Oréal]] 和 Salesforce 为企业使用者。Salesforce 另有客户侧确认；其他名称在没有同级材料前只能写成“Anthropic 点名”。

这些材料可以证明关系、部署或计划的某一层，但 deployed、access、planned rollout、active users、paid seats 与 audited outcomes 不能互换。

## Bun 收购与产品关系

Anthropic 于 2025-12-03 公布 [[Anthropic收购Bun\|Anthropic收购Bun]]，并把 [[Bun\|Bun]] 团队加入 Claude Code 产品方向。该公告同时披露产品 10 亿美元 run-rate，却没有披露收购价格。Bun 继续按自身开源许可运营，不改变 Claude Code 自身的商业许可，也不能证明收购产生了特定金额的协同收益。

## 竞争与多供应商采购

[[GitHub Copilot\|GitHub Copilot]] 与 [[Cursor\|Cursor]] 是企业采购场景中的替代产品。Coinbase 同时开放多种产品，说明企业可以采取多供应商并用；它不提供可比的实际使用、支出或留存数据。媒体对竞争格局的描述和厂商各自的 run-rate、用户数口径也不统一，不能据此排列全球份额或宣布领导地位。

## 不能推出

- 核心产品 GA 不等于所有后续入口都已 GA。
- 网页价格不等于每一份企业合同、确认收入或现金回款。
- Run-rate 不等于审计收入、ARR、利润、订单或市场份额。
- Anthropic 全公司客户、收入、融资和估值不等于 Claude Code 产品数据。
- 客户自报、厂商案例、未来计划与独立效果审计不是同一级证据。
- 云市场渠道不等于产品所有权、终端客户或单一合同主体。
- 客户的输入／输出权利不等于拥有 Claude Code 产品或源码。
- Bun 继续开源不等于 Claude Code 开源。
