# 红熊AI

红熊AI是由 [[上海算模算样科技有限公司\|上海算模算样科技有限公司]] 运营的品牌/产品公司节点，核心叙事是“记忆科学 + 多模态大模型”。品牌与法律主体分别建模，不互作别名。它把企业级 AI 应用的瓶颈解释为记忆、上下文连续性、幻觉控制和场景适配问题，并围绕 OpenBear、MemoryBear、CodeBear 和原生 Agent 架构组织产品路线。

## 观察

- 2026 年 7 月，红熊AI宣布完成 A+ 轮融资。36氪和投资界口径均称融资金额为数亿元人民币、投后估值接近 30 亿元人民币；具体资本端点统一经 [[红熊AI A+轮融资\|红熊AI A+轮融资]] 事件页中转。
- “15 个月完成 6 轮”和“18 个月完成 6 轮”是两个公开口径，当前更适合把它理解为快速连续融资，而不是固定采用某一个月数。
- 红熊AI把 [[AI 记忆系统\|AI 记忆系统]] 做成企业级 AI 的基础层：显式记忆、长期上下文、语义剪枝、自我反思、Agent 协作和行业知识沉淀共同构成产品卖点。
- 当前商业化集中在智能客服、智能营销、ChatBI、智能教育等 To B 场景；这说明“AI 记忆”首先被包装为降低重复沟通、提高服务一致性和提高业务分析效率的工程能力。
- 公司已经公开平台文档、MemoryBear 代码与自发布评测制品；这比纯营销指标更可检查，但仍不是独立 benchmark、真实客户案例或长期续费证据。

## 截至 2026-08-10 的产品与评测答案

- 红熊平台文档公开了模型支持、Prompt 编排、RAG、企业知识库、工作流和 API；MemoryBear 仓库提供 Apache-2.0 代码、部署说明与服务依赖；Hugging Face 仓库提供 LongMemEval、LoCoMo 的逐题输出、检索记忆和汇总指标。
- 评测制品由项目方发布并复现基线，生成和裁判模型也由项目方统一选择；数据集网页预览还报告字段不一致错误。因此这些材料支持“可检查的自评”，不能写成独立复现、生产性能、成本优势或隐私合规。
- 营收、客户数与续费仅在客户侧案例、审计口径或独立长期评测出现时重开。

## 关系

- [[AI 记忆系统\|AI 记忆系统]]：红熊AI是国内把“记忆层”明确产品化和融资叙事化的案例。
- [[AI Agent 安全\|AI Agent 安全]]：长期记忆会提高 Agent 的连续执行能力，也会放大权限、隐私、纠错和遗忘机制的重要性。

## 三同关系线索

- 核心人物是田轩宇。36氪和投资界报道把其列为红熊AI创始人兼 CEO，并给出康奈尔大学计算机专业和创业经历线索。
- 同事/团队线索包括 OpenBear、MemoryBear、CodeBear 与企业服务交付团队；但当前公开来源不足以写具体联合创始人、导师或同学关系。
- 地缘/组织线索是 [[上海算模算样科技有限公司\|上海算模算样科技有限公司]]；投资关系统一在 [[红熊AI A+轮融资\|红熊AI A+轮融资]] 中记录，不等于三同关系。
