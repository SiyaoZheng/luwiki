# Stanford University

Stanford University（斯坦福大学）是美国加利福尼亚州的研究型大学。官方页面将其学术结构概括为七所学院；本库只为直接服务商业实体关系或产品主张的校内学院、实验室、研究项目和人物建立必要节点。
