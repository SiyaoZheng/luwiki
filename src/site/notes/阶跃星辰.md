# 阶跃星辰

阶跃星辰（StepFun）是上海的大模型公司节点，核心观察不是单轮融资或估值，而是多模态基础模型、终端场景和国产芯片适配正在被组织成同一个生态叙事。

## 观察

- 阶跃星辰把技术路线表述为从单模态、多模态到世界模型和 AGI 的连续推进。这个叙事与 [[世界模型\|世界模型]]、多模态生成和 agent 应用都相邻。
- [[模芯生态创新联盟\|模芯生态创新联盟]] 说明，大模型竞争不只是模型参数和榜单竞争，也包括模型与芯片、推理框架、云平台和终端厂商的联合适配。
- Step 3 和相关开源/开放计划把“国产芯片友好”变成产品定位的一部分：模型设计、推理效率和部署成本被放到同一张产业图里。
- 文章中的投资分析、估值和融资展望只作为来源语境，不写入本页判断。对本 wiki 来说，更重要的是模型-芯片-应用的协同结构。
