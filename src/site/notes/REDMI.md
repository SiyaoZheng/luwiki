# REDMI

**REDMI**（历史英文写法 Redmi，中文常称“红米”）是[[小米集团\|小米集团]]旗下消费电子品牌。它起于2013年的红米手机系列，2019年1月被集团纳入双品牌战略并与[[小米\|小米]]形成相互独立的产品品牌。这里的“独立”是品牌定位与经营分工，不是法人分拆：公开文件没有显示 REDMI 是独立公司、上市主体、股权子公司或单独报告分部。

2024年11月启用的当前品牌标识及较新的官方材料多采用全大写 REDMI；旧产品页和部分仍在线的地区／旧代目录继续使用 Redmi。这是视觉与品牌写法升级，不是法律实体或商标权利主体的更名。

## 品牌、法律与运营边界

| 层级 | 已核角色 | 不能推出 |
|---|---|---|
| 品牌 | REDMI 是小米集团产品与经营品牌；2019年后与 Xiaomi／小米品牌并列 | 不是“REDMI公司”，也不是可独立合并、融资或上市的法体 |
| 上市与合并披露 | [[小米集团\|小米集团]]的开曼发行人 Xiaomi Corporation 披露集团品牌、产品与财务 | 发行人不当然是每个地区 REDMI 设备的制造商、卖方、售后方或活动主办方 |
| 商标证据 | WIPO域名裁决把 XIAOMI、Mi 与 REDMI列为 Xiaomi Inc. 使用的商标；招股文件把 Xiaomi Inc. 对应为[[小米科技有限责任公司\|小米科技有限责任公司]] | 单一裁决或法域记录不能证明全球所有类别的完整商标权链 |
| 产品制造与销售 | 具体设备可由[[小米通讯技术有限公司\|小米通讯技术有限公司]]等集团实体承担制造、合规或销售职能；地区网站与活动另有当地主体 | 任一中国或地区公司都不能据单一文件被写成全球唯一 REDMI 运营公司 |

地区条款显示这种主体分工不是抽象风险。2026年马来西亚 REDMI Note 15 系列活动由[[Xiaomi Technologies Malaysia Sdn. Bhd.\|Xiaomi Technologies Malaysia Sdn. Bhd.]]组织；台湾同系列活动由[[台湾小米通讯有限公司\|台湾小米通讯有限公司]]组织。两条证据只支持对应活动与地区安排，不证明两家公司拥有 REDMI 品牌，也不能覆盖经销商、电商平台或其他市场的合同主体。

## 品牌演化与定位

| 时间 | 事件 | 证据边界 |
|---|---|---|
| 2012 | WIPO品牌案例把“Redmi计划”追溯至2012年 | 属机构整理的公司品牌史，不是独立法人设立 |
| 2013年中 | 小米推出首款红米智能手机 | 当时是小米旗下手机系列／子品牌；本页不把更细日期当成统一的发布与销售起点 |
| 2019-01 | 小米年报称 Xiaomi 与 Redmi 自该月起成为相互独立品牌，并启动双品牌战略；Redmi Note 7是该阶段首款产品 | 品牌分离不等于公司分拆或股权独立 |
| 2024-11 | 品牌视觉标识统一为全大写 REDMI | 不是法体或商标权利人的法律更名 |
| 2025—2026 | 中国与全球目录继续按地区更新手机、平板、穿戴和音频产品 | 动态目录只能证明访问时点的产品组合，不能倒推历史首发或全球统一供应 |

2019年公司把 Xiaomi 品牌描述为更聚焦先进技术、中高端和新零售，把 Redmi 描述为追求高品质、可及价格与当时的线上渠道。这是品牌升级时的历史定位，不能固化为今天“REDMI只做低端或只在线销售”。中国商城中 K 系列已覆盖更高价格带，当前渠道也包含小米官网、门店、授权零售商和电商伙伴。

## 管理与集团关系

[[卢伟冰\|卢伟冰]]于2019年加入小米时曾任集团副总裁兼 Redmi 总经理。小米2025年年报与当前投资者关系页面显示，他现为集团合伙人、集团总裁兼手机部总裁，并负责 REDMI 相关的品牌、产品规划、制造、销售和营销工作。应按现行集团职务书写，不能把历史“Redmi总经理”继续当作其2026年现职，也不能据品牌职责创造“REDMI CEO”这一未披露头衔。

雷军在2019年品牌升级时对外说明 REDMI 战略，但其公开法定角色仍位于小米集团。公开集团层面的品牌职责负责人是卢伟冰；小米当前投资者关系页面没有披露现任“REDMI品牌总经理”。现有公开材料也没有给出一张 REDMI 独立董事会、完整管理层或单体组织架构表。

## 产品组合

REDMI已从手机系列扩展为多品类消费电子品牌。产品系列是品牌端点，不是公司或财务报告分部。

| 产品层 | 当前可稳定指认的系列 | 地区与口径边界 |
|---|---|---|
| 智能手机 | [[REDMI Note系列\|REDMI Note系列]]、[[REDMI A系列\|REDMI A系列]]以及数字系列 | 全球目录持续列出 Note、A与数字系列；型号、内存、网络制式和发布日期按市场变化 |
| 中国大陆手机 | [[REDMI K系列\|REDMI K系列]]、[[REDMI Turbo系列\|REDMI Turbo系列]]，以及 Note、数字系列 | 中国商城出现不等于同名机型全球销售；中国和全球代际可并行 |
| 平板 | [[REDMI Pad\|REDMI Pad]]及中国市场的 K Pad | 平板型号、蜂窝版本与上市范围按地区判断 |
| 穿戴 | [[REDMI Watch\|REDMI Watch]]及部分地区的 REDMI Band | 不证明所有穿戴设备运行同一系统版本 |
| 音频 | [[REDMI Buds\|REDMI Buds]]及其他 REDMI 耳机 | 全球目录出现不等于每个国家均在售 |
| 其他中国品类 | 电视、REDMIBook笔记本、显示器、路由器等 | 属访问时点的中国目录，不外推为全球组合 |

2026年1月15日全球 REDMI Note 15 系列发布页明确提示：具体型号、销售日期、功能与可用性取决于当地供应。它因此是全球产品发布证据，而不是所有国家同日开售或中国同名系列同步更新的证据。

## 软件平台关系

部分 REDMI 手机、平板和穿戴设备使用[[Xiaomi HyperOS\|Xiaomi HyperOS]]；更早设备使用过[[MIUI\|MIUI]]。HyperOS 是小米集团的跨设备软件平台品牌，REDMI 是采用该平台的硬件品牌之一，两者不存在所有权倒置，也没有独立的“REDMI HyperOS”。

中国大陆与全球 HyperOS 页面分别列出适配设备和推送波次。预装、Beta计划、soft release和实际到达用户设备是不同阶段；不能写成所有 REDMI 产品在同一日期完成系统迁移，也不能把某款手机的 Android 基线推广到电视、穿戴或其他设备。

## 渠道与地区运营

REDMI在2019年品牌升级时以线上为重要渠道，但当前销售已纳入小米集团的全渠道体系，包括官网、Xiaomi Stores、小米之家、授权电商与授权零售商。集团披露的中国和海外门店数量服务多个品牌与产品，不能改写为 REDMI 专卖店数。

地区目录差异具有实质意义：

- 全球手机目录当前以 Note、A与数字系列为主，并另列 REDMI 平板、手表和耳机。
- 中国大陆目录还包括 K、Turbo、电视、笔记本、显示器和路由器。
- 具体活动、销售和售后责任可能由当地小米公司、授权经销商或第三方商家承担。

因此，品牌覆盖“全球市场”不等于每个市场有相同SKU、价格、卖方或服务条款；官方首发价也不是持续成交价或集团平均售价。

小米2025年年报只按“手机×AIoT”和“智能电动汽车、AI及其他新业务”两个报告分部披露。REDMI手机进入集团智能手机口径，平板、电视、穿戴与音频进入IoT与生活消费产品口径；公司没有单列REDMI收入、利润、毛利率、ASP、年度出货、MAU、客户集中度或品牌市场份额。

## 供应与合作边界

两组公开文件提供了可核验但必须限于单款产品的商业关系：

- [[2026 REDMI Note 15 5G供应链披露\|2026 REDMI Note 15 5G供应链披露]]：该型号官方FAQ列出Qualcomm Snapdragon 6 Gen 3、Samsung Semiconductor工艺、Visionox／BOE屏幕及Corning保护玻璃。它是单一SKU与文件时点的供应披露，不证明品牌级独家、采购份额或所有机型采用。
- [[2025 REDMI K90 Pro Max与Bose音响合作\|2025 REDMI K90 Pro Max与Bose音响合作]]：小米2025年第三季度披露称该型号的2.1三扬声器系统与Bose合作开发及联合调音。它不证明股权关系、排他条款或REDMI全品牌的长期联盟。

小米集团年报披露的匿名前五客户与供应商集中度仍不能下放到REDMI，也不能由产品规格反向识别匿名主体。

## 竞争边界

REDMI横跨入门、主流与更高价格带，不存在一个覆盖全部手机、平板、电视和穿戴产品的统一竞争集合。可核的竞争观察必须限定产品、地区和分母：Counterpoint的2025年第一季度全球型号sell-through榜把Redmi 14C 4G与多款[[Samsung Galaxy A系列\|Samsung Galaxy A系列]]机型列在同一前十榜；Omdia的2026年第一季度拉美分析则在同一地区的分价位竞争版图中分别讨论Note 15、Samsung A系列与[[Motorola Moto G系列\|Motorola Moto G系列]]部分型号。两类材料只建立同榜或同地区的型号／系列层市场参照，不证明这些产品是一对一直接竞品、整个品牌完全可替代或拥有统一份额。

Omdia同时明确其“Xiaomi”厂商估计包含POCO和REDMI。这证明厂商统计不能下放为REDMI品牌份额；现有公开披露仍不足以给出REDMI跨品类总市场份额或行业排名。

## 证据边界

1. REDMI是品牌，不是公司、子公司、上市主体或独立报告分部。
2. 2019年“独立品牌”表示品牌定位和经营分工，不表示法律、股权或财务独立。
3. 当前全大写REDMI是标准视觉写法；Redmi与红米仍是历史和中文别名，不是不同实体。
4. 商标权、制造／合规主体、商城平台、销售合同、售后与地区活动主办方必须逐法域、逐文件判断。
5. 中国、全球与单一国家目录不能互相替代；型号、价格、系统版本和发布时间均可能不同。
6. 历史累计销量、系列累计出货、型号级sell-through和集团厂商出货不能相加或互换。
7. 集团收入、ASP、毛利、份额、MAU、客户和供应商集中度不得下放为REDMI品牌数据。
8. 某一SKU的供应、认证或营销权益不等于品牌级独家或长期合作。
9. 截至2026年8月12日，公开材料未显示REDMI拥有独立融资、并购、董事会、法定高管名册或单体审计报表。
