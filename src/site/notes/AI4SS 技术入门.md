# AI4SS 技术入门

AI4SS 技术入门是一个面向社会科学研究者的公开讲座节点。它把 AI 从聊天机器人转向智能体系统的变化，放到社会科学研究链条中理解：文献综述、研究设计、数据处理、机制建模、验证和写作都可能被 agent 基础设施重塑。

## 观察

- 对社会科学来说，AI4SS 的关键不是“更快写作”，而是研究流程中哪些环节可以被结构化、审计和复用。
- 讲座把“从聊天到智能体”作为范式变化：聊天模型主要回答问题，智能体系统则可以围绕目标、工具、上下文、记忆和验证循环组织工作。
- 这与 [[可执行社会科学\|可执行社会科学]] 的方向一致：研究问题、理论机制、数据处理、仿真配置和结果解释需要被接成可运行 workflow。
- 这也与 [[实证研究智能体工作流\|实证研究智能体工作流]] 相邻：README、skills、provenance、verification、permissions 和 stopping rule 是社会科学 agent 基础设施的基本对象。
- 公开讲座类来源适合作为教学/传播节点，不等于提供了完整方法论文或可复现实验结果。
