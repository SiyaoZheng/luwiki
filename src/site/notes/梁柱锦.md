# 梁柱锦

梁柱锦是[[北京章鱼灵动科技有限公司]]联合创始人，公开材料把其职责重心放在世界模型、强化学习和具身技术研发。

## 经历与核验层级

- [[中山大学人机智能融合实验室]]官方校友页列出梁柱锦为[[中山大学]]硕士校友，毕业去向为[[北京地平线机器人技术研发有限公司|地平线机器人]]，独立支持其教育与早期任职关系。
- 公司自述其为[[中山大学]]本硕、[[清华大学创新领军工程博士项目|清华创新领军工程博士]]；清华项目经历本轮未取得学校一侧的个人名单确认。
- 2023年鉴智机器人与地平线合作材料称其为[[鉴智机器人]]副总裁、感知产品线负责人，和[[都大龙]]共同出席产品合作活动。
- 章鱼动力公司材料称其曾任鉴智技术副总裁、地平线早期员工，负责世界模型、强化学习等方向。

## 关系线索

- 已核验共事：与都大龙在鉴智机器人共同任职，并在2023年同一公开合作活动中出现。
- 共同前雇主：与都大龙、[[潘杨家一]]、[[樊庆元]]都存在地平线任职线索。
- 同校项目线索：与都大龙均被章鱼动力称为[[清华大学创新领军工程博士项目|清华创新领军工程博士]]；不据此推断私人关系或严格“同门”。

## 边界

独立来源能够确认中山大学硕士—地平线去向，以及鉴智副总裁/感知产品线负责人身份。章鱼动力中的正式职务、清华项目经历和技术分工目前主要依赖公司第一方材料。
