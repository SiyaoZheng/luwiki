# NAFAS

NAFAS（Neuroadaptivity for Autonomous Systems）是 [[德国网络安全创新署\|德国网络安全创新署]] 与 [[Zander Laboratories GmbH\|Zander Laboratories GmbH]] 于 2023-12-15 签署的约 3,000 万欧元、四年期神经技术研发项目。

项目旨在开发非侵入式神经技术原型，并联合 Fraunhofer IDMT、TNO、Brain Products、Eaglescience 以及多所大学。现有来源把这些机构列为分包或学术协作方；在没有分别建立稳定端点前，本页不对它们创建不确定图谱边。

## 关系边界

NAFAS 是研究合同和资助项目，不是 Zander Labs 的股权融资，也不能用项目总额推断公司收入、估值或可自由支配资金。
