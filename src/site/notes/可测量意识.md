# 可测量意识

可测量意识指神经科学试图用脑活动的复杂性、整合性和可扰动响应来判断一个系统是否仍具备产生主观经验的能力。它不直接读取意识内容，而是测量意识能力的边界。

## 观察

- 意识测量的临床核心问题是“无反应是否等于无意识”。隐匿意识和认知-运动解离提醒，外显行为可能沉默，但脑内任务理解或经验能力仍可能存在。
- 扰动复杂度指数（PCI）把问题从行为反应转向脑系统因果复杂性：给大脑一个扰动，再观察响应是否在多个区域展开、是否具有复杂而非重复的时空结构。
- 整合信息理论（IIT）提供相邻理论背景：意识被理解为一种不可约、整合且分化的因果结构，而不是单纯信息量或局部脑区活动。
- 对 [[NeuroAI\|NeuroAI]] 来说，可测量意识提供了一个边界案例：AI 可以帮助建模脑活动和复杂系统，但意识判断仍涉及临床伦理、理论争议和第一人称经验不可直接观测的问题。
- 这一路线把意识科学从“寻找相关脑区”推进到“一个系统是否具备产生经验的组织能力”的测量问题。

## 边界

- PCI、PCI-ST 和 IIT 都不是无争议答案；阈值、适用人群、设备条件和临床解释都需要专业评估。
- 本页面不提供医疗建议，也不把公众号中的医疗模型推广内容写入知识判断。
