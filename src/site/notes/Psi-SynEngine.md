# Psi-SynEngine

Psi-SynEngine 是 [[灵初智能\|灵初智能]] 对具身数采引擎的公开命名。公司 2026 年材料仍使用该名称，描述其通过穿戴式手套采集人类真实操作数据，并把数据送入质检、标注与审核管线；它不再只是媒体使用的早期名称线索。

## 截至 2026-08-10 的结论

- **名称存在已闭合**：灵初智能 2026-03-10 的公司文章明确使用“Psi-SynEngine 具身数采引擎”，并称其用于获取真实交互数据。它是公司仍在使用的方案名，而非只能由媒体转述支持的旧称。
- **公开产品面被拆成不同层**：[[Psi Data\|Psi Data]] 有独立产品页，定位为一站式数据采集平台；ψ-SynGlove 与 ψ-SynGlove Air 有硬件和 SDK 文档。公开材料没有给出三者的版本、上下位、交付或计费关系，因此本页不把它们互设 alias。
- **部署证据仍是主体侧口径**：公司文章称已在真实物流客户仓库完成小规模场景验证，世界机器人大会展商页重复该说法；公开材料没有任务清单、样本量、成功率、失败分布或客户签章，不能升级为独立部署验证。
- **成本主张尚不可复算**：公司 CEO 称手套采集的综合成本约为真机遥操作的十分之一；没有公开工资、设备折旧、质检返工、有效轨迹率和跨本体转换成本，故该数字只能作为公司口径。
- **不是独立 release**：当前官网产品导航没有 Psi-SynEngine 的独立产品页、版本说明、许可、API 或服务条款。现有证据支持“公司方案名”，不支持把它视为已经标准化对外发布的软件产品。

## 证据分级与重开条件

- 名称与公司归属：公司一手材料支持。
- 硬件可操作性：公开 SDK 文档支持 ψ-SynGlove 系列，但不能替代对整套数采引擎的审计。
- 性能、成本与客户价值：仍缺独立 benchmark 和可复算材料。
- 仅在出现版本化产品文档、公开 API/许可、客户或第三方对照评测、以及可复算成本表时，才重开“是否已经标准化发布、是否确有数量级成本优势”的判断。
