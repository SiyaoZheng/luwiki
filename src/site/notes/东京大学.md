# 东京大学

东京大学是 [[EgoBrain\|EgoBrain]] 论文与数据集的机构端点之一。论文时点，[[Nie Lin（EgoBrain）\|Nie Lin（EgoBrain）]]、[[Ryosuke Furuta\|Ryosuke Furuta]] 与 [[Yoichi Sato\|Yoichi Sato]] 标注该校；官方数据页以 UT-Vision 与 [[微软亚洲研究院\|微软亚洲研究院]] 的共同研究展示项目。

## 关系边界

这里建立的是论文署名和项目合作关系，不表示东京大学对任何 MindSpace、OriginFlow、脸谱心智、Encord 或 Zander Labs 商业主张背书。
