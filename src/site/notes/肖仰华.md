# 肖仰华

肖仰华是[[复旦大学计算与智能创新学院\|复旦大学计算与智能创新学院]]教授，也是[[复旦大学知识工场实验室\|复旦大学知识工场实验室]]负责人和[[上海市数据科学重点实验室\|上海市数据科学重点实验室]]主任。当前来源把他的研究方向放在知识图谱、大模型和自进化智能体，并记录了他围绕[[数字分身\|数字分身]]的一次公开自述。

## 观察

- 肖仰华在来源中把个人文本、微信消息、公开文章、采访和演讲材料组织为数字分身素材，提出一种工程化的人格描述框架。
- 这个人物节点与 [[AI 记忆系统\|AI 记忆系统]]、[[自进化智能体\|自进化智能体]] 和 [[AI Agent 安全\|AI Agent 安全]] 的交叉点在于：当 AI 能以某个人的身份持续互动时，记忆、身份、授权和责任会成为同一个系统问题。
- 来源中的“计算灵魂学”更像一个面向公众的概念表达，当前不应当直接提升为成熟学科。

## 三同关系线索

- **同校/任职**：复旦官方页面显示，肖仰华 2009 年获复旦大学博士学位后留校任教；当前任职机构以[[复旦大学计算与智能创新学院\|复旦大学计算与智能创新学院]]人物页为准。学籍和任职同属一校但属于不同关系，不能合并成泛化“复旦系”。
- **实验室职务**：官方简介将其列为[[复旦大学知识工场实验室\|复旦大学知识工场实验室]]负责人和[[上海市数据科学重点实验室\|上海市数据科学重点实验室]]主任。负责人、主任、学生和合作企业是不同角色，不能由实验室成员关系自动推断同门或公司关系。
- **关系含义**：其数字分身和自进化智能体观点应放在复旦知识图谱、认知智能和大模型应用研究网络中理解，而不是孤立看成个人随笔。
