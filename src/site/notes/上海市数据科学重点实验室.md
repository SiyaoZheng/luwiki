# 上海市数据科学重点实验室

上海市数据科学重点实验室是依托[[复旦大学\|复旦大学]]建设的省市级重点实验室，2013 年批准筹建、2015 年验收挂牌。

## 与当前实体的关系

- 官方页面将[[肖仰华\|肖仰华]]列为实验室主任，属于已核验任职关系。
- [[复旦大学知识工场实验室\|复旦大学知识工场实验室]]是实验室内部研究网络的重要相邻节点，但不能与本实验室合并。

## 边界

重点实验室依托复旦，不是独立大学；负责人、研究室、项目和企业合作应分别建模。
