# 柯罗马

柯罗马是[[彩丞科技\|彩丞科技]]的联合创始人、董事和 CEO。现有资料呈现的是一条跨学科创业路径：从[[武汉大学\|武汉大学]]哲学专业转入软件工程，毕业后进入通信行业，再于 2021 年进入[[清华大学社会科学学院\|清华大学社会科学学院]]心理学系博士项目。

## 观察

- 教育路径横跨哲学、软件工程和 MBA，职业路径横跨通信销售/市场与传统制造创业。
- 创业对象不是互联网软件，而是以 3D 光学材料和印刷包装为核心的硬科技/制造业公司。
- 该案例显示，“软件工程背景 + 销售/战略经验”可以进入传统材料和包装行业，形成偏产业应用的技术创业。

## 关系

- [[彩丞科技\|彩丞科技]]：柯罗马参与创办并经营的 3D 光学材料公司。

## 三同关系线索

- **武汉大学学籍**：武汉大学印包系全国校友会访谈称其 1999—2002 年学习哲学、2002—2004 年转入软件工程，支持[[武汉大学\|武汉大学]]公开校友叙述。截至 2026-08-10，本轮未取得教务/学位档案，故不补写具体学位和院系沿革；仅在学校档案出现时升级。
- **清华学习经历**：[[清华大学社会科学学院\|清华大学社会科学学院]]官方文章明确把柯罗马列为心理学系 2021 级博士生，并回顾其更早的清华硕士学习。这一页面支持社科学院博士学籍，不能把文中未具名同学升级为具体私人关系。
- 同学/同伴影响可谨慎记录：清华文章提到其在班级创业氛围中受到同学创业选择影响，但未点名具体同学，因此只能写成“班级/学院创业氛围线索”，不能外推成具体同学关系。
- 公司关系是 [[彩丞科技\|彩丞科技]] 联合创始人、董事和 CEO。后续若讨论材料、印刷包装或防伪产业链，应优先补工商、投资方和客户案例，而不是只依赖校友访谈。
