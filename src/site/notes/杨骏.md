# 杨骏

杨骏（Jun Yang）是[[线性资本\|线性资本]]合伙人、[[达达集团\|达达集团]]共同创始人及前 CTO。他的公开履历把浙江大学与 CMU 的训练、Google／Facebook／Square 的工程管理、达达创业以及线性投资连接成一条连续路径。

## 可核验时间线

| 时间 | 角色 | 证据 |
|---|---|---|
| 2008—2009 | [[Google LLC\|Google LLC]]工程师 | 达达证券文件 |
| 2010—2014 | [[Meta\|Facebook]]工程经理，负责用户增长和广告优化 | 达达证券文件 |
| 2014—2015 | [[Block\|Square]]增长工程团队负责人 | 达达证券文件 |
| 2015—2023 | [[达达集团\|达达集团]]共同创始人、CTO；2020 年起曾任董事 | 达达证券文件与线性加入公告 |
| 约 2023—2025 | 天使投资人、创业顾问、线性资本资深顾问 | 线性加入公告 |
| 2025-06 起 | 线性资本全职合伙人 | 线性团队页与加入公告 |

教育方面，线性与达达文件支持其获[[浙江大学\|浙江大学]]计算机学士、硕士，并获[[Carnegie Mellon University\|Carnegie Mellon University]]计算机硕士、博士。

## 人物关系：从旧同事到合伙人

[[王淮\|王淮]]公开称杨骏是其 Facebook 老同事和浙大学长，并称杨骏回国创业后二人交流更频繁。达达文件给出的杨骏任期与王淮公开任期使共同窗口至少覆盖 2010—2011 年，详见[[2010-2011 王淮与杨骏在Facebook共事\|2010-2011 王淮与杨骏在Facebook共事]]。该关系不是从履历相似性推断，而由王淮本人明确确认。

杨骏 2008—2009 年的 Google 任职与旧页[[洪锋\|洪锋]]、[[Sundar Pichai\|Sundar Pichai]]发生同期重叠，见[[2008-2009 杨骏与洪锋在Google任职重叠\|2008-2009 杨骏与洪锋在Google任职重叠]]。目前没有同团队、汇报关系或共同项目证据。

[[Peter Thiel\|Peter Thiel]]在 2005—2022 年担任 Facebook／Meta 董事，覆盖杨骏员工任期；这只是一条治理层—员工层同期边，不证明直接认识或合作。

## 商业角色边界

- 达达 2020 年 F-1 将杨骏列为共同创始人、CTO、受益所有人，并说明其将于注册声明生效后任董事；后续文件给出董事任期变化。
- “带领公司上市”来自线性第一方简介，不能把 IPO 归因于单一个人。
- 加入线性前以资深顾问参与多个项目，是机构口径；未披露项目清单、个人决策权或经济权益。
- Google、Facebook、Square 的连续任职不自动形成三家公司之间的商业关系。
