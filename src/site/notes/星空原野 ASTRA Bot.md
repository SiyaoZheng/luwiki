# 星空原野 ASTRA Bot

星空原野 ASTRA Bot 是 [[星空原野\|星空原野]] 在公司/投资方访谈中披露的星空摄影智能体规划，拟把位置、时间、天气、月相、拍摄规划和移动端后期处理组织成一个工作流。

## 截至 2026-08-10 的发布状态

- **规划名称已确认**：线性资本组合文章与融资报道都把 ASTRA Bot 分成创作建议系统和图像处理引擎；前者计划提供地点、时间、天气、月相、拍摄参数建议，后者计划在手机端完成堆栈降噪、拼接、色彩还原和多素材融合。
- **仍未形成公开 release**：Asterra 官方当前公开销售 Asterra Z+，产品页把 Planit 作为规划工具；官网未检出 ASTRA Bot 独立产品页、下载入口、应用商店条目、服务条款、版本说明或公开测试。
- **计划时间尚未到达**：投资方文章把新一代 Robot Camera 的目标写为 2026 年 10 月，其他报道写为 2026 年第四季度并计划优先通过 Kickstarter 众筹。二者都是前瞻性计划，不是已上线事实。
- **预期配套但未交付**：投资方材料把 ASTRA Bot 与 [[星野 Robot Camera\|星野 Robot Camera]] 放在同一软硬件路线中；官方产品页目前使用 Planit，尚无公开 release 能说明 ASTRA Bot 是否已完成集成，亦不能据此推断 Planit 已替代 ASTRA Bot。
- “ASTRA Bot”在互联网中存在其他同名产品；本页标题加入公司前缀，不能与同名 Discord 机器人或其他项目合并。
