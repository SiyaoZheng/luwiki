# 深圳科创学院

深圳科创学院是李泽湘于 2021 年创立的硬科技创新创业平台。官网称其围绕人才培养、课程、供应链、市场资源和基金构建创业支持体系。

截至 2026-08-10，官网概况称平台有 900 余名创业者和 90 余个在孵项目。官网把 2—4 周的科创训练营、面向全职创业者的正式项目孵化等路径分开，因此“参加过学院活动”“进入训练营”“正式入孵项目”和“校友/导师关系”不能互换。

## 关系网络与边界

现有证据可以确认深圳科创学院的平台身份，但不能确认秦深涛参与的正式批次或项目归属；人物—平台关系不能因采访中的一句经历叙述升级为已核验三同或导师关系。

## 截至 2026-08-10 的关系答案

- 学院官网、概况页及公开索引没有检索到秦深涛、元信号数据科技、NEO FLOW 或 OriginFlow 的个人、项目、批次或校友条目。
- 因而当前最强结论仍是：投资界采访支持秦深涛曾在该平台接受创业孵化，但公开材料不能识别具体项目、批次、时间或参与层级，也不能证明早期项目或后来公司进入正式孵化体系。
- 这不是一个可以靠平台概况补齐的事实。只有学院官方名单/项目页、结营证书、双方公告或可核验档案出现时才重开；在此之前不升级为正式校友、在孵项目或李泽湘个人导师关系。
