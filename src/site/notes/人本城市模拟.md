# 人本城市模拟

人本城市模拟把城市从道路、建筑、人口和交通流的工程对象，转向由日常行为、情感反应、文化习惯和空间实践共同构成的可计算环境。它与 [[社会世界模型\|社会世界模型]] 相邻，但更具体地落在城市规划、建筑、数字人文和参与式仿真。

## 观察

- François Penz 提出的 AI-driven human-centric urban simulation 把电影作为城市行为数据来源：从跨文化剧情片中提取人的移动轨迹、身体距离、手势、情感表达和日常活动序列，再转化为可编程的 agent behavior。
- 这个路线把电影从“再现城市”的媒介，变成“抽取城市生活模式”的数据层。它不是直接把电影当真实城市数据，而是把影像中的空间行为作为建模线索，再通过用户、规划师和社会学家的交互反馈验证。
- 技术链条由四段组成：多模态 AI 影像分析、行为/情感 agent 建模、虚幻引擎中的三维城市环境、以及参与式验证循环。
- 与传统智慧城市相比，人本城市模拟强调不可轻易量化的生活质感：公共空间吸引力、身体距离、日常节奏、文化差异和空间情绪。这使它同时接近 [[以人为中心的具身智能\|以人为中心的具身智能]] 与城市数字人文。
- [[AgentSociety²\|AgentSociety²]] 提供相邻路线：它把城市移动、灾害响应、社交媒体和公共品博弈等场景封装为可执行社会实验环境，使人本城市模拟可以连接到更广的 [[社会世界模型\|社会世界模型]] 和 [[可执行社会科学\|可执行社会科学]]。
- [[MindSpace\|MindSpace]] 把空间样本、传感信号和心理响应组织成空间数据库，提示人本城市模拟的输出也可能变成可检索的空间记忆层。
- [[WUDAPT\|WUDAPT]] 提供城市气候和 Local Climate Zone 分类数据入口，说明人本城市模拟还需要环境、建筑形态和热环境底图，而不只是人物行为数据。
- [[DataShareClub\|DataShareClub]] 补充逐小时天气、AQI、湿度、能见度和太阳辐射等动态环境变量，这些变量可能影响出行、户外活动、情绪和公共健康。
- [[心理世界模型\|心理世界模型]] 把城市模拟中的“人”进一步推向 mental states：行为轨迹之外，意图、信念、情绪和社交预期也可能成为人本模拟的状态变量。
- [[APRU 可持续城市与景观年会\|APRU 可持续城市与景观年会]] 把人本城市问题扩展到气候风险、基础设施道德生态、公共健康、城市更新、社区参与和跨区域知识共创，提示人本模拟的变量不应只停留在个体行为层。
- [[城市情绪反应建模\|城市情绪反应建模]] 提供了现场数据路线：用 GIS、EEG、空间特征分类、ABM 和 LLM 叙事连接城市移动、身体感受和空间设计反馈。
- [[电单车出行环境优化\|电单车出行环境优化]] 把人本城市模拟推进到微出行场景：骑行者在道路条件、安全感、制度规范和目的地约束之间做选择，这些行为很难只用传统交通流变量解释。
- [[SounDiT\|SounDiT]] 把声景纳入人本城市模拟：环境声音可以被转译为地理语境图像，使听觉经验、视觉景观和场所感知进入同一个可讨论的模拟对象。
- [[街景视域因子\|街景视域因子]] 提供行人视角的物理环境输入：天空、树木和建筑可见度可以成为热环境、舒适度、空间压迫感和行为模拟的解释变量。
- [[建成环境具身智能感知\|建成环境具身智能感知]] 提供从测量到设计反馈的上位框架：在城市、邻里、场地三种尺度上，把空间形态与人的具身感知连接到采集、分析、评价和预测。它补足了模拟前的数据组织和模拟后的评价环节，但预测结果仍不能自动解释为设计干预的因果效应。
- 该路线仍有关键不确定性：电影镜头包含导演选择、叙事功能和美学偏差，不能直接当作真实城市行为分布；需要真实城市影像、传感、眼动、访谈或现场实验校准。

## 截至 2026-08-10 的答案

- **当前方法不能复现。** 对项目名称、负责人和 AI-driven human-centric urban simulation 的精确检索仍只得到项目沟通会层材料，没有公开论文、代码、数据、行为编码表或可运行模型。最低复现包应包括影片抽样框、镜头/人物/行为标注本体、标注一致性、提取模型与版本、观测到 agent rule 的转换函数、参数不确定性、真实城市校准样本和 out-of-sample 验证。
- **跨文化差异必须先拆除电影生产偏差。** 影片类型、年代、导演/镜头选择、审查、叙事功能和发行市场都可能与城市文化混杂。分类体系至少需要多地区真实现场数据对照、分层标注者、测量不变性/差异项检验和不确定性；电影中的频率不能直接当成居民行为率。
- **规划增益尚未被验证，但验证标准可以确定。** 应在真实规划任务中比较“规划师+传统数据”与“规划师+模拟”，预先定义行为/空间预测、方案选择质量、弱势群体影响、解释时间和实施后结果；如果只比较 3D 场景丰富度或叙事感，不能证明决策增益。论文、代码、评测或实际规划案例是重新开启证据升级的触发条件。
