# 星海图

星海图 / Galaxea 是一个具身智能公司节点。当前来源把它放在“本体 + 智能 + 真实数据 + 开放生态”的组合路线中，用来观察具身智能公司如何从机器人整机 demo 转向系统工程和数据飞轮。

## 观察

- 星海图的核心叙事不是单独卖机器人本体，而是把本体、模型、真实场景数据和应用生态组织成闭环。这个闭环与 [[具身智能系统工程\|具身智能系统工程]] 的判断一致：机器人智能不能只靠模型参数，还要受制于硬件、数据、端侧时延和供应链。
- 来源中的 G0.5 和 Fast-WAM 叙事把 VLA 与世界模型放在融合关系中，而不是互斥路线。对 [[世界模型\|世界模型]] 来说，这说明世界模型可能作为动作生成和反馈预测的一部分进入真实机器人控制链路。
- 100 万小时真实数据计划把竞争焦点推到 [[具身智能数据基础设施\|具身智能数据基础设施]]：真实机器人数据、数据质量、采集成本、清洗回流和联盟机制共同决定模型迭代速度。
- [[高继扬\|高继扬]] 关于“具身大概率不会出现 GPT 时刻”的判断，把商业化从爆发式拐点改写为 2B 场景逐步渗透。这里的核心不是一次性通用能力跃迁，而是一个场景、一个场景地打开生产力任务。

## 边界

- G0.5、Fast-WAM、榜单、成本和百万小时计划都来自会议报道口径，需要公司官方资料、公开模型、数据计划和第三方评测继续核验。
- 官网当前可以访问；其产品、客户、部署和排名仍属于公司侧口径，需要文档、代码、客户或第三方评测分别核验。
- “卖本体 -> 卖订阅 -> 卖 Token”是商业蓝图，不代表当前收入结构已经进入后两个阶段。

## 三同关系线索

- 核心人物是 [[高继扬\|高继扬]]。世界机器人大会资料把他列为星海图 CEO；公司官网/介绍材料把星海图定位为“整机 + 智能”的具身智能公司。
- 同事/共事网络应以团队角色写入：公司介绍列出赵行、许华哲、李天威、虞磊等关键成员，并出现 Waymo、Momenta、清华大学、UC Berkeley、MIT、USC 等履历线索。在逐名人物页闭合前，这些聚合团队画像不形成公司到前雇主/学校的直接图边，也不代表 [[高继扬\|高继扬]] 本人曾任职于上述机构。
- 地缘/生态线索目前可写北京总部、苏州硬件设计及制造子公司、全球客户和开发者生态。[[星海图融资与产业资本\|星海图融资与产业资本]] 已用港交所公告闭合北京机器人产业基金的投资关系；该关系经融资事件中转，仍不能从园区或活动共现推断其他资本关系。
