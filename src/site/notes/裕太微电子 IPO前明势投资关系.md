# 裕太微电子 IPO前明势投资关系

[[明势资本]]官网称其是[[裕太微电子]]最早的机构投资人和唯一天使轮投资方；裕太微招股书还披露黄明明曾任董事，并列出北京明势合讯资本管理有限公司、嘉兴自知股权投资管理有限公司等关联主体。

“明势资本”品牌、管理公司、基金载体和上市前股东必须分层。当前材料不足以把[[曾颖哲]]的项目归因提升为个人持股、董事席位或退出收益。
