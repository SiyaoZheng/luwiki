# 复旦大学知识工场实验室

复旦大学知识工场实验室是[[复旦大学\|复旦大学]]知识图谱研究平台，源于图数据管理实验室，聚焦大规模知识图谱构建、管理与应用。

## 与当前实体的关系

- 官方简介将[[肖仰华\|肖仰华]]列为实验室负责人，属于已核验任职关系。
- 实验室与[[上海市数据科学重点实验室\|上海市数据科学重点实验室]]共享部分人员和研究场域，但两者不是同一机构。

## 边界

实验室成员、学生、合作企业和共同项目不能仅凭负责人履历自动扩展。
