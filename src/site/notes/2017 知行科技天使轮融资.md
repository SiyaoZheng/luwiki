# 2017 知行科技天使轮融资

港交所招股书记录[[知行科技]]在 2017 年 9—11 月完成 Series Pre-A，引入嘉兴自知一号和北京车和家等投资人；[[明势资本]]官方材料把知行科技称为其天使轮项目和唯一财务投资人。

两类材料的品牌／法律主体和轮次命名需要分层，不把嘉兴自知一号直接改写成明势品牌本身，也不推断[[曾颖哲]]个人持股。
