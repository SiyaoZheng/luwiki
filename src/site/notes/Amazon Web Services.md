# Amazon Web Services

Amazon Web Services 是 [[Amazon\|Amazon]] 体系的云计算业务，自 2006 年起提供云服务能力。AWS 品牌、Amazon 母公司、地区运营公司和具体客户合同主体需要分开建模。

## 身份与层级

- AWS 是 Amazon 的业务组织，不是 Amazon 母公司的别名。
- 投资 Anthropic 的主体与提供云服务、分销和计费渠道的 AWS 业务属于同一集团中的不同关系层；不能把母公司股权关系直接写成 AWS 对客户公司的控制权。

## Anthropic 商业关系

AWS 是 [[Anthropic\|Anthropic]] 公开确认的主要云与训练基础设施提供方。Amazon 在 2023—2026 年分阶段对 Anthropic 作少数股权投资和后续承诺；这些资本关系由 Amazon 承担，AWS 同时提供采购、云服务和分销渠道。

两条渠道不能合并：

- [[Amazon Bedrock\|Amazon Bedrock]] 是 AWS 管理、销售和计费的模型分销服务。
- [[Claude Platform on AWS\|Claude Platform on AWS]] 于 2026 年推出，客户可经 AWS 账户采购，但服务由 Anthropic 运营；它不是 Bedrock 的改名。

Anthropic 与 Amazon 2026 年公告还包含长期云采购与未来投资承诺。公告中的“承诺”“最多”和客户数量均应按公司自报及未来条件处理，不等于资金已全部到账、合同收入已经确认或客户独家使用 AWS。

## 其他商业网络

- [[GitLab\|GitLab]] 的 Dedicated 产品部署在客户选择的 AWS 区域；这是一条产品托管关系，不代表 Amazon 投资或控制 GitLab。
- [[张靖\|张靖]] 的公开履历把 AWS 经历作为云服务产品化来源；欧拉万象公司关系经人物页中转。

## 证据等级与边界

- **证据**：A：AWS／Amazon／Anthropic 官方公告；C：媒体人物履历。
- AWS 作为主要提供方不等于排他提供方；Anthropic 同时使用其他云渠道。
- Amazon 的少数投资者身份不公开精确持股比例，也不能由云采购金额反推表决权。
- Bedrock 与 Claude Platform on AWS 的运营、合同和数据处理边界不同。
- 前 AWS 经历不表示 Amazon 或 AWS 投资、合作或提供技术背书。
