# Amazon Web Services

Amazon Web Services 是 Amazon 体系的云计算业务，自 2006 年起提供云服务能力。

## 身份与层级

- AWS 是 Amazon 业务组织；品牌、地区运营公司和具体服务合同主体需分开。

## 当前网络角色
