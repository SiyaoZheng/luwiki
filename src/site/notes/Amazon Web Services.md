# Amazon Web Services

Amazon Web Services 是 [[Amazon\|Amazon]] 体系的云服务品牌、管理业务与 SEC 报告分部，自 2006 年起对外提供服务。AWS 品牌、报告分部、[[Amazon Web Services, Inc.\|Amazon Web Services, Inc.]]、Amazon 母公司以及不同国家的合同主体必须分层建模。

## 身份、法人和报告分部

- Amazon.com, Inc. 的 2025 年 10-K 只设 North America、International 和 AWS 三个报告分部。
- AWS 2025 年净销售额为 1,287.25 亿美元、营业利润为 456.06 亿美元；分别占 Amazon 合并净销售额约 18%和营业利润约 57%。这是报告分部口径，不是 Amazon Web Services, Inc. 单体财务。
- [[Matt Garman\|Matt Garman]]自 2024 年 6 月起任 AWS CEO；该头衔描述业务管理责任，不自动构成所有当地 AWS 法人的法定董事或签约授权证据。
- [[Amazon Web Services, Inc.\|Amazon Web Services, Inc.]]是 Amazon.com, Inc. 100% 持有的重要美国子公司之一。AWS 官方合同方页面显示，不同国家和地区的客户可能与当地 AWS 实体签约；因此不能把全球 AWS 合同都归给这一家公司。
- AWS 是 Amazon 的业务组织与报告分部，不是 Amazon 母公司的别名；“AWS 收入”“Amazon 投资”和“当地 AWS 合同”是不同证据层。

2025 年 Amazon 现金资本性支出约 1,283 亿美元，10-K 称多数技术基础设施投资支持 AWS 增长。该金额是合并集团资本配置，不等于 AWS 当年确认成本、某一客户采购额或单一数据中心投资。

## Anthropic商业关系

AWS 是 [[Anthropic\|Anthropic]] 公开确认的主要云与训练基础设施提供方。Amazon 的股权投入通过 [[Amazon投资Anthropic\|Amazon投资Anthropic]] 记录；AWS 是云服务供给方并承接渠道分销，Anthropic 则承担云容量采购承诺。投资主体、证券登记持有人与 AWS 业务单元不能在没有文件时合并。

截至 2026 年 6 月 30 日，Amazon 的 SEC 披露支持累计实际投入 Anthropic 180 亿美元，另有最高 150 亿美元的条件性未来额度。Anthropic 同时承诺未来十年在 AWS 支出超过 1,000 亿美元。已投入股权资金、未来融资上限和长期云采购是三种不同关系；采购承诺也不是已经确认的 AWS 收入。

两条产品渠道不能合并：

- [[Amazon Bedrock\|Amazon Bedrock]] 是 AWS 管理、销售和计费的模型分销服务。
- [[Claude Platform on AWS\|Claude Platform on AWS]] 于 2026 年推出，客户可经 AWS 账户采购，但服务由 Anthropic 运营；它不是 Bedrock 的改名。

AWS 是“主要”提供方不等于排他提供方；Anthropic 同时通过其他云渠道提供产品。融资额度与 AWS 容量交付里程碑挂钩，也不足以证明投资资金必须原路回流 AWS。

## OpenAI商业关系

AWS 与 [[OpenAI\|OpenAI]] 的云商业关系和 Amazon 集团的股权投入需要分开。Amazon 2026 年第二季度 10-Q 披露，AWS 与 OpenAI 原有 380 亿美元多年云服务承诺，其后又扩展 1,000 亿美元、期限八年；[[Amazon投资OpenAI\|Amazon投资OpenAI]]则记录累计 500 亿美元股权投入及其到账时点。

380 亿美元原有承诺、1,000 亿美元新增扩展、500 亿美元股权投入和未来确认的 AWS 收入是不同口径。合同总额不等于已确认收入，也不能从云采购承诺反推持股、表决权或经营控制。

## 其他商业网络

- [[NVIDIA AI Enterprise\|NVIDIA AI Enterprise]] 在 AWS Marketplace 由 NVIDIA 出售并部署于 AWS；这是采购、计费与云运行渠道，不表示 AWS 拥有该产品、充当终端客户，或取得 NVIDIA 软件收入的全部归属。
- [[GitLab\|GitLab]] 的 Dedicated 产品部署在客户选择的 AWS 区域；这是一条产品托管关系，不代表 Amazon 投资或控制 GitLab。
- [[张靖\|张靖]] 的公开履历把 AWS 经历作为云服务产品化来源；欧拉万象公司关系经人物页中转。
- AWS 与 Amazon Leo、Zoox、Whole Foods 等集团业务共享母公司，但不能仅凭集团关系推断这些业务由 AWS 法人运营或采购。

## 证据等级与边界

- **A 级**：Amazon SEC 申报、AWS 合同方页面、Amazon／Anthropic 官方公告。
- **C 级**：媒体人物履历。
- AWS 报告分部不等于 Amazon Web Services, Inc. 单一法人。
- Amazon 的少数投资者身份不公开精确持股比例，也不能由云采购额反推表决权。
- Bedrock 与 Claude Platform on AWS 的运营、合同和计费边界不同。
- 前 AWS 经历不表示 Amazon 或 AWS 对人物现公司投资、合作或提供技术背书。
- 本页只记录商业实体、产品定位与合同／渠道关系所需的高层事实，不涉及实现或 cybersecurity。
