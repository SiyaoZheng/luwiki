# 源策未来

源策未来（Archon Robotics）是一个围绕通用全身人形基座模型展开的具身智能公司节点。当前来源称其由 [[李弘扬\|李弘扬]] 带队创立，核心方向是 Whole-body Intelligence，即为人形机器人构建可跨本体迁移的全身具身大脑。

## 观察

- 源策未来把行业痛点定义为全身动作数据缺失：桌面第一视角、单机械臂和夹爪数据难以覆盖重心转移、躯干借力、多肢体联动和居家复杂任务。
- 公司路线强调 [[全身智能\|全身智能]]：上层大脑做任务理解和长周期规划，中层沉淀不绑定单一本体的全身运动表征，下层小脑跟踪位姿和维持平衡。
- 来源称公司完成 2500 万美元种子轮融资；资本端点和财务顾问角色统一经 [[源策未来种子轮融资\|源策未来种子轮融资]] 事件页中转。这些融资信息应作为媒体报道口径保存，后续需要公司公告、工商信息或投资方披露核验。
- 该公司样本说明 [[具身智能数据基础设施\|具身智能数据基础设施]] 的数据荒正在从“有没有机器人数据”细化为“有没有全身协同、重心变化、触觉和居家场景数据”。

## 三同关系线索

- 核心人物是 [[李弘扬\|李弘扬]]。Archon Robotics 官网把他列为 founder and Chief Robot Officer；其港大、OpenDriveLab、上海人工智能实验室关系应由人物页中转，不在公司页直接连接前任职或学校。

## 截至 2026-08-10 的公开答案

- 官网已经确认 [[李弘扬\|李弘扬]]、李天羽和陈立的创始团队角色、约 20 人团队、Humanoid Foundation Model 方向，并把当前阶段明确写为 `Demo / Early Product Validation`。公司称已有内部原型和演示，但未来 12 个月才计划扩大机器人队列并建立合作方试点；这不是已有客户部署的证据。
- 公司技术愿景把全身智能拆为 S2 任务语义、S1 原生人形模型、S0.5 运动/BFM 和 S0 跟踪控制四层，并提出人类、机器人、仿真、失败与部署数据的复合预训练。这回答了“通用全身人形基座模型”在其路线中的含义，但文章没有实验表、模型 release 或独立 benchmark。
- 官网投资者栏没有显示可核验的机构名称或金额；公开页面也未提供权重、代码、数据集、模型卡、具名试点或开源时间表。2500 万美元、公司成立时间和投资方仍只能保留为原报道口径；只有公司/投资方公告、登记材料或公开 release 才重新开启交易和产品进展判断。
