# 泛化

泛化是个体在经历某一刺激和反应后，把类似反应扩展到相似刺激、相似情境或相似行为上的学习现象。它既可以表现为技能迁移和举一反三，也可以表现为恐惧、焦虑或情绪反应向无关对象扩散。

## 观察

- 泛化把学习从单点经验变成类别经验：相似刺激越接近原刺激，越容易触发相似反应。
- 在经典条件反射中，刺激泛化说明有机体不只记住一个精确刺激，也会对相邻刺激范围形成反应梯度。
- 在教育和训练中，泛化是能力可迁移的前提；只会在单一老师、单一地点或单一指令下完成任务，不等于真实掌握。
- 在心理问题中，过度泛化会让负面情绪从原始事件扩散到更多场景。治疗或训练中的“分化”则是重新学习差异，限制错误联结的扩散。
- 对 [[AI 与大脑情绪系统\|AI 与大脑情绪系统]] 来说，泛化是情绪条件作用能否迁移到相近刺激的关键观察点；它不等于主观情绪，只是学习曲线和表征变化的证据之一。
- 对 [[心理世界模型\|心理世界模型]] 和 [[以人为中心的具身智能\|以人为中心的具身智能]] 来说，泛化能力决定模型是否能把人类反馈、情绪线索和交互规则迁移到新情境，同时也带来误读和过度推断风险。
