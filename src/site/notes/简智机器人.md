# 简智机器人

简智机器人（GenRobot AI）是一家围绕人类中心具身数据采集、治理和数据服务构建产品栈的公司。公开产品包括 DAS Ego、DAS Dex、DAS Fingers、DAS Gripper、DAS Controller、Gen Human Data 和 Gen Matrix 数据治理平台。

## 产品栈

- 采集端覆盖第一视角视觉、手部运动、触觉、IMU、轨迹、语音等模态；不同 DAS 设备承担头部、手部或控制器入口。
- 治理端由 Gen Matrix 承担清洗、轨迹与环境重建、切片、标注和模型评测等环节。
- 数据服务分为 Raw Data、Processed Data 和 Model-processed Data，体现从采集资产到模型可用数据的分层交付。

## DPH 指标

公司在 2026 WRC 论坛提出 `DPH = 独立任务数 × 采集者人数 ÷ 数据总时长`，希望用“每小时多样性”替代只按小时计数的规模叙事。它抓住了任务与人群覆盖的重要性，但当前仍是公司提出的评价框架，不是经验证的行业标准。

DPH 至少还需与以下指标联用：任务独立性的定义、模态完整率、跨设备同步误差、有效样本率、跨人/跨场景/跨本体留出，以及相同训练预算下的真实机器人增益。否则高 DPH 可能只代表更多短任务和表面差异。

## 对噜 Wiki 的意义

简智机器人为[[具身智能数据基础设施\|具身智能数据基础设施]]提供了“采集—治理—融合—训练—评测—回流”的商业闭环样本。其关键可检验命题不是设备数量或数据小时数，而是 Model-Ready Data 是否在目标模型上带来可复现的泛化与真机提升。
