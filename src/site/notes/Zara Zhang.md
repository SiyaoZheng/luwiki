# Zara Zhang

Zara Zhang 是 GitHub 账号 `zarazhangrui` 的公开显示名，也是开源项目 [[Frontend Slides\|Frontend Slides]] 的维护者。她的公开作品把 HTML、coding agent 和设计规则结合为可复用的演示制作 skill。

## 公开工作

- GitHub 主页把 `frontend-slides` 列为置顶项目，并链接到个人网站；仓库的 README 和提交历史把该账号标为项目创建者与维护者。
- 公开演示《Code as a medium for storytelling》把 HTML 视为演示媒介，并展示了从视觉规则、迭代反馈到封装 skill 的工作过程。
- [[Frontend Slides\|Frontend Slides]] 的关键贡献不是一个固定模板，而是把风格发现、固定画布、内容转换、浏览器验证和分享路径组织成 coding-agent 可读取的流程文件。
