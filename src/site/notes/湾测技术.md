# 湾测技术

湾测技术（WONSOR；深圳市湾测技术有限公司）是一家面向工业安全、精密测量和通用传感的高端工业传感器企业。

## 产品与采用边界

公司官网列出安全传感器、三维/二维测量和通用传感产品，并称服务 3C、新能源、汽车、机器人和半导体等行业。具名客户、出货量、国产替代和标准参与多为公司自报，不能自动写成客户采购规模、市场份额或第三方性能验证。
