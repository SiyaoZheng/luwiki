# 元禾控股

元禾控股是一家股权投资管理机构。它在当前网络中的直接作用是作为 [[元禾原点\|元禾原点]] 的父机构节点，避免把“元禾”当作一个未分化的投资主体。

## 可核验组织关系

- 元禾控股官网为 [[元禾原点\|元禾原点]] 设置独立业务入口，支持二者的组织层级连接。
- 元禾控股官网同时把 [[元禾璞华\|元禾璞华]] 列为其集成电路投资平台；这条组织关系已由父机构一侧直接确认，不再只是名称相似推断。元禾璞华仍保留独立机构页，以区分品牌平台、管理人和具体基金载体。
- 元禾控股本体没有被交易公告列为 OriginFlow 的直接参投方；公开角色属于元禾原点和元禾璞华两个具名机构。
