# Xiaomi HyperOS

**Xiaomi HyperOS（小米澎湃OS）**是[[小米集团\|小米集团]]面向手机、平板、穿戴、电视、智能家居和汽车连接场景使用的跨设备软件平台与操作系统品牌。它不是公司、法律主体、财务报告分部或公开单列收入线；英文标准名为 Xiaomi HyperOS，中文标准名为小米澎湃OS，HyperOS／澎湃OS只是简称。

对手机和平板而言，公开产品仍与 Android 版本结合；对穿戴、电视、IoT 和汽车连接等场景，HyperOS又作为跨设备软件架构和体验品牌使用。因此更稳妥的对象层级是“一组按设备类别承载的软件系统与连接能力的共同品牌”，而不是所有设备运行同一套二进制、同一内核或同一版本。

截至2026年8月12日，小米中国与全球官方页面仍把 **Xiaomi HyperOS 3** 作为当前已发布大版本。同期媒体出现的 HyperOS 4 测试或发布日期线索尚未得到小米正式发布材料确认，不能写成已发布产品、正式版或确定兼容名单。

## 产品身份与系统层级

| 层级 | 已核事实 | 不能推出 |
|---|---|---|
| 集团与品牌 | [[小米集团\|小米集团]]在监管披露中把 HyperOS 作为“人车家全生态”的软件基础；[[小米\|小米]]是集团经营品牌 | HyperOS不是开曼发行人的子公司、独立业务分部或单独上市资产 |
| 前身产品线 | 2023年起，HyperOS按小米管理层口径逐步接替[[MIUI\|MIUI]] | 不是2023年10月某日全球MIUI即刻停服，也不是MIUI的法律更名 |
| 组成平台 | 2023年集团披露称核心由[[Xiaomi Vela\|Xiaomi Vela]]与深度定制的Linux系统构成，并把HyperConnect称为自研跨设备连接框架 | 不能把Vela、HyperConnect、HyperAI或HyperCore互作HyperOS别名，也不能把手机端底层推广到所有设备类别 |
| 设备实现 | 全球页覆盖中国大陆以外的Xiaomi／[[REDMI\|REDMI]]／[[POCO\|POCO]]手机与平板，以及Xiaomi／REDMI穿戴；中国页另覆盖列明的电视和Xiaomi Watch | 不能写所有小米、REDMI、POCO或AIoT设备均支持，也不能把不同地区页面的名单拼成全球统一覆盖 |

手机端的 Android 基线与 HyperOS 大版本并非同一版本轴。2026年7月，Android Central实测部分Xiaomi 17系列设备已经升级Android 17，但系统仍显示HyperOS 3.0.332；这支持两者可以分别更新，不支持“HyperOS已脱离Android”或“Android升级必然同步改变HyperOS代际”。

| 时间 | 事件 | 状态与边界 |

| 2023-10-26 | 初代Xiaomi HyperOS正式发布并随Xiaomi 14系列在中国首发 | 集团港交所文件保守确认“2023年10月发布”；旧设备随后按批次更新 |
| 2023-12至2024-01 | 首批小米平板、电视、手表、音箱和摄像机等计划渐进升级正式版 | 计划与开始推送不等于每台合资格设备完成安装 |
| 2024-10 | Xiaomi HyperOS 2随Xiaomi 15系列推出 | 公司将HyperCore、HyperConnect、HyperAI作为该代产品框架；它们不是独立法人或财务分部 |
| 2025-08 | Xiaomi HyperOS 3在中国正式发布 | 中国官网自8月29日起列出多波Beta计划，Beta不能写成全球稳定版完成 |
| 2025-09至2026-03 | 全球版公开介绍后，官方列出2025年10—11月、11—12月和2025年12月至2026年3月三波soft release | 仅表示计划开始分批推送；机型、地区、语言、系统应用版本和实际时间均可能调整 |

HyperOS发布前最后一项可比集团指标是2023年9月全球月活用户6.231亿。它是MIUI历史指标，不能改名为HyperOS装机量。类似地，小米集团披露的手机／平板MAU、AIoT联网设备和硬件出货量也都有不同分母，均不是HyperOS活跃用户、累计安装或升级完成率。

## 地区、设备与分发

HyperOS通过两条主要路径进入设备：新机预装，以及存量设备的OTA／soft release。官方排期同时受到机型、购买地区、系统版本、语言和应用版本影响；“在支持名单中”只说明合资格或计划波次，不证明设备已收到、用户已安装或功能已在全部地区开放。

| 官方页面 | 适用范围 | 重要限制 |
|---|---|---|
| 中国大陆HyperOS 3页面 | 页面列明的Xiaomi／REDMI手机和平板、电视及Xiaomi Watch | 首批为Beta计划；机型与时间可调整，部分能力还需系统应用另行升级 |
| 全球HyperOS 3页面 | 中国大陆以外的global versions：Xiaomi／REDMI／POCO手机和平板及Xiaomi／REDMI穿戴 | 三波soft release不是全量交付证明；功能会随地区、语言、机型与应用版本变化 |
| 2024 MWC页面 | 以手机和平板跨端剪贴板、Home Screen+、笔记等演示“人车家全生态”连接 | 展示具体兼容场景，不证明全部智能家居、汽车或第三方设备运行相同系统 |

中国电视的Beta覆盖不能直接外推为海外电视版本可用；全球页的手机、平板与穿戴名单也不能反向证明中国大陆稳定版已完成。页面中“功能将在未来开放”“预计推送”或“支持机型将增加”等表述都应保留前瞻时态。

## 运营主体与知识产权边界

HyperOS是集团产品品牌，但公开材料没有给出一个覆盖所有地区、设备、系统组件、云服务和开发者服务的唯一运营法人。

- [[小米集团\|小米集团]]是港交所发行人和集团披露主体，支持集团层面推出、披露并使用该品牌；它不因此自动成为每项终端服务、账号、云功能或地区协议的直接缔约方。
- [[小米澎湃OS开发者平台\|小米澎湃OS开发者平台]]一份2026年安全开放服务协议把“Xiaomi HyperOS／小米澎湃OS”等标识列为[[小米科技有限责任公司\|小米科技有限责任公司]]及其关联主体拥有的小米标识。这支持集团关联主体的品牌权利口径，不证明该公司是全球所有模块的唯一开发者、许可人或数据控制者。
- 同一开发者平台的快应用专项协议由小米科技有限责任公司、[[北京小米移动软件有限公司\|北京小米移动软件有限公司]]及小米集团下属关联公司共同作为“小米”一侧主体。它证明具体开发者服务可以由多个法人承载，不能泛化为所有HyperOS产品合同。

终端设备、账号、云服务、AI功能和区域隐私角色仍须按具体产品与地区条款判断。集团品牌归属、软件知识产权、服务合同主体和个人信息控制者是不同问题。

## 开放平台、许可与第三方能力

2023年公司称向应用和智能硬件开发者开放HyperConnect，并宣布开源Xiaomi Vela。当前全球HyperOS页面的“Open source / Apache 2.0”链接实际跳转到Vela/openvela页面；Vela官网将其定义为基于NuttX的IoT嵌入式软件平台，并对openvela使用Apache 2.0口径。

因此，**Apache 2.0只能归属于openvela／具体Vela仓库及其适用范围，不能归属于整个HyperOS产品**。HyperConnect在集团披露中反而被称为proprietary；Android、Linux、第三方依赖、系统应用、云服务、字体和品牌素材还可能适用各自条款。尚未找到一份可覆盖全部国家、设备类别和HyperOS组件的统一开源许可。

全球HyperOS 3页面还展示Google Gemini相关功能，并注明兼容性、地区和语言限制以及Google商标归属。这支持部分机型集成Google服务，不支持排他合作、共同开发、Google背书或经济条款。页面对iPhone／iPad／Mac描述的是安装Xiaomi Interconnectivity应用后的互操作兼容，并明确非Apple赞助、背书或关联，不能据此写成小米与Apple的商业合作。

## 采用与商业边界

小米没有在本轮所核公开材料中单列HyperOS的MAU、累计激活量、升级完成率、收入、ARR、许可收入、GMV或市场份额。可核验的采用证据主要是：具名新机预装、官方更新排期、已开始soft release，以及特定设备／地区的功能页。

这使HyperOS更适合作为小米硬件和服务组合的系统入口与跨设备连接层观察，而不是单独估值或收入归属的业务单元。官方“人车家全生态”定位描述了平台目标；它不证明所有连接设备都运行HyperOS、全部功能已经交付，或系统已形成可单列的外部许可业务。未找到第三方OEM获得HyperOS整机品牌许可或小米披露相应许可收入的证据。

## 证据边界

1. HyperOS是软件平台／操作系统品牌，不是法律主体、报告分部或独立收入线。
2. MIUI自2023年起被逐步接替；没有证据支持某日全球即刻停服或所有存量设备完成迁移。
3. 中国大陆Beta、全球soft release、新机预装和存量OTA是不同阶段；合资格名单不是安装量。
4. 手机端Android版本不能代表电视、穿戴、IoT或汽车的统一底层，Android大版本也不等于HyperOS大版本。
5. Vela/openvela的Apache 2.0口径不能外推为整个HyperOS完全开源。
6. 集团MAU、AIoT连接设备和硬件出货不能改写成HyperOS用户或装机量。
7. 具体服务主体随协议和地区变化；发行人、品牌权利主体、服务缔约方和数据控制者不能互换。
8. 兼容Apple设备不等于与Apple合作；集成Gemini不等于Google共同开发或排他授权。
9. 截至2026年8月12日，当前官方已发布版本仍是HyperOS 3；HyperOS 4仅有未确认线索。
