# 清华大学自动化系

清华大学自动化系是[[清华大学\|清华大学]]教学科研单位，成立于 1970 年，覆盖控制科学与工程、智能科学与技术等方向。

## 与当前实体的关系

- [[黄青虬\|黄青虬]]本科就读清华自动化系的说法已获 CUHK MMLab 官方校友页交叉支持：页面记载其 2016 年取得清华大学自动化本科。当前没有清华校友档案，但关系已从“单一交易材料”升级为第二所大学官方页面加交易材料双来源。
- 手亿科技创始团队的清华自动化训练背景目前来自融资媒体；这不等于公司由自动化系孵化或持股。

## 边界
