# 社交代理

社交代理是让 AI 代表用户处理一部分社交探索、筛选、互动和反馈的产品形态。它不是普通聊天机器人，也不是纯粹的数字人格展示，而是把“谁来面对社交噪声、谁来判断互动是否值得交还给人类”变成系统设计问题。

## 观察

- 社交代理把 [[数字分身\|数字分身]] 从“像我说话”推进到“按我的逻辑先行动”：代理需要知道用户的价值判断、关系边界、风格偏好、近期目标和不能越过的禁区。
- 这种产品的关键不是全自动社交，而是“代理试探 - 人类确认”的闭环。AI 可以先完成点赞、评论、破冰和低风险互动，真正的承诺、亲密推进和高风险表达仍需要人类接管。
- [[AI 记忆系统\|AI 记忆系统]] 是社交代理的前置条件。EVE/Elys 相关来源把 128 个记忆槽位、异步 reflection、冲突合并和 planning model 组织成主动记忆层，说明社交场景不能只靠关键词 RAG。
- 主动记忆与被动检索的差异在社交场景中尤其明显：用户没有主动提到的短期目标、长期梦想、政治偏好、亲密边界或近期压力，也可能决定代理该不该回应、怎么回应。
- 社交代理把 AI 陪伴从封闭对话推向开放网络。陪伴不再只是用户和 AI 的双人关系，也可能变成 AI 在公共或半公共空间替用户维护弱连接、筛选关系和减少试探成本。
- 人类的接管、驳回和确认会成为高价值训练信号。相比普通聊天点赞，接管行为更直接地暴露“这个代理此刻是否还能代表我”。
- 对 [[AI Agent 安全\|AI Agent 安全]] 来说，社交代理的风险核心是身份权限：代理能否代表用户发言、能否主动联系他人、如何标注 AI 身份、何时必须停止，以及被代理互动的第三方是否知情。

## 边界

- “超级对齐”“第二灵魂”属于产品叙事，不等于代理已经可靠理解用户人格。
- 社交代理会放大误解、冒犯、操控和关系依赖风险；自动化社交不应绕过显性授权、人类确认和撤销机制。
