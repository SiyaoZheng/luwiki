# 裕太微电子

裕太微电子股份有限公司（Motorcomm；上交所代码 688515）是一家高速有线通信芯片设计企业，核心产品包括以太网物理层 PHY 芯片，并扩展至交换、网卡和车载以太网芯片。

## 身份纠错

“裕太微电子”是正式公司名，“裕太微”是证券简称。线性资本中文团队页写作“裕泰微电子”，属于错字，不应另建实体或 alias。

## 投资关系

[[裕太微电子 IPO前明势投资关系]]记录明势品牌关联的具体基金载体在 IPO 前持股的事实。品牌、基金管理人、投资载体与上市公司股东不能合并成同一法律主体。线性团队页把该项目归入[[曾颖哲]]在明势时期的项目清单，但不足以证明个人持股、董事席位或退出收益。
