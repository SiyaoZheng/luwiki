# PepWeather

PepWeather / 陪你天气是一个把天气不确定性产品化的气象 AI 节点。它的公开叙事把天气预报从“给出一个确定结果”转向“输出可量化、可响应、可补偿的不确定性体验”。

## 观察

- PepWeather 的技术叙事围绕 [[数据同化\|数据同化]]、[[潜空间数据同化\|潜空间数据同化]]、generative post-processing 和 stochastic interpolants 展开：NWP ensemble 与 AI weather model 不是最终产品，而是进入后处理和不确定性校准的输入。
- 它的应用场景横跨参数化保险、量化交易、复杂风险引擎和出行天气保障，说明气象 AI 的商业化不只在“预报更准”，还在“概率分布能否被定价和触发行动”。
- 第 151 条 `/home` 和第 152 条根域名都只返回前端壳，但 meta description 已经把中文产品定位表达为用数据和算法把天气不确定性转化为可量化、可响应、可补偿的体验。
- PepWeather 与 [[DataShareClub\|DataShareClub]] 相邻但层级不同：DataShareClub 更像历史天气/AQI 数据入口，PepWeather 更像把预报、同化、不确定性和补偿机制组织成产品。
