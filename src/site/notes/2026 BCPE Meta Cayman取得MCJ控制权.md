# 2026 BCPE Meta Cayman取得MCJ控制权

这是[[株式会社MCJ\|株式会社MCJ]]在2026年进行的管理层收购与私有化事件。公开买方[[BCPE Meta Cayman, L.P.\|BCPE Meta Cayman, L.P.]]是为投资MCJ于2026-01-14在开曼设立的有限合伙企业；MCJ 2026年4月文件称其由Bain Capital Private Equity, LP提供投资建议的基金及其集团持有和运营。该载体、Bain体系、MCJ和其子公司应分层记录，不能互作同一法律主体。

## TOB、结算与控制权快照

MCJ董事会于2026-02-05表明支持本项MBO并推荐股东参与公开收购。公开收购期为2026-02-06至2026-04-07；2026-04-14开始结算时，BCPE Meta Cayman持有70,792,445股，按MCJ当时计算口径的所有割合为74.91%，并成为MCJ亲公司及第一大股东。

74.91%是有明确分母的交易时点比例：文件以2025-12-31已发行101,774,700股，扣除MCJ自持股7,266,759股后所得94,507,941股为分母。它不是BCPE对MCJ每一类别证券、每一期间的恒定比例，也不能下推到[[株式会社マウスコンピューター\|株式会社マウスコンピューター]]的直接持股比例、经营权细节、融资金额或最终实益所有人结构。

## 私有化和退市

MCJ于2026-04-27决定将株式并合、取消单位股制度及章程修改提交5月27日临时股东会。东京证券交易所记录，该会通过使指定主体以外股东持股成为不足一股的并合方案；MCJ股票自2026-05-27至2026-06-15列为整理铭柄，并于2026-06-16从Standard Market退市。

退市是该项私有化程序中的市场状态变化，不等于MCJ解散、停止经营或旗下品牌／子公司发生即时法人变更。MCJ对Mouse的间接控制路径应写作“Mouse → MCJ → 本交易事件 → BCPE Meta Cayman”，而非将BCPE或Bain写成Mouse的直接股东或直接融资方。

## 创始人再投资安排的边界

MCJ 2026-04-27披露交易被界定为MBO，理由是董事长兼当时第一大股东[[髙島勇二\|髙島勇二]]预计在交易完成后继续参与经营；文件还称其被设想为保留股份，或在应募后对MCJ再出资。该文是交易安排和意向的披露，不能单独证明再投资已经交割、最终持股比例、投票权安排或所有资金来源。

交易披露也提到收购方拟从BCPE Meta Intermediate Holdings Cayman, L.P.获得出资并获得银行融资；这是收购与端数处理的拟定资金安排，不应写成MCJ自身的新一轮融资、Mouse的债务或已经完整执行的资本结构。
