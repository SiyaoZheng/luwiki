# 招商局创投

招商局创投是招商局集团面向战略性新兴产业和产业培育的企业创投平台。

## 身份与层级

- 该节点属于招商局集团产业投资体系；招商启航等下属平台和具体基金需另行建模。

## 当前网络角色

- [[欧拉万象早期融资\|欧拉万象早期融资]] 的投资方披露把招商局创投列为领投方。
