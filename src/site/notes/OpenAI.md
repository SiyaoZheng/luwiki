# OpenAI

OpenAI 是从事人工智能研究、模型和产品开发的机构节点。品牌背后存在不同运营和治理实体；本页不把 OpenAI 品牌压缩成单一法律主体。

## 与 Anthropic 的人物和竞争关系

[[Anthropic\|Anthropic]] 的早期团队中，多名共同创办人在创办公司前曾任职 OpenAI。为避免制造公司—前雇主直边，履历关系分别经 [[Dario Amodei\|Dario Amodei]]、[[Daniela Amodei\|Daniela Amodei]]、[[Jack Clark\|Jack Clark]]、[[Sam McCandlish\|Sam McCandlish]]、[[Jared Kaplan\|Jared Kaplan]]、[[Chris Olah\|Chris Olah]] 与 [[Tom Brown\|Tom Brown]] 等人物页核验；共同前雇主不等于仍受 OpenAI 控制，也不自动证明知识产权转让。

在产品市场上，OpenAI 的 [[ChatGPT Enterprise\|ChatGPT Enterprise]] 与 Anthropic 的 [[Claude Enterprise\|Claude Enterprise]]、两家开发者平台及其他企业产品构成直接竞争。竞争关系不等于双方全部产品可互换，也不能用单一投资人调查推断全球审计市场份额。

## 与 NVIDIA 的投资和基础设施关系

OpenAI 于 2026-02-27 公告新一轮 1,100 亿美元投资、投前估值 7,300 亿美元，其中 NVIDIA、SoftBank 与 Amazon 的公告金额分别为 300 亿、300 亿和 500 亿美元；OpenAI 同时宣布扩大与 NVIDIA 的基础设施合作。该轮与 NVIDIA 的具体关系见 [[2026 NVIDIA对OpenAI投资\|2026 NVIDIA对OpenAI投资]]。

仅凭 OpenAI 的融资公告不能证明各投资方全部资金已经到账；Amazon 后续 10-Q 已确认其 500 亿美元投入的时间层次，但该公告没有披露 NVIDIA 的最终持股或表决权。2026 年公告的 NVIDIA 300 亿美元不能与 2025 年双方“最高 1,000 亿美元”意向上限机械相加；意向、承诺上限、完成投资和确认收入必须分开。

## 与Amazon的投资和云商业关系

[[Amazon投资OpenAI\|Amazon投资OpenAI]]记录 2026 年股权投入及其到账时点。OpenAI 公告把 Amazon 的本轮投资额列为 500 亿美元；Amazon 的第二季度 10-Q 则披露，截至 2026 年 6 月 30 日已投入 287 亿美元，期后再投入 213 亿美元。融资公告金额、已到账现金、持股比例与表决权不是同一口径。

同一 SEC 文件还把 AWS 与 OpenAI 原有 380 亿美元多年云服务承诺，以及新增 1,000 亿美元、八年期扩展安排分开披露。股权投入与云采购承诺不能相加成单一投资额，也不能从采购额反推控制权或已确认收入。
