# OpenAI

OpenAI 是从事人工智能研究、模型和产品开发的机构节点。品牌背后存在不同运营和治理实体；本页不把 OpenAI 品牌压缩成单一法律主体。

## 与 Anthropic 的人物和竞争关系

[[Anthropic\|Anthropic]] 的早期团队中，多名共同创办人在创办公司前曾任职 OpenAI。为避免制造公司—前雇主直边，履历关系分别经 [[Dario Amodei\|Dario Amodei]]、[[Daniela Amodei\|Daniela Amodei]]、[[Jack Clark\|Jack Clark]]、[[Sam McCandlish\|Sam McCandlish]]、[[Jared Kaplan\|Jared Kaplan]]、[[Chris Olah\|Chris Olah]] 与 [[Tom Brown\|Tom Brown]] 等人物页核验；共同前雇主不等于仍受 OpenAI 控制，也不自动证明知识产权转让。

在产品市场上，OpenAI 的 [[ChatGPT Enterprise\|ChatGPT Enterprise]] 与 Anthropic 的 [[Claude Enterprise\|Claude Enterprise]]、两家开发者平台及其他企业产品构成直接竞争。竞争关系不等于双方全部产品可互换，也不能用单一投资人调查推断全球审计市场份额。

## 其他网络角色
