# 小米澎湃OS开发者平台

**小米澎湃OS开发者平台**是围绕 [[Xiaomi HyperOS\|Xiaomi HyperOS]] 生态提供开发、测试审核、分发、推广与商业化入口的官方开发者服务门户。当前官网标题严格使用这一名称。现行文档仍沿用“小米开放平台”“小米应用商店开发者站”“小米开发者站”等历史或模块称谓，但本轮没有找到它们与现门户完全等同的正式改名文件，因此不把这些称谓设为 alias。

本轮未见该平台被登记或定义为独立法律主体；它也不等同于 Xiaomi HyperOS 操作系统本身。中国大陆以外的应用分发由官方文档导向独立地区入口 [[Mi Developer\|Mi Developer]]；它不是本页的英文别名。

## 产品与服务边界

| 服务层 | 当前官方入口所列内容 | 证据边界 |
|---|---|---|
| 开发 | 应用与系统能力接入、快应用、小游戏，以及设备开发入口 | 系统能力按项申请；设备开发外链到独立的 [[Xiaomi Vela\|Xiaomi Vela]] 体系，不能把两个平台合并 |
| 测试与审核 | 应用测试、上架审核、部分系统能力的资质与场景审核 | 注册账号不等于自动取得全部能力，也不保证审核通过 |
| 分发 | 应用、游戏、电视应用、快应用、小游戏、负一屏服务与全搜内容分发 | [[小米应用商店\|小米应用商店]] 是其中一个具名分发产品，不是整个门户的 alias |
| 推广与变现 | 营销平台、游戏联运、广告联盟、应用联运 | 各模块另有规则、结算与分成安排，不能从单项协议推导统一费率 |
| Agent 生态 | 2026 年文档化的 MCP、Skill 与 Agent 服务发布和调用 | 这些是平台内服务类别，不拆成独立技术节点；官方协议不保证流量、收益或持续可用 |

2024 年小米合作伙伴大会把适配技术、开发者服务、统一分发与商业化作为澎湃 OS 生态的几项基础。该表述来自小米活动及新华社客户端转述，适合说明平台定位，不是对使用规模、分发效果或商业回报的独立审计。

## 运营与合同主体

平台各模块的运营、合同和数据处理主体并不完全相同，不能把集团、站点页脚和单项协议压成一个“全球唯一运营主体”。

| 范围 | 已核验主体口径 | 可以推出什么 |
|---|---|---|
| 门户页脚 | [[小米科技有限责任公司\|小米科技有限责任公司]] | 支持站点版权与备案口径；不足以证明其单独承接所有模块、所有地区合同 |
| 应用商店 | 应用发布协议称小米应用商店由小米科技有限责任公司所有并运营 | 支持该分发模块的运营主体；不等同于整个开发者门户 |
| 快应用 | 协议列小米科技有限责任公司、[[北京小米移动软件有限公司\|北京小米移动软件有限公司]]及集团下属关联公司 | 支持快应用模块的共同协议口径；不能外推其他模块 |
| Agent 服务 | 2026 年服务协议以小米科技有限责任公司签约，并把其关联公司纳入定义 | 支持该协议覆盖的 MCP、Skill、Agent 服务，不代表早期门户全部沿用同一合同 |
| 隐私与后台服务 | 隐私政策列小米科技有限责任公司及其关联公司，并分别说明推送、快应用、电视、穿戴、游戏等后台服务方 | 数据共享或后台服务方身份不自动等于平台运营者、合同方或知识产权所有人 |

小米集团的开曼上市主体是投资控股公司；本轮直接访问的门户页脚和模块协议指向境内运营公司，因而不把上市主体写成直接运营或签约方。

## 准入与地区

- 现行应用商店注册规范写明，当前暂不接受新的个人开发者账号申请；企业、政府／事业单位及其他组织需完成实名和资质审核。这是应用商店新账号入口的规则，不能推出历史个人账号均已注销，或自然人在所有服务中绝对不能使用。
- 系统能力接入通常要求已认证账号、至少一个已上架且场景匹配的应用；部分能力还需单独申请、审核和签署协议。因此“注册成功”与“取得全部能力”是两个阶段。
- 应用创建指南把中国大陆以外的分发导向 Mi Developer；快应用协议把该模块的许可范围限定为中国大陆。这两项地区证据按各自模块适用，不能概括为整个门户只服务中国大陆，也不能把国内入口写成全球统一站点。

## 费用、许可与内容权利

应用发布协议仅称该协议项下的平台服务“目前”免费，并保留未来收费或分成的可能；这不证明联运、广告、结算或其他模块免费。开发者对其应用承担独立运营、合规与用户纠纷责任，平台不保证上架、流量或收益。

快应用协议对小米工具与文档给予开发者在约定地区内有限、非排他、不可转让且不可再许可的使用权。与此分开，应用发布协议要求开发者就发布作品授予小米非排他、全球、不可撤销、免授权费、可转让且可分许可的广泛使用、修改、传播及第三方渠道分发许可；快应用协议对快应用内容的许可亦为非排他、全球、不可撤销、免授权费，并覆盖使用、复制、公开传播与营销。开发者或原权利人仍保有原始权利，但不能把合同授权收窄成仅限“分发所需”。2026 年 Agent 平台服务协议同样保留开发者或原权利人的上传内容知识产权，但发布后允许小米及第三方访问、使用或调用相应服务，并要求版本审核。上述安排都不能被写成平台收购内容、取得独家所有权或承诺商业回报。

## 演进时间线

- **2023-08-24／2024-09-25**：隐私政策正文声明政策于 2023-08-24 更新，而页面元数据显示该文档于 2024-09-25 更新。正文日期早于 HyperOS 发布，且仍使用“小米应用商店开发者站”称谓，说明账号、上传与管理基础设施具有 MIUI 时代的延续性；这不等于旧称与现平台完全同义。
- **2023-10**：Xiaomi HyperOS 操作系统发布。操作系统发布日期不是门户改名或上线日期。
- **至少到 2024-10-31**：Internet Archive 的页面快照已经显示“小米澎湃OS开发者平台”现名。快照首见日期只给出存在下界，不是精确上线日。
- **2024-12-27**：小米合作伙伴大会设置 HyperOS、开发者服务、应用生态和商业合作议程，显示门户已成为生态合作入口。
- **2026-04 至 2026-05**：Agent 服务协议新增并生效，MCP 发布指南更新，说明 MCP、Skill 与 Agent 服务进入正式文档化发布阶段；不能据此倒推这些服务在更早时期已经按同一框架运行。

## 证据边界

- 没有找到官方公告给出门户从“小米开放平台／开发者站”改为现名的精确日期。
- HyperOS、MIUI、小米应用商店、Xiaomi Vela、Mi Developer 与本平台是相互关联但不相同的产品或服务节点，不能互作 alias。
- “开放”主要指开发能力、文档、分发与生态接入；不能推出整个 HyperOS 或门户全部开源。明确开源的具体项目应单独核验。
- 官网用户规模、审核时效和大会成效属于官方口径；没有独立审计时必须保留来源归属。
- 各模块的运营、许可、地区和费用规则可能更新，使用当前规则时应同时保留访问日期与模块名称。
