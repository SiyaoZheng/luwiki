# 电单车出行环境优化

电单车出行环境优化关注电动自行车在城市日常交通中的行为机制、骑行环境、安全治理和空间设计。它把微出行从单纯交通工具问题，扩展为个人意图、道路环境、规则执行和城市生活方式共同塑造的治理对象。

## 观察

- 以计划行为视角研究电单车出行，意味着骑行选择不只由距离和费用决定，也受态度、主观规范、感知行为控制、安全感、便利性和周边基础设施影响。
- 电单车是 [[人本城市模拟\|人本城市模拟]] 的重要场景：它发生在机动车、步行、自行车、公交接驳和社区生活之间，容易暴露道路断点、停车秩序、冲突空间和安全感差异。
- 对 [[智能社会治理\|智能社会治理]] 来说，电单车问题不是单纯“严管”或“放任”的二分。更好的治理需要把道路设计、骑行环境、执法尺度、充电/停放设施和用户行为机制放在一起。
- 3S 出行与城市人居课题组的广东省哲社科立项把广州市作为案例，说明电单车正在成为城市交通与人居环境研究中的正式社科议题，而不只是城市管理中的临时问题。
- 这类研究可以和 [[以人为中心的具身智能\|以人为中心的具身智能]] 相邻：理解城市中的人，需要捕捉真实移动路径、身体暴露、风险感知、空间偏好和制度约束，而不是只看聚合流量。
