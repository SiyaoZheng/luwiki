# Carnegie Mellon University

Carnegie Mellon University（CMU，卡内基梅隆大学）是美国匹兹堡的研究型大学。本页只维护它与本库人物、院系和研究网络之间的公开关系，不用学校声誉替代对具体论文、公司或技术的核验。
